# 모바일 뒤로가기와 안내 문구 통일

운영 메종의 매장 판매 생성 화면에서 상단 부모 화면 링크가 약 16px 높이로 렌더링되는 차이를 발견했다. 아뜰리에와 카르넷의 대응 버튼은 44px였다. 카르넷 현황 화면의 시연 자료 안내는 좁은 화면에서도 제목, 본문, 상태 문구가 가로로 배치되어 본문이 불필요하게 좁아졌다.

## 변경

- 메종의 같은 구현 144곳을 `qd-text-action qd-text-action--regular w-fit`에 연결했다. 버튼 높이, 간격, 글자 크기, 색상, 모서리는 기존 큐 디자인 규칙을 읽는다.
- 카르넷 안내 컨테이너를 `qd-demo-banner-content`에 연결했다. 큐 디자인의 카르넷 기반 CSS가 640px 이하에서 한 열로 배치하고 본문에 전체 가용 폭을 준다. 넓은 화면은 기존 가로 배치를 유지한다.
- 링크 목적지, 문구, 아이콘과 나머지 메종 코드는 144개 파일 전체 비교로 동일함을 확인했다. 카르넷 업무 처리 코드의 변경은 없다.
- 기존 메종 수동 검수 75건의 인자, 참조 줄, 소비자 AST를 재확인했다. 달라진 인자나 참조 줄은 기존 판정을 물려받을 수 없다.
- 과거 토스트와 로딩 검수는 새 변경의 정확한 역변환을 거쳐 이전 지문을 검사한다. 새 변경 자체도 별도로 검사한다.

## 검증

- 메종 타입 검사, 린트와 운영 빌드 통과. 기존 린트 경고는 남아 있다.
- 메종 2,690개 시험 중 최초 3개가 시간 초과했다. 같은 단언으로 재실행해 모두 통과했다. 전체 파일을 읽는 실명 검사는 제한 시간을 5초에서 30초로 늘려 재실행했다.
- 카르넷 타입 검사와 운영 빌드 통과. 이번 CSS 변경에 DB 기록 시험은 실행하지 않았다.
- 클래스 외 변경과 위장된 링크, 인자 변경, 참조 줄 변경, 기존 기반 CSS 변경을 거부하는 5개 회귀 시험 통과.
- 실제 안내 JSX 블록을 사용한 20개 브라우저 사례 통과. 밝은·어두운 테마, 폭 375/390/640/641/1280px, 두 권한 분기를 확인했다. 공통 높이 44→48px, 모서리 10→6px, 좌우 여백 20→24px 변경도 전파됐다. 이 시험은 제품 훅이나 데이터 작업을 실행하지 않는 정적 배치 검사다.
- 세 제품 통합 릴리스 검사 통과. 원본 지도 111곳과 생성 사본이 일치하며 앱 아이콘도 32/32 일치한다.
- 공통 부품 18개 비교와 확장 부품 30개 비교의 차이·실패는 0건이다. 중앙 값 전파 408건, 팔레트 전파 36건, 기반 화면 18개 사례도 모두 통과했다.
- 메종 전체 대장은 원문·근거 지문을 정확히 역변환한 뒤 42,914개 기존 기록의 전체 필드를 중복 CSS 문맥까지 그대로 대조했다. 링크당 기존 유틸리티 6개가 공통 레시피 2개로 바뀌었다. 미분류 0건을 유지한다.
- 메종 09280b6a, 카르넷 69163745의 운영 배포가 모두 READY이며 각 운영 도메인에 연결됐다. 배포 ID, 커밋과 도메인은 `reviews/phase68-operating-deployments.json`에 기록했다.
- 로그인된 운영 화면을 폭 390px로 재검수했다. 메종 `/store/new`의 부모 화면 링크는 높이 44px, 모서리 10px, 글자 13px다. 카르넷 `/` 안내는 한 열이며 본문 폭 340px가 내부 가용 폭과 일치한다. 두 화면 모두 가로 넘침이 없다. 실제 화면과 측정은 `reviews/phase68-operating/`에 보관했다.

## 범위와 남은 검토

이 단계는 실제 확인된 두 차이와 그 반복 구현을 해결한다. 기존 540개 화면 대상과 2,330개 이미지 기록 전체를 이번에 새로 촬영한 것은 아니다. 현재 소스 미분류는 아뜰리에 851건, 메종 0건, 카르넷 0건이다. 미분류 851건을 전부 결함 또는 검수 완료로 취급하지 않는다.

큐 디자인을 수정한 뒤 생성·동기화·제품 빌드·배포를 거쳐야 운영 화면에 반영된다. 운영 중인 세 제품에 파일 저장 즉시 자동 반영된다는 의미는 아니다. 이 단계의 새 규칙은 중앙 CSS와 이 과정에 연결됐다.

iOS는 사용자 요청으로 제외했다. Android의 기존 unsigned 빌드 검증은 별도 기록에 있으며, 연결된 실제 기기에서 설치·실행한 검증은 아직 없다.
