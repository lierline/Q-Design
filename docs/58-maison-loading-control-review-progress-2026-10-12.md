# 메종 로딩 화면의 제어 높이 통일

메종의 실제 입력창과 기본 버튼은 공통 높이 44px인데, 필터와 양식의 로딩 자리는 36px로 고정돼 있었다. 작은 머리 동작 자리도 모바일·터치 환경에서 실제 작은 버튼과 높이가 달랐다. 로딩이 끝날 때 상자의 크기가 바뀌는 디자인 차이를 수정했다.

## 변경과 중앙 연결

`patterns/component-implementations/maison/components/shared/page-skeleton.tsx`를 정본으로 등록했다. 여섯 일반 입력·선택·제출 자리는 `--qd-control-height`를 읽고, 머리의 작은 동작 자리는 `--qd-control-height-sm`을 읽는다. 폭 640px 이하와 터치 포인터에서는 일반 제어 높이를 최소 높이로 사용한다. 현재 일반 높이는 44px, 데스크톱 작은 동작 높이는 36px다. 제목 자리, 공개 API, 반복 개수, 표시 내용과 접근성 구조는 유지했다.

정본 구현 범위는 29개 파일이다. 아뜰리에 5개, 메종 UI 18개와 공용 로딩 1개, 카르넷 5개다. 공개 내보내기는 값 161개와 타입 11개이며 보조 함수도 포함한다. 이 수를 독립 컴포넌트 수로 해석하지 않는다. 아뜰리에 Skeleton의 부속 렌더러 5개는 별도로 기록한다.

생성기는 제품 파일의 기존 줄바꿈 형식을 보존한다. 변경된 정본을 CRLF 제품 파일에 전달하는 회귀 검사를 추가했다. 제품 사본은 전체 본문과 공개 내보내기까지 정본과 대조한다. 큐 디자인의 CSS 값이나 해당 구현 정본을 수정한 뒤 생성·동기화, 검사, 제품 빌드·배포를 거쳐 반영한다.

## 검증 근거

현재 제품의 실제 React Input·Button과 Head·List·Form 로딩을 현재 제품 CSS 및 설치된 Tailwind로 함께 렌더링했다. 밝은·어두운 테마, 화면 폭 1280·390·375·640·641px, 두 포인터 조건의 20개 조합을 확인했다. 일반 높이를 48px, 작은 높이를 40px로 변경한 상태도 대조했다. 전체 40개 상태에서 로딩 높이 320회와 실제 제어 높이 120회가 일치했다. 390px 두 테마의 합성 화면 이미지도 직접 확인했다.

이 검사는 고정 제어 높이의 합성 회귀 검사다. 업무 데이터가 있는 새 업무 화면, 외부 글꼴, 날짜 입력과 모든 로딩 변형의 시각 인증을 뜻하지 않는다. 외부 발송, 가입·조직 생성과 운영 데이터 변경은 실행하지 않았다. 검사는 `tools/check-components.mjs --browser`의 브라우저 단계에 연결했다.

변경 전 전체 소스와 정확한 일곱 치환을 검증하는 별도 검사를 추가했다. 원본은 `source/history/maison-page-skeleton-before-controls.tsx`에 보관한다. 기존 판정 21개는 해당 인자와 소비 줄이 그대로인지 다시 대조했다. 소스·근거 지문과 세 줄 삽입에 따른 위치만 갱신했고, 다른 검토 내용은 유지했다. 변경된 인자나 다른 소스가 기존 승인을 물려받는 경우에는 검사가 실패한다.

구현 생성·변환·알림 근거 회귀 검사 11개, 메종 정본 사본 검사 92개와 운영 빌드가 통과했다. 빌드의 기존 이미지 대체 텍스트 경고 2개는 남아 있다. 정상 커밋 훅의 린트와 포맷 검사도 통과했다. 제품 커밋은 `8d7a97e7816303ffc658fa3e291f6fabdea0df2e`다.

## 최종 검사와 운영

최종 `extract-all --check --only=Q-Atelier,Q-Works,Q-Forge`가 종료 코드 0으로 통과했다. 원본 사본 111개와 제품 아이콘 32개가 일치했다. 별도 브라우저 단계도 종료 코드 0으로 통과했다. 기본 부품 비교 18개와 확장 비교 30개 조건에서 차이가 없었고, 배경·인증·화면 셸 검증 18개, 중앙 값 전파, 선택 상태, 앱 오프라인, 표·인쇄·차트·달력·파일 입력·알림과 이번 로딩 검사가 통과했다.

Windows 제한 환경에서 Edge 실행이 중단돼 브라우저 단계만 일반 권한으로 재실행했다. 보관용 변경 전 소스를 현재 원본 사본 폴더에 둔 문제와 빌드가 생성했다가 되돌린 버전 파일의 목록 지문도 수정한 뒤 전체 릴리스 검사를 다시 통과시켰다. 근거 검사를 생략하거나 훅을 우회하지 않았다.

메종 제품 커밋을 운영에 반영했다. 배포 `dpl_3dVx5WvG81sNPFyxjKoWBN2VvAcF`의 READY 상태, 일치하는 커밋과 `maison.medqraft.app` 연결을 확인했다. 운영 로그인 페이지가 불러오는 CSS 자산 2개에서 일반 높이, 작은 높이와 터치 최소 높이 유틸리티를 확인했다. `reviews/maison-loading-deployment.json`과 `reviews/maison-loading-production-assets.json`에 기록했다. 이 공개 자산 검사를 운영 업무 화면의 실시간 시각 검수로 세지 않는다.

## 남은 범위

아뜰리에 미분류 891개, 메종·카르넷 0개다. 이번 변경을 미분류 감소로 세지 않는다. 등록 주소 540개, 실제 화면 523개와 정상 제한·주소 이동 17개, 업무 화면 이미지 판정 2,330개도 그대로다. 합성 회귀 검사를 업무 화면 수에 더하지 않는다.

남은 미분류 인자의 소비 흐름, 추가 모바일·테마·입력 상태와 iOS·설치 기기·서명 검토가 남아 있다. 이번 변경은 메종 웹 로딩 구현이다. 공통 CSS와 앱 오프라인 자산은 변경하지 않았으므로 기존 앱 산출물 범위를 유지한다. 전체 시스템의 모든 인자가 이미 중앙 제어된 상태라고 인증하지 않는다.
