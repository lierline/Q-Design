# 업무 색상의 중앙 연결 검증

남은 736건 중 55건의 중앙 연결을 확인했다. 811건에서 시작한 이번 감사에서 누적 130건을 정리했으며 현재 미분류는 681건이다. 이번 단계도 제품 코드·디자인 값·운영 배포를 변경하지 않는다.

## 확인한 연결

청정실, 임상 평가, EU MDR, 미국·중국·일본 허가, PMS, 표준, 멸균과 UDI 목록의 상태 색상, CAPA·고객 불만 상태 표시와 구독 상태 표시가 해당한다. 중간 모듈에서 받은 값이나 지역 함수의 반환값이 실제 중앙 팔레트로 이어짐을 확인했다.

정적 import·re-export에 등장하는 실제 지역 모듈을 후보에 더한다. 파일을 발견했다는 이유로 승인하지 않으며 기존 판정 뒤에만 추가 연결을 검증한다. 각 변수, 가져오기 심볼, 반환 분기, 조합 속성과 CSS 변수는 기존의 완전한 값 증명을 거쳐야 한다. 별도 색상, 변경된 객체, 외부에서 받은 색상, 알 수 없는 값과 소스 밖 경로는 승인하지 않는다.

구독 상태의 `{ color, reason }`처럼 업무 문구와 색상이 함께 반환될 때는 실제 반환 객체에서 색상 속성만 추적한다. 함수의 모든 색상 분기가 중앙 값이어야 한다. 객체가 외부로 전달될 수 있으면 속성 값이 별도로 원시 값임도 증명해야 한다. 비동기 함수와 제너레이터의 반환은 동기 스타일 객체로 취급하지 않는다.

## 기록 보존과 검증

전체 53,991개 인자 중 이전 미분류 55개만 판정·사유·근거를 변경했고 나머지 53,936개는 모든 필드와 순서가 같다. 소스 지문, 인자 값·지문과 보고서 메타데이터는 유지했다. `atelier-import-ledger`가 현재 소스를 다시 읽어 각 연결을 검증하고 과거 검사의 입력을 정확한 이전 보고서로 투영한다. 73단계의 75건 증명도 유지한다.

가져오기 발견, 분기·변경·외부 값 거부, 지역 함수 반환, 과거 기록 보존에 대한 시험 52개가 통과했다. 세 제품 전체 릴리스 검사는 종료 코드 0으로 통과했고 공통 부품 계약과 앱 아이콘 32개도 모두 일치했다. 로그는 `D:/Claude/tmp/qd-phase74-final-tests.log`, `qd-phase74-proof-tests.log`, `qd-phase74-import-ledger.log`, `qd-phase74-release.log`에 보관한다.

다음 범위에는 정의되지 않은 `--qa-font-mono`를 읽는 전문가 알림 세 곳이 있다. 현재는 일반 monospace로 대체될 수 있어 중앙 글꼴과 차이가 난다. 해당 변수의 중앙 연결을 수정하고 실제 표시·중앙 값 변경 전달을 확인한다. 공통 부품의 전달 인자와 실제 측정값도 남은 범위이며 이 문서는 전체 화면 완료 판정이 아니다.
