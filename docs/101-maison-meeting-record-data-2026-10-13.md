# 메종 회의록 데이터 조립 인자 검수

회의록 양식의 미분류 스프레드 15건을 실제 안건·조치·후속 업무 데이터로 판정했다. 메종 미분류는 586건에서 571건으로 줄었다. 아뜰리에 573건, 카르넷 0건과 합하면 총 1,144건이다.

TypeScript가 해석한 조치 필드 4개, 안건 필드 5개, 후속 업무 필드 2개와 제출 기록 필드 12개를 각 위치에서 대조했다. any·unknown 타입은 허용하지 않는다. 양식의 createMeeting(common)과 updateMeeting({ id, ...common }) 호출은 실제 회의록 액션으로 심볼을 해석해 확인했다. 검증 스키마와 저장 액션의 전체 소스를 고정하고, 안건·조치·회의 개요·특이 사항·비고 필드의 실제 소비를 확인했다. 데이터베이스 코드나 실제 저장은 실행하지 않았다.

실제 행 수정 함수 세 개를 격리해 실행했다. 원문의 줄바꿈과 공백, 다른 조치·안건과 다른 후속 업무를 유지하는지 확인했다. 전체 판정 역변환은 이 15건만 되돌리며 다른 값 변경이나 빌린 근거는 거부한다. 준비 기록·문서 이미지·문서 필드·새로고침·업무 화면 판정을 포함한 17개 검사가 최종 실행에서 모두 통과했다.

이번 변경은 판정 도구와 근거에 한정된다. 제품 화면·업무 기능을 변경하지 않았으며 새 운영 배포는 없다. 전체 릴리스는 남은 미분류 때문에 아직 통과하지 않는다.
