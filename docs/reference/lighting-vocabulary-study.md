## 3. 우리 화면의 그림자를 빛의 말로 읽으면

5장의 그림자 값을 «광원이 어디에 있는가» 로 읽습니다.

| 5장 값 | 빛의 말 |
| --- | --- |
| 모든 그림자가 `0 Ypx Bpx` (x 가 0, y 가 양수) | 광원은 **화면 바로 위 정면**(탑 · 약간 앞). 왼쪽 · 오른쪽에서 오는 빛은 없다 |
| 번짐이 크고 진하지 않음(`0 6px 18px rgba(0,0,0,0.35)` · 라이트는 0.14) | **소프트 라이트**(큰 광원) |
| 고정 다크의 `0 1px 0 rgba(255,255,255,0.04 ~ 0.06) inset` | 위에서 온 빛이 판 윗모서리를 스치는 **림**. 5장의 말로 «금속에 빛이 스치는 인상» |
| 라이트 그림자가 검정이 아니라 `rgba(80,65,40,…)` sepia | 빛이 **따뜻하다**(골든 아워 · 프랙티컬 쪽). 그림자 색은 빛의 보색이 아니라 «종이에 비친 따뜻한 방 빛» |
| 공용 부품의 카드 그림자 없음 · 떠 있는 겹만 `0 12px 36px` | 바닥에 붙은 것은 그림자가 없고(플랫), 떠 있는 것만 그림자가 생김 |

그래서 한 줄 규칙으로 쓸 수 있습니다: **«화면의 빛은 하나다. 위에서, 부드럽게, 라이트에서는 따뜻하게.»** 새 그림자를 만들 때 x 를 넣거나(옆빛), 색 그림자를 넣거나(네온 · 글로우), 둘 이상의 방향을 섞으면 이 한 빛이 깨집니다. unslop 의 «On dark themes depth comes from surface steps and hairlines, not from shadows» 와도 같은 말입니다([unslop 대조](unslop-study.md)).

## 4. 로그인 배경 프롬프트를 이 어휘로 읽으면

`source/brand/login/PROMPTS.md`(2026-10-22 «판이 열린다» 의 배경 여섯 장)는 빛을 이렇게 적었습니다.

| 프롬프트의 말 | 34개 어휘로 | 판정 |
| --- | --- | --- |
| Single soft broad studio light | 13 소프트 · 큰 광원 하나 | 우리 UI 그림자의 빛과 같음 ○ |
| Extremely low contrast · seamlessly recede | 다크 = 02 로우키 · 라이트 = 01 하이키 + 27 플랫 | ○ |
| Not fog · no haze | 26 볼류메트릭 금지 | ○ |
| no circular glows, halos, lens flares, bokeh | 34 시어트리컬 · 11 림 글로우 금지 | ○ |
| no neon · no purple | 28 네온 금지 | ○ |
| no polished highlights · maximum RGB brightness about 40 | 11 림 · 12 하드 금지 | ○ |
| Lift all shadows · no dark shadows (라이트) | 14 바운스로 그림자 들어 올림 | ○ |

이미 34개 어휘의 좋은 쪽만 골라 적었습니다. 다만 **빛의 방향**은 적혀 있지 않습니다(«studio light» 만). 다음에 다시 뽑을 때 «key from top, slightly front» 를 더하면 UI 그림자의 광원(3절)과 그림 속 광원이 같은 자리에 서고, 판 위에 놓인 로그인 폼 카드의 그림자 방향과 배경 금속의 음영이 어긋나지 않습니다.

## 5. 가져올 것 · 안 가져올 것

### 가져올 것

1. **빛을 이름으로 시키기.** 그림 · 영상을 AI 도구에 시킬 때(얼굴 화면 배경 · 홍보 그림 · [움직임 브리프](motion-brief-study.md) 7절 «4 생김새») «분위기 있게» 대신 이름을 씁니다. 우리 기본 조합: **다크 «low-key, single soft key from top-front, no rim, no haze»** · **라이트 «high-key, flat soft light, warm bounce, no dark shadows»** · 사람 · 공방 장면은 **«soft window light from the side, one warm practical lamp»**.
2. **금지 목록을 빛의 말로.** 9장 금지(보라 그라데이션 · 네온 · 글로우)는 그림에서는 «28 네온 · 26 볼류메트릭 · 34 시어트리컬 · 31 스크린 글로우 · 29 틸 앤 오렌지 · 33 스트로브» 로 적어야 도구가 알아듣습니다.
3. **«화면의 빛은 하나다» 한 줄.** 5장 «깊이» 절에 3절의 읽기를 한 줄로(값 그대로). 새 그림자를 만들 때 x 를 넣지 않는 까닭이 생깁니다.
4. **프롬프트에 방향 한 마디.** 로그인 배경을 다시 뽑을 때 «key from top, slightly front».

### 안 가져올 것

극적 · 장르 조명(키아로스쿠로 · 실루엣 · 스플릿 · 언더 · 블루 아워 · 데이 포 나이트 · 문라이트 · 블라인드 · 대플드 · 모노크롬 레드 · 패싱) 과 9장 금지와 겹치는 것(네온 · 볼류메트릭 · 시어트리컬 · 스크린 글로우 · 틸 앤 오렌지 · 스트로브). 업무 도구의 «정밀 · 절제 · 따뜻한 고급감»(1장)과 반대편입니다.

- 로그인 배경을 다시 뽑을 일이 생기면 프롬프트에 빛의 방향을 더함.
- 34개 프롬프트 원문은 DM 으로만 줍니다. 받으면 2절 «무엇» 칸과 대조.
