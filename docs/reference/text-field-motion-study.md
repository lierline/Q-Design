# 입력 칸 움직임 조사 · Text Field Part 2 (@ui_motion_prompts) · 영상 실측

조사일: 2026-11-07. 출처: 인스타그램 [릴스 @ui_motion_prompts «Text Field Part 2»](https://www.instagram.com/reel/DfYRPKEDSDJ/) (입력 칸 연출 여섯 · 영문 · 일문).
오빠 지시 «이것도 공부해. 영상으로 애니메이션을 봐야 공부가 될 거임». 이번에는 **영상 본문을 받아 0.1초 단위로 읽었습니다**(아래 1절). 규칙이 아니라 참고라 이 폴더에 둡니다. 정본 값은 바꾸지 않았습니다.
같은 계정의 앞선 셋: [아래 탭줄](tabbar-motion-study.md) · [단추 · 카탈로그](ui-motion-prompts-study.md) · [화면 전환](screen-transition-study.md).

> **한 줄 요약.** 여섯은 전부 «입력하는 동안 칸이 사용자에게 되돌려 주는 말» 입니다. 글자 하나마다 150ms 안에 반응하고, 끝났을 때 색이 바뀌며(민트), 끝난 상태를 1.2초 이상 멈춥니다.
> 우리 입력 칸은 초점에서 테두리 금색 + 바탕 한 겹 들어감(`surface2`)으로 «지금 여기» 는 말하지만, **입력하는 동안**의 말이 없습니다. 비밀번호 강도 막대 하나(로그인 가입)만 있고 그것도 정본 밖입니다.
> 가져올 것은 넷입니다: 비밀번호 강도 막대를 정본 부품으로(상태색 사다리 · 단 하나씩 100ms) · 여러 줄 칸이 한 줄씩 자람(스프링 없이 160ms) · 완료 ✓ 와 «채워 드렸습니다» 류 보조 글귀 · 인증 코드 칸(생기면).

## 2. 여섯 연출 · 실측 시간표

장면은 0.0초에 가짜 손가락(고리)이 다가와 **0.6 ~ 0.7초에 칸을 누르고**, 그때부터 글자가 **0.1 ~ 0.15초에 하나씩** 찍힙니다. 끝난 상태는 **1.2 ~ 1.5초 멈춘 뒤** 3.5 ~ 3.6초에 0.2초 동안 흐려지며 처음으로 돌아갑니다. 초점 테두리는 보라 → 시안 그라디언트, 완료는 민트(초록), 바탕은 어두운 남색입니다.

| # | 이름 | 표지 설명(원문) | 실측(초 · 장면 시작 기준) | 무엇이 움직이나 |
| --- | --- | --- | --- | --- |
| 1 | OTP Code | Six code boxes fill one by one, then turn mint in a wave. | 0.7 첫 칸 초점 → 0.7 · 0.9 · 1.0 · 1.2 · 1.3 · 1.5 에 숫자 하나씩(초점 테두리가 다음 칸으로 옮겨 감) → 1.6 ~ 1.9 왼쪽부터 **칸마다 0.05초 어긋나게** 민트로 → 2.0 «✓ Verified» 가 아래에 떠오름 → 3.4 까지 멈춤 | 초점 이동 · 색 바뀜(어긋남) · 글귀 등장 |
| 2 | Card Number | Card digits group as you type, then the expiry fields slide in. | 0.7 초점 → 0.7 ~ 2.0 숫자 16개가 찍히며 **네 자리마다 빈칸이 끼어듦**(4821 7730 5196 2047) → 2.1 앞 열두 자리가 흐려지며 «•••• 2047» 로 접힘 → 2.1 ~ 2.3 오른쪽에서 MM/YY · CVC 칸이 **미끄러져 들어옴** → 3.5 까지 멈춤 | 글자 묶음 · 접힘(투명도) · 이동 |
| 3 | Strength Meter | A four-step meter fills and recolors as the password grows. | 0.6 초점 → 0.7 ~ 2.3 «Sunset42!?» 입력 → 0.9 첫 단 분홍(1.1 «Weak») → 1.3 둘째 단, **채워진 단 전부가** 노랑으로(1.4 «Fair») → 1.7 셋째 단 시안(«Good») → 2.2 넷째 단 민트(«Strong») → 3.4 까지 멈춤 | 단 채움(100ms) · 채운 단 전체 재색칠 · 오른쪽 작은 이름 |
| 4 | Auto Grow | The note field grows a line at a time with a soft spring. | 0.6 초점 → 입력 → 1.3 → 1.4 **둘째 줄로 한 번에 자람**, 2.0 → 2.1 셋째 줄. 보내기 단추는 오른쪽 아래에 고정 → 3.4 까지 멈춤 | 높이 한 줄씩(스프링 · 약 100 ~ 150ms) |
| 5 | Tag Input | Each typed word pops into a chip you can remove with ×. | 0.7 ~ 1.0 «design» → 1.1 **칩으로 톡 바뀜**(scale 팝) → motion 1.6 · ui 1.9 · prompts 2.5(둘째 줄로 **칸이 한 줄 자람**) → 3.4 까지 멈춤. 칩은 × 를 달고 색이 번갈아(보라 · 남색) | 글자 → 칩(scale) · 줄 바꿈 자람 |
| 6 | Ghost Complete | A gray completion appears; tap it and it fills in white. | 0.6 초점 → 0.8 ~ 1.0 «mia@» → 1.0 회색 유령 글 «mail.com» + 오른쪽 «Tab →» 알약 + 아래 «Tap Tab to accept» → 1.3 ~ 1.8 손가락이 알약으로 → 1.9 누름: 글이 흰색으로 채워지고 알약이 **민트 ✓** 로, 테두리 민트, 아래 «Filled in for you» → 3.4 까지 멈춤 | 유령 글(투명도) · 알약 → ✓ 교체 · 색 바뀜 |

영상에서만 보이는 공통 규칙 넷. ① 글자 하나마다 반응이 **150ms 안**(단 채움 · 칩 · 묶음 빈칸). ② 끝나면 **색이 바뀌고**(민트) 글귀 한 줄이 아래에 선다(Verified · Strong · Filled in for you). ③ 끝난 상태를 **1.2초 이상** 멈춘다. ④ 어긋남은 **0.05초**(OTP 민트 물결)로 아주 짧다. 넷 다 우리 5장과 같은 숫자 감각입니다(120 · 200ms · 35ms 어긋남 · 1.2초 멈춤은 앞 문서 «움직임 브리프»).

## 4. 여섯을 우리 규칙에 비추면

| # | 5장 · 9장 판정 | 우리 자리 | 가져올 것 · 버릴 것 |
| --- | --- | --- | --- |
| 1 OTP | 초점 이동 ○ · 색 어긋남 ○ · 떠오르는 글귀 ○ | 지금 없음. 2차 인증 · 이메일 인증 코드가 생기면 | 뼈대 그대로(칸마다 0.05초 어긋난 색 바뀜은 `.qa-stagger` 35ms 와 같은 말). 색은 민트 대신 `--qd-ok`. 보류 |
| 2 Card | 묶음 빈칸 ○ · 접힘 ○ · 미끄러짐 ○ | 결제 없음. 다만 **UDI · 문서 번호 · 로트 번호**처럼 «자리 수가 정해진 번호» 칸이 많음 | **네 자리마다 빈칸이 끼어드는 것**만. 접힘 · 미끄러짐은 자리 없음 |
| 3 Strength | 단 채움 ○ · 재색칠 ○ · 작은 이름 ○ | 로그인 가입에 이미 있음(정본 밖) | **정본 부품으로 올림.** 색은 위험도 사다리(2장 «위험도 색» · 빨강 → 주황 → 노랑 → 초록)를 그대로 써서 «약함 ~ 매우 강함» 과 짝. 단 채움 100ms · 재색칠은 `transition: background` 160ms. 이름은 오른쪽 12px `muted` 가 아니라 그 색 |
| 4 Auto Grow | 높이 자람 △(5장 «이동 · 투명도만» 밖 · 탭줄 D 와 같은 결정) · 스프링 × | `Txt` 가 3줄 고정 · 손으로 늘림. 폰에서 메모 · 사유 칸이 답답함 | **한 줄씩 자람**(`field-sizing: content` 또는 `scrollHeight` 로 행 수) + `transition: height 160ms` ease-out expo. 스프링 없음. 최대 8줄 뒤 스크롤. 폭 전환 예외와 같은 «배치 전환» 이라 오너 결정 |
| 5 Tag | 글자 → 칩 △(scale 팝 ×) · 줄 자람 △ · × 제거 ○ | 칩 입력이 없음. 생길 자리: 검토자 · 참조자 · 키워드 | 팝 대신 **칩이 투명도 + 왼쪽 4px 떠오름**으로 나타남. 번갈아 가는 색 × (칩은 한 색 · `Tag` 규칙). 필요해질 때 |
| 6 Ghost | 유령 글 ○ · 알약 × · ✓ 교체 ○ · 보조 글귀 ○ | 유령 자동 완성 없음. 조직 메일 도메인 · 제품 코드 접두어처럼 «늘 같은 뒷부분» 이 있는 칸 | 유령 글(`muted`) + **Tab 수락** + 완료 ✓ 와 «채워 드렸습니다» 류 보조 글귀. «Tab →» 알약은 키보드 힌트 글(`kbd`)로 |

살아남는 것은 **3(강도 막대 정본화) · 4(한 줄씩 자람) · 6 의 완료 ✓ 와 보조 글귀 · 2 의 자리 수 묶음** 넷이고, 1 · 5 는 그 칸이 생길 때 뼈대를 씁니다.

## 5. 시안 (오너가 고를 것 · 아직 안 만듦)

공통: `transform` · `opacity` · `background` · `border-color` 전환만(높이는 4 에서 예외 결정) · ease-out expo · 반응 150ms 안 · 끝난 상태 1.2초 이상 · reduce 에서 즉시.

### A. 비밀번호 강도 막대를 정본 부품으로 (`StrengthMeter`)

- 로그인의 `PasswordStrengthBar` 를 Q-Design `source/components` 로 올리고 세 제품(Q-Maison 가입 · Q-Carnet 가입)이 받습니다. 지금은 Q-Atelier 로그인 파일 안의 함수라 다른 제품에 없습니다.
- 4단 · 단 사이 4px · 높이 4px · 모서리 0(장부 결). 단 채움 100ms, 채운 단 전부의 색이 `transition: background 160ms` 로 바뀜(영상 3 의 «재색칠»). 색은 2장 위험도 넷(`--qa-risk-critical` 빨강 ~ `--qa-risk-low` 초록)을 «약함 ~ 매우 강함» 에 거꾸로 맞춤. 이름은 오른쪽 12px, 막대와 같은 색(막대 색은 글자 대비가 낮으므로 글자 색 토큰 `-text`).
- 9장 어법: 이름은 명사(«약함» · «보통»). 「비밀번호가 약합니다」 문장은 안 씀.

### B. 여러 줄 칸이 한 줄씩 자란다 (`Txt grow`)

- `Txt` 에 `grow` 를 주면 내용 줄 수만큼 높이가 따라가고(최소 3줄 · 최대 8줄 · 그 뒤 스크롤), `transition: height 160ms` ease-out expo. 스프링 · 출렁임 없음. 폰 키보드 위에서 칸이 자라며 보내기 단추를 밀지 않게 단추는 칸 밖 아래.
- 높이 전환은 5장 «이동 · 투명도만» 밖입니다. 탭줄 D 의 폭 전환과 함께 «배치 전환 두 가지(폭 · 높이)는 160ms 안에서 허용» 으로 예외를 둘지 오너가 정합니다.

### C. 칸 안 완료 ✓ 와 보조 글귀

- 검증이 끝난 칸(중복 확인된 문서 번호 · 형식이 맞은 이메일 · 저장된 값)에 오른쪽 안쪽 ✓(`--qd-ok` · 16px · 투명도 0 → 1 160ms)와 아래 보조 글귀 한 줄(«사용할 수 있는 번호입니다» 류 · `Field` 의 hint 자리). 테두리는 바꾸지 않습니다(초점 금색과 겹치므로). 오류의 반대편을 같은 자리(hint)에 두는 것이라 `Field` 규칙과 맞습니다.
- 알림(토스트)으로 «저장됐습니다» 를 띄우던 자리 가운데 칸 하나짜리 저장은 이것으로 조용히 바꿀 수 있습니다(앞 문서의 «복사 피드백» 과 같은 생각).

### D. 자리 수가 정해진 번호 칸의 묶음 빈칸

- UDI(14자리) · 로트 · 일련번호처럼 자리 수가 있는 칸에서 네 자리마다 빈 칸을 끼워 보여 주고 값은 그대로 저장. 움직임이 아니라 표기이지만 영상 2 의 요지가 이것입니다. 모노 글꼴(3장)과 짝.

### 하지 않을 것

- 보라 → 시안 그라디언트 초점 · 민트 · 알약 «Tab →» · 칩 scale 팝 · 번갈아 가는 칩 색 · 스프링. 9장 · 5장 금지이고 우리 초점은 금색 한 색입니다.
- 카드 번호 접힘 · 만료 칸 미끄러짐(자리 없음). OTP · 칩 입력은 칸이 생길 때까지 보류.
