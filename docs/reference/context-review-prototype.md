# 맥락 유지형 문서 검토 시안

2026-10-10. Q-Design 안에서 직접 조작하며 검토하는 시안입니다.

## 열기

저장소 루트에서 정적 서버를 실행하고 `preview/context-review.html`을 엽니다.

```powershell
python -m http.server 4817 --bind 127.0.0.1 --directory D:/Claude/Q-Design
```

주소: http://127.0.0.1:4817/preview/context-review.html

## 체험 순서

1. 목록의 문서를 선택합니다. 왼쪽 목록을 유지한 채 오른쪽에 상세가 나타납니다.
2. 확인 항목을 체크하고 검토 메모를 작성합니다. 다른 문서를 눌렀다가 돌아오면 초안이 남아 있습니다.
3. 집중 보기로 전환합니다. 목록과 함께 보기로 복귀하면 목록 위치와 상세 읽기 위치를 복원합니다.
4. 메모 저장을 누릅니다. 저장 중과 완료를 동일한 자리에서 표시합니다.
5. 모든 확인 항목을 체크한 뒤 검토 완료를 누릅니다. 다음 대기 문서로 이어갈 수 있습니다.
6. 목록으로 버튼 또는 Escape로 돌아옵니다. 검색어, 상태, 정렬과 목록 위치가 유지됩니다.

### 두 집중 보기 전환 비교

화면 위의 `현재 방식` 또는 `폭이 이어지는 방식`을 고른 다음 `집중 보기 체험`을 누릅니다.
같은 버튼이 `목록과 함께 보기`로 바뀌며, 다시 누르면 복귀합니다. 문서를 선택하지 않은 경우 첫 검색 결과로 체험합니다.
`3배 느리게`를 켜면 두 방식의 차이를 자세히 확인할 수 있습니다. 방식 변경은 메모와 검색 조건을 초기화하지 않습니다.

- 기본 선택은 폭이 이어지는 방식입니다. `?motion=current`로 기존 방식을 바로 열 수 있습니다.
- 기존 방식은 목록 폭을 즉시 바꾸고 본문을 짧게 나타냅니다.
- 새 방식은 같은 본문을 유지한 채 목록 영역을 접고 상세 영역을 넓힙니다. 돌아올 때 반대로 펼칩니다.
- 본문 복제나 글자 확대는 없습니다. 이 작은 시안에서는 실제 두 열의 폭을 변경합니다. 글자는 새 읽기 폭에 맞춰 줄바꿈됩니다.
- 전환 중 반대 동작, 방식 변경, 크기 변경, 읽기 조작은 대기열에 쌓이지 않고 현재 전환을 중단하거나 되돌립니다.
- 폰은 단일 화면 구조이므로 폭 전환 비교를 실행하지 않습니다. 목록 복귀와 문서별 초안은 같은 방식으로 유지합니다.

모바일에서는 목록과 상세를 한 화면씩 표시합니다. 브라우저 뒤로가기와 앞으로가기도 지원합니다.
문서 목록 버튼은 위·아래 화살표와 Home·End로 초점을 이동하고 Enter로 열 수 있습니다.
내용 검토와 변경 이력 탭은 좌·우 화살표로 이동합니다.

## 모션

| 동작 | 기본 시간 | 방식 |
| --- | ---: | --- |
| 선택과 조작부 | 120ms | 배경과 테두리 변화 |
| 상세 교체 | 220ms | 본문만 4px 위로 이동하며 등장 |
| 집중 보기 | 260ms | 본문 6px 이동과 투명도 |
| 집중 보기 복귀 | 180ms | 본문 4px 이동과 투명도 |
| 집중 보기, 폭 연결 | 320ms | 목록을 먼저 부드럽게 감추며 상세의 실제 읽기 폭을 확장 |
| 집중 보기 복귀, 폭 연결 | 240ms | 목록을 펼치며 이전 읽기 위치 복원 |
| 상세 닫기 | 120ms | 상세를 짧게 감춘 뒤 목록에 초점 복귀 |
| 저장 결과 | 140ms | 결과 문구만 4px 이동과 투명도 |

본문 전환에는 기존 Q-Design의 `cubic-bezier(.16,1,.3,1)`을 사용합니다.
폭 연결은 `cubic-bezier(.22,1,.36,1)`로 시작과 정지를 다듬었습니다. 목록은 8px 이내에서 이동하며 투명도를 함께 바꿉니다.
접기에서는 폭 전환 시간의 65%에 목록 글자가 먼저 사라져 가장자리에서 잘리는 인상을 줄입니다.
회전·확대·축소·바운스는 없습니다.
목록 전체의 반복 등장 연출과 인위적인 문서 로딩 대기는 없습니다.
모션 줄이기는 CSS와 Web Animations 양쪽에 적용됩니다. 운영체제의 모션 줄이기를 우선합니다.
시안 설정의 3배 느리게는 모션에만 적용하며, 예시 저장 응답은 650ms로 고정합니다.
상세 내용은 이전 본문과 겹치지 않게 교체합니다. 스크롤을 전환 시작 전에 복원하고 종료 시 최종 폭에서 확인합니다.
모션 줄이기에서는 즉시 전환하되, 현재 문서·상태 문구·초점과 화면 읽기 안내를 유지합니다.

## 합의 반영

사용자는 두 방식을 직접 비교한 뒤 폭이 이어지는 방식을 선호한다고 밝혔고, 이 방식을 기준으로 더 다듬어 Claude에게 전달하도록 요청했습니다.
선호 반영 후 비교 조작부의 채운 면을 줄이고 밑줄로 선택을 표현했습니다. 검토 완료가 주요 행동으로 남도록 체험 버튼의 강조를 낮췄습니다.
목록과 집중 보기의 본문 최대 폭 및 도구 모음 여백을 통일해 전환 시작 시 생기던 작은 치수 변화를 줄였습니다.

- 화면 외곽의 둥근 상자와 선택 행의 별도 테두리를 줄이고 붙어 있는 면과 괘선을 사용합니다.
- 주 버튼은 중립색입니다. 선택·초점·체크도 시안 전용 중립색으로 비교하며, 공통 디자인 토큰의 확정이나 변경을 의미하지 않습니다.
- 검토 대기, 완료, 오류 등 업무 상태색은 제품 식별색과 분리해 기존 의미를 유지합니다.
- 장식 구분선과 입력·조작 경계를 분리합니다. 입력, 선택 상자와 보조 버튼은 선명한 경계와 키보드 초점을 제공합니다.
- 상세 상단에 현재 문서 번호와 짧은 제목을 유지하고, 전체 제목은 본문에 표시합니다.
- 모바일 메뉴는 앱 헤더 아래에 붙습니다. 닫기와 Escape는 읽던 위치를 보존하고 메뉴 버튼으로 초점을 돌립니다.
- 메뉴 회전·가상 키보드의 실제 기기 검증은 아직 하지 않았습니다. 이번 확인은 브라우저의 폭·높이 변경 시뮬레이션입니다.

## 상태와 데이터

- 8개 문서는 가상 데이터입니다. 실제 파일, 사용자, 승인, API와 연결되어 있지 않습니다.
- 메모와 체크 항목은 문서별 메모리에 유지합니다. 새로고침하거나 탭을 닫으면 사라집니다.
- 검토 완료는 결재나 승인으로 표현하지 않습니다. 완료한 검토는 다시 열 수 있습니다.
- 저장 실패 체험은 다음 저장 한 번에만 적용됩니다. 실패 후 초안을 유지하고 재시도할 수 있습니다.
- 저장 중 다른 문서로 이동해도 저장 결과는 원래 문서에만 반영합니다.
- 저장 중 추가 입력을 하면 요청 시점의 내용만 저장하고 남은 변경을 안내합니다.
- 필터 밖의 문서가 열려 있어도 상세를 갑자기 닫지 않습니다. 상세 상단에 현재 조건 밖임을 알립니다.
- 초점 복귀 시 대상 문서가 필터 밖이면 검색창으로 돌아갑니다.

자동화 확인 스크립트: `tools/check-context-review.cjs`, `tools/check-context-motion.cjs`.
