## 2. unslop 의 생각

> 「Slop spreads color and effects over the chrome … Craft keeps the chrome quiet and puts the richness into one or two moments of content that people remember.」

- **좋은 화면의 다섯**: 밝은 것 하나(색 · 공을 지는 한 가지) · 조용한 크롬(차림 · 단추 · 글은 중성색과 강조 하나) · 한 문장으로 말할 수 있는 생각 · 비워 둔 자리에 놓인 글 · 진짜 제품 · 진짜 재료.
- **방향 다섯 줄을 먼저 쓰고 멈춘다**: Product(무엇을 누구에게) · Character(구체어 둘 셋 · «clean · modern · sleek · minimal · premium» 금지) · World(제품이 속한 재료 · 장소) · Moments(색이 몰리는 한두 자리) · Signature(이 제품만의 작은 장치 하나). 사용자 답을 듣기 전에는 고치지 않는다.
- **정도를 먼저 판정**: 무거움(전 과정) · 가벼움(«다듬기» · 찾은 것만 · 기존 브랜드 유지) · 없음(그렇다고 말하고 두세 개만 제안 · «좋은 화면을 다르게 하려고 바꾸지 말 것»).
- **아홉 단계를 순서대로, 한 단계를 화면 전체에 끝내고 다음으로**: 간격 → 색 → 아이콘 → 글 → 글자 → 배치 → 세부 → 그림 → 움직임. 간격이 먼저인 까닭은 리듬이 맞아야 나머지가 제대로 읽히기 때문이고, 글이 글자 · 배치보다 먼저인 까닭은 제목 길이가 크기와 자리를 정하기 때문이다.
- **템플릿 점검**: 「제품 이름을 다른 제품으로 바꿔 끼워도 화면이 맞으면 방향을 더 밀어라」.
- **하지 말 것**: 걷어낸 장식을 새 장식으로 바꾸지 말 것(유리 · 결 · 노이즈 · 네온 · 벤토). 기능 · 주장 · 자료를 지어내지 말 것. 모든 제품을 같은 얼굴로 되돌리지 말 것.

우리 1장(«강조는 한 화면에 하나 · 시각적 서명 다섯»), 2장(«금색은 상태가 아닙니다»), 9장(«AI 티로 읽히는 어법»)과 같은 말입니다. 우리 «World» 는 «아틀리에 · 장인의 공방 · 종이와 금», «Signature» 는 «제목 위 32×1.5px 금색 짧은 선» 입니다.

## 5. 가져올 것 · 안 가져올 것

### 가져올 것

1. **«티 → 고친 값» 한 줄 짝 꼴.** 우리 9장 표는 «도구가 세는 것 · 이 시스템에서» 두 칸입니다. unslop 처럼 «무엇이 보이면 → 무엇으로» 를 한 줄로 쓰면 고치는 사람이 바로 씁니다. 9장 표에 «고친 값» 칸을 더하는 안(값 변화 없음).
2. **느낌표 한 줄.** 9장 «화면 말투» 에 «화면 글에 느낌표를 쓰지 않습니다(진단 · 로그 글 제외)» 를 더하고 `check-voice.mjs` 가 세게 하는 안. 지금 유일한 ×.
3. **고치는 순서 아홉.** 10장 «고치고 키우는 흐름» 에 «한 화면을 다듬을 때 간격 → 색 → 아이콘 → 글 → 글자 → 배치 → 세부 → 그림 → 움직임, 한 단계를 화면 전체에 끝내고 다음» 을 참고로. 전수 검수 때 이 순서로 보면 같은 화면을 두 번 덜 엽니다.
4. **정도 판정 셋(무거움 · 가벼움 · 없음).** «좋은 화면을 다르게 하려고 바꾸지 않는다» 는 우리 «고침 · 바꿈» 갈래와 같은 생각이고, «없음이면 두세 개만 정확한 값으로 제안» 이 좋은 꼴입니다.
5. **템플릿 점검 한 줄.** 「제품 이름을 바꿔 끼워도 맞으면 실패」. 세 제품(아뜰리에 · 메종 · 카르넷)이 같은 정본을 쓰므로 «세 제품이 서로 바꿔 끼워도 맞는가» 로 읽으면, 제품 식별 색(7장)이 왜 필요한지의 근거가 됩니다.
6. **이야기 영상 기법**(고치는 과정을 10초로): 구조는 그대로 두고 CSS 단계 클래스(`.s1 .s2 …`)만 겹쳐 값이 제자리에서 바뀌게, 왼쪽 위부터 수십 ms 어긋난 물결, 빨간 교정선 먼저. Q-Design 소개 · 전후 비교 자료에 쓸 수 있습니다(라이선스 표기 필요).

### 안 가져올 것

- **Inter · Geist 권장**(tokens.md «정밀 · 기술 · 차분» 줄). 우리 9장은 둘을 «AI 생성물에서 가장 흔한 글꼴» 로 금지합니다. Pretendard 단일.
- **제목 굵기 400 ~ 500 · 600 이상 드물게.** 라틴 글꼴의 기준입니다. 한글 제목은 우리 3장 사다리(700)를 지킵니다.
- **겹친 모서리 계산 · 크기별 모서리.** 우리는 10px 단일 결정(5장 · 오너 2026-09-24).
- **누를 때 scale 0.97.** 우리는 `translateY(1px)` (1장 «scale 금지»).
- **랜딩 히어로에 생성 이미지 «장면».** 우리 얼굴 화면은 정해진 그림(10-22)이 있습니다.
