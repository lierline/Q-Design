# 공통 부품 추가 대조와 적용 경로

## 이번 수정

사각 조작부의 모서리 10px 통일에 이어, 선택 단추·탭의 글자 굵기와 여백, 빈 상태의 기본·작은 형태와 설명·동작·힌트 간격, 로딩 움직임을 공통 역할 변수로 연결했다. 메종의 참석자 선택 행과 삭제 동작, 이전 개정 없음 안내도 같은 규칙을 쓴다.

640px 이하 창에서는 터치 장치 여부와 관계없이 공통 단추·선택·탭의 최소 조작 높이를 44px로 유지한다. 실제 운영 메종의 375px 창에서 선택 단추와 사람 선택 행이 36~38px였던 차이를 기준으로 수정했다. 문장 입력의 최소 높이 80px, 표 내부 행의 평평한 경계, 출력 문서 격자, 원형 의미 표시는 각각의 역할을 유지한다.

정본은 `patterns/foundation.css`다. `source/component-rules.json`에 선택·입력·피드백·내비게이션 역할의 조건을 기록했고, 세 제품의 실제 부품 또는 업무 화면에 사용하는 기본 조합을 비교 시안에 연결했다. 카르넷에는 다른 제품과 동일한 빈 상태 동작 슬롯이 없으므로 없는 슬롯을 검수한 것으로 세지 않는다.

## 검증 범위

- 두 테마와 375·412·1440px 창, 터치·일반 포인터의 조합에서 세 제품 30개 사례를 대조했다. 이번에 추가한 동등 역할의 차이는 0이다.
- CSS 역할 값을 임시로 바꾸어 선택·탭·빈 상태·로딩·사람 선택의 실제 계산값이 따라 바뀌는지 확인했다. 동작 감소 설정도 확인했다.
- 기존 공통 부품·팔레트의 전달 검사 408개와 36개 팔레트 대조를 유지했다.
- 커밋된 원본 110개, 세 제품 사본, 앱 아이콘 32개를 전체 릴리스 경로로 검사했다.
- 아뜰리에의 타입 검사·단위 시험 4,664개·린트를 통과했다. 시험의 기존 예상 실패 1개와 제외 3개는 유지된다. 린트 오류는 0이며 기존 경고는 남는다.
- 메종 전체 시험 중 과부하에서 시간 초과한 두 파일은 독립 재실행하여 통과했다. 타입 검사와 카르넷 테마·동작 감소 검사도 통과했다.

## 큐 디자인 수정 후 반영 경로

1. 해당 역할의 `patterns/` 또는 큐 디자인 소유 원본을 수정한다. 제품 소유 사본인 `source/components`와 `source/screens`는 직접 수정하지 않는다.
2. 제품 부품 연결을 바꾸었다면 먼저 제품 원본을 커밋한다. 추출기는 커밋된 아뜰리에 HEAD를 읽는다.
3. `node tools/extract-all.mjs --sync --only=Q-Atelier,Q-Works,Q-Forge`로 정본과 세 제품 사본을 함께 생성한다.
4. `node tools/check-components.mjs --browser`와 `node tools/extract-all.mjs --check --only=Q-Atelier,Q-Works,Q-Forge`를 통과시킨다. 제품의 정상 사전 커밋·사전 푸시 검사도 수행한다.
5. 생성된 제품 변경을 커밋하고 배포한다. 운영 별칭과 배포 커밋을 대조하고 실제 화면을 확인한다.

파일 저장만으로 운영 시스템이 즉시 바뀌는 구조는 아니다. 공통 규칙의 수정은 동기화·검사·제품 배포 경로를 통해 반영된다. 이번 점검에서 팔레트 추출기가 진입 CSS만 읽어 분리된 팔레트를 놓친 문제를 고쳤다. 이제 커밋된 CSS import 전체를 읽고 세 제품 범위를 전달한다. 빈 상태에 추가한 클래스 때문에 낡은 추출 정규식이 실패한 문제도 실제 클래스와 판 구조를 함께 검사하도록 수정했다.

## 전체 감사의 남은 범위

페이지와 관련 UI 파일이 공통 CSS에 연결된다는 검사는 외형 전체의 검수 완료를 뜻하지 않는다. 아뜰리에의 미판정 인자 1,036개와 접근·상태 경계, 메종의 아직 직접 확인하지 않은 캡처와 모바일 재촬영이 남는다. 과거 일부 `mobile375` 캡처는 실제로 1280px였으며, 요청 폭과 실제 폭이 다르면 유효 모바일 검수로 승인하지 않는 가드를 추가했다.

개정 비교 화면의 이전 이미지는 발견된 차이의 증거로 유지하고, 수정 후 실제 화면을 다시 확인해야 해결된 화면으로 승인한다. 전체 업무 화면과 모든 인자가 큐 디자인 하나로 완전히 통제된다는 최종 인증은 아직 하지 않는다.
