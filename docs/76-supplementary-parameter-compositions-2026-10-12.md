# 추가 전달 인자 조합 검수

미분류 638건 중 50건의 사용처와 연결 근거를 추가로 검수하여 588건이 남았다. 811건으로 시작한 감사에서 누적 223건을 정리했다. 이 단계는 제품 화면 코드나 운영 배포를 변경하지 않는다.

40개 명시적 렌더러 인자 후보를 실제 TypeScript 심벌과 모든 호출부로 추적했다. 30개에서 정확한 원시 타입과 전달 경로를 확인했다. 호출부가 없거나 해석할 수 없는 참조가 있는 후보는 승인하지 않았다. 전달 인자의 타입은 객체 전달과 숫자 단위 조합을 구별하는 데만 사용한다. 호출자 지정값, 기본값, 계산 계수와 대체값의 중앙 연결 의무는 그대로 남는다.

새로 판정한 50개 조합은 중앙 값 또는 별도로 기록한 전달 인자만으로 구성되는지 확인했다. 숫자 타입이 정확히 증명된 전달 인자만 CSS 단위 문자열에 결합할 수 있다. 문자열이나 혼합 타입, 미검수 기본값과 임의의 계산 계수는 거부한다. 중앙 값이 아닌 조합에는 실제 JSX style 소비처 또는 명시적인 CSSProperties 문맥도 요구한다.

전체 53,991개 인자의 순서와 지문을 유지했다. 이전 미분류 50개만 판정·사유·근거를 바꾸었고 나머지 53,941개는 모든 필드가 같다. 새로운 역검증 장부가 실제 소스를 다시 읽고 모든 조합을 검증한 뒤 정확한 75단계 보고서로 복원한다. 이전 73~75단계 역검증도 유지한다.

관련 시험 50개가 통과했다. 세 제품 전체 릴리스 검사의 컴포넌트 계약, 원본 사본, 팔레트, 문구, 앱 독립 화면, 문서, 커버리지와 제품 동기화 항목이 통과했다. 최초 실행은 마지막 앱 아이콘 단계에서 샌드박스의 브라우저 경로가 설치 경로와 달라 종료 코드 1이었다. 설치된 고정 버전 브라우저를 PLAYWRIGHT_BROWSERS_PATH로 지정하여 실패한 항목만 다시 실행했고, 종료 코드 0으로 제품 아이콘 32/32 및 관련 주소·앱 설명·Q 표시·상단 색 대조가 통과했다. 아이콘 원본과 승인 지문은 수정하지 않았다.
