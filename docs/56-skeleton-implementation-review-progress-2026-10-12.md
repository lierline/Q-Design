# 로딩 묶음 정본 연결 기록

아뜰리에의 `components/Skeleton.tsx`를 Q-Design 구현 정본에 연결했다. 기본형과 행·카드·지표·제목·표 형태를 포함한다. 기존 커밋 `f794024ddccbdc7f8f6b4e4c8b599bc85ac830ee`와 전체 본문을 비교해 줄 끝만 정규화했다. 실제 제품 파일, 디자인 값, 입력과 접근성 동작은 바꾸지 않았다. 역사적 채택 근거는 `reviews/skeleton-implementation-adoption.json`에 별도로 기록했다.

## 범위와 공개 부품

구현 정본은 합계 28개 파일이다. 아뜰리에 5개, 메종 18개, 카르넷 5개다. 값 내보내기 154개와 타입 내보내기 11개에는 보조 함수도 포함하므로 부품 165개라고 표현하지 않는다. Skeleton의 부속 렌더러 다섯 개는 내보내기 합계에 합치지 않고 별도 항목으로 기록한다.

`Skeleton.Row`, `Card`, `KPIGrid`, `PageHd`, `Table`의 공개 이름과 원래 명명된 함수 이름을 명시적으로 등록했다. 등록하지 않은 추가, 이름 변경, 누락, 계산된 속성과 중첩 대입을 거부한다. 기존 React 표시 이름은 메타데이터로 구분하며 함수 대입으로 바뀌면 거부한다. 이 검사는 모든 정본과 선택 대상의 사전 검사에 포함되어 앞 제품의 파일을 먼저 바꾸지 않는다.

## 현재 표시 규칙과 검증

로딩 면과 모서리는 공통 CSS의 `--qd-surface2`와 `--qd-radius`를 읽는다. 반복 시간은 `--qd-skeleton-duration`이며 움직임 줄이기에서는 애니메이션을 멈춘다. 기존 문서의 초기 shimmer 설명과 현재 pulse 규칙을 구분해 안내했다.

실제 제품 구현을 설치된 React로 렌더링했다. 기본형과 다섯 부속 형태의 기본 개수·높이·모서리 참조를 확인했다. 중앙 반복 개수·높이·간격을 변경한 임시 입력이 실제 렌더링 결과에 반영됐고, 호출부가 명시한 폭·높이·개수는 보존됐다. 이는 React 출력 검사이며 새로운 업무 화면 시각 인증이 아니다.

별도 임시 작업 공간에서 정본 너비 표현을 바꾸고, 사본을 동기화하지 않은 상태가 실패하는지 확인했다. 아뜰리에만 동기화한 뒤 정본과 일치했다. 공개 부속 이름과 함수 이름을 바꾸거나 추가했을 때 앞 제품의 파일을 쓰지 않고 거부했다. 구현·문구 회귀 검사 14개가 통과했다.

최종 `extract-all --check --only=Q-Atelier,Q-Works,Q-Forge`가 종료 코드 0으로 통과했다. 실제 28개 구현 본문, 표시 인자·팔레트·동기화·앱 시작 화면 계약과 기존 검사까지 통과했다. 정본 렌더러의 앱 아이콘 32개도 모두 일치했다. 금지 문자 1,684개 파일 검사와 변경 공백 검사도 통과했다. 기존 접근 시뮬레이터의 정적 참조 미검출 안내는 동적 연결을 별도로 확인해야 한다는 범위 고지이며, 이번 단계에서 그 항목을 새 시각 인증으로 바꾸지 않았다.

## 남은 검토

아뜰리에 스타일 미분류 897개, 메종·카르넷 0개를 유지한다. Skeleton의 미분류 12개도 파일 소유를 근거로 승인하지 않았다. 호출부 스타일·클래스와 화면 상태는 별도 검토 대상이다. 등록 주소 540개와 업무 화면 이미지 2,330개의 집계도 그대로다. 현재 운영 배포와 Android 산출물은 실행 소스 변경이 없어 유지한다. iOS 직접 지정 디자인과 설치 기기·서명 배포 검증은 남아 있다.
