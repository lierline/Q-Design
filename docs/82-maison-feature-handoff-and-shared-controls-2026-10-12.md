# 메종 기능 이식 후 디자인 검수 재개

Claude의 `codex-briefing/06_Maison_이식_완료_알림.md`를 읽고 5c19ef2e 이후의 메종 main을 기준으로 검수를 재개했다. 이식된 819개 파일과 약 300개 업무 화면을 이전 검수 결과로 승인하지 않는다. 운영 DB 마이그레이션은 변경하지 않았다.

## 실제 수정과 운영 반영

TimePicker를 큐 디자인의 기본 UI 정본에 등록했다. Input의 date/time 분기와 새 Combobox 구현을 현재 이식 소스와 맞췄다. 시각 입력, 열기 버튼, 선택 항목, 팝오버, 확인 동작은 공통 규칙을 사용한다. 입력값 정규화, 오전·오후 전환, 비활성 상태와 기존 분 값은 유지했다. 운영 커밋은 0b7e83970ce52dc170efbf25e950f310ee338693이다.

메종 29개 파일의 표시 문구 54곳을 정리했고, 실제 검사 등록 화면에서 확인한 문구 4곳을 추가로 정리했다. 누적 30개 파일, 58개 리터럴이다. 메뉴, 미등록 발주 품목, 종료 날짜·시각, 서면 결재, 입고 미완료, 작성 중, 검사 판정 안내 등을 공통 문구 규칙으로 관리한다. 커밋 ba541d44와 e7be4ba1이다. 조건식, 권한, 업무 코드, 저장값과 마이그레이션은 변경하지 않았다.

보조 정보와 식별자의 10·11px 글자 11곳을 중앙 `--qd-caption-size`로 연결했다. 현재 값은 12px이다. 8개 파일의 캡션 변경이며, 고정 크기를 승인하는 예외를 추가하지 않았다. 운영 커밋 88eb59308a056210ec53b1677816dfdc3db04372, 배포 dpl_FJzBQnTDLeq8DTeJzVb8Ty9f4Tve가 READY이며 maison.medqraft.app에 연결됐다. ba541d44 문구 배포도 READY를 확인했다. e7be4ba1 배포 상태는 별도 후속 확인한다.

아뜰리에의 전문 문구 수정은 9f22faefa3bfb904f80be5c4c8a7dcf73ec59682로 운영 반영됐다. 배포 dpl_EaTicSTXfu3cdw5C2tHKgAz574Di의 READY와 atelier.medqraft.app 연결을 확인했다.

## 검증 범위

- 실제 운영 메종 대시보드의 일정 등록 양식에서 시각 팝오버의 10px 모서리와 화면 안 배치를 확인했다. 양식은 취소했으며 저장하지 않았다.
- 구매 실적 분석, 검사 목록, 검사 등록 양식을 실제 운영에서 열고 검토했다. 검사 목록의 표시된 사각 조작부는 10px 모서리였고, 1280px 화면의 문서 폭 초과는 없었다. 등록 양식의 데이터 입력·판정·등록은 실행하지 않았다.
- 시각 입력은 실제 Input·DatePicker·TimePicker와 제품 CSS를 장착한 12개 화면 폭·글꼴·테마 조합에서 확인했다. 높이·모서리 중앙 값 변경, 오전·오후와 분 선택, 비정규 분 값, 직접 입력 정규화, Escape, 비활성 상태를 검사했다.
- 캡션은 실제 11개 요소의 전체 클래스와 제품 CSS로 12개 조합을 검사했다. 320·390·1280px, 12·24px, 어두운/밝은 테마에서 넘침이 없었다. 중앙 값을 18px로 바꾸면 모든 요소가 함께 변했다.
- 메종 전체 타입 검사를 통과했다. 기존 일정·반복 일정 테스트 41개, 문구·색상 검사 16개, 결과 심볼 분석 17개, 새 비시각 소비자 검사 3개, 현재 탐색 검사 2개를 통과했다.
- 30개 수정 소스는 전체 파일 비교로 문구와 포매터 변경만 허용했다. 후보 인자 1,328개 중 도움말 본문의 정확한 표시 문자열만 별도로 대조하고, 나머지 인자는 그대로 유지했다. 캡션 변경은 별도 전체 소스 검증으로 구분했다.

## 미분류와 릴리스 상태

메종의 새 이식 기준 미분류는 최초 1,284건에서 984건으로 줄었다. 지표 색 선택자 254건, 캡션 11곳의 중앙 연결, 독립된 결과 변수 심볼의 실제 소비, 권한 판정 데이터·도움말 본문·DB 조회 열 62건을 각각 검증했다. 메종 미분류 984건, 아뜰리에 580건, 카르넷 0건이 남았다. 전체 1,564건은 모두 실제 디자인 결함이라는 뜻이 아니다. 해당 업무 소비자와 표현 값의 분류를 계속 검토해야 한다.

현재 메종 app 소스 전체의 지문을 바탕으로 공통 부모 이동 링크 147개를 검증했다. 이전 144개 링크 변경 이력은 고정된 과거 커밋에서 검증하며, 현재 이식 소스는 별도 검증한다. 기존 기록을 현재 화면에 그대로 승계하지 않는다.

전체 릴리스 검사는 아직 통과하지 않았다. 첫 실행은 메종 루트 글꼴·새로고침 연결과 기존 토스트 검수 지문, 이후 실행은 카르넷 전문 문구 변경과 배너 기록의 충돌을 발견했다. 이 충돌은 전체 소스 역대조와 변경 거부 테스트로 수정했다. 메종 이식 후 탐색 지문도 현재 증거와 과거 변경 이력으로 구분해 검사한다. 전체 검사는 계속 진행하며 남은 미분류를 숨기거나 관문을 우회하지 않는다. 마지막 전체 통과 기록은 phase78의 586개 테스트와 아이콘 32/32이다.
