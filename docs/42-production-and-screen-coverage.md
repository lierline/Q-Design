`tools/all-screen-connections.mjs`는 실제 import와 CSS import 연결을 해석해 기반·컴포넌트·팔레트 CSS 상속을 확인한다. 페이지, 레이아웃, 로딩, 오류, 찾을 수 없음, 전역 오류, 템플릿과 기본 슬롯 파일을 포함한다. 루트 레이아웃을 대체하는 `global-error`는 자체 CSS import를 따로 검사한다. 회귀 검사에서는 전역 오류 화면이나 팔레트 연결이 빠졌을 때 실패함을 확인했다. 검사는 전체 릴리스 검사에 포함했다.

521개는 페이지 파일 수이며 리다이렉트 페이지도 포함한다. 761개는 서로 다른 업무 화면 수가 아니다. 이메일·인쇄·독립 HTML·오프라인 출력은 각각의 출력 계약으로 검사한다. 개별 컴포넌트의 고정 값과 클래스 누락은 별도의 소비자 검사로 확인한다.

## 실제 화면 감사의 남은 범위

| 제품 | 직접 검토한 기존 캡처 | 유효 화면 근거 | 확인된 접근 경계 | 유효 근거 또는 경계가 필요한 대상 |
| --- | ---: | ---: | ---: | ---: |
| Q-Atelier | 661/661 | 169 | 2 | 30 |
| Q-Maison | 606/855 | 195 | 0 | 82 |
| Q-Carnet | 295/295 | 60 | 2 | 0 |

아뜰리에 `/onboarding` 캡처 1개가 남아 있다. 심사 준비도·계약 목록처럼 로딩만 표시된 화면과, `/family-link`처럼 권한·구독 조건으로 대시보드로 이동한 캡처는 해당 업무 UI 검수 통과로 처리하지 않았다. 아뜰리에의 미분류 표현 인자 1,041개도 남아 있다. 업무 계산·SVG·출력 규격과 공통 시각 규칙을 분리해 검토해야 하며 이 수 자체는 결함 수가 아니다.

기존 캡처는 대부분 로컬의 데스크톱 화면이다. 검토한 이미지의 정확한 지문과 관찰 내용만 기록했다. 메종 운영 `/audits/new`는 720px 높이의 메인 스크롤 영역을 0부터 4,127px까지 겹치는 9장으로 추가 검수했다. 전체 내용 높이 4,847px의 마지막 저장 버튼까지 확인했다. 입력·선택창은 높이 44px, 다중 입력창은 80px, 공통 글자는 13px, 모서리는 10px이며 가로 넘침이 없었다. 이 운영 근거는 기존 로컬 캡처 집계에 섞지 않고 `reviews/production-maison-audits-new-2026-10-11.json`에 따로 기록한다.

이를 최신 운영 버전의 모든 테마·좁은 화면·동적 상태·상호작용 검수로 확대하지 않는다. 전체 감사 판정은 현재 `not-certified`다.

## 큐 디자인 수정의 반영 경로

Q-Design 정본 수정 → 생성·동기화 → 해당 제품 검사·빌드 → 운영배포 → PWA 캐시 갱신 순서다. 파일 저장만으로 운영 사이트가 즉시 바뀌지는 않는다. 이번 제품 배포는 완료됐지만 Q-Design 저장소의 이번 정본·검수 도구 변경은 아직 로컬 작업 트리에 있다. 검수용 계정 정보나 비공개 화면 캡처를 저장소에 무차별 추가하지 않는다.

```text
node tools/extract-all.mjs --sync --only=Q-Atelier,Q-Works,Q-Forge
node tools/extract-all.mjs --check --only=Q-Atelier,Q-Works,Q-Forge
node tools/check-components.mjs --browser
node tools/page-evidence.mjs --write
node tools/design-readiness.mjs --write --check
```

마지막 명령은 남은 감사 항목이 있어 현재 실패하도록 설계되어 있다. 릴리스 검사 통과와 전체 디자인 감사 완료를 서로 다른 결과로 유지한다.
