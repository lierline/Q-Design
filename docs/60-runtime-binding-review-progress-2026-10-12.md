# 실행 데이터 인자의 추가 분류

높이·너비 후보로 잡힌 지역 변수 일곱 개를 실제 선언과 참조까지 확인했다. 대기 검토·허가 스냅샷 데이터, 문서 안내 문구, 문서 쓰기 권한 응답, 세션 처리 객체와 암호화 데이터에 쓰이는 `h`, `w`였다. 해당 변수만 업무 데이터로 분류했다. 표시 스타일과 그 이후 소비 인자는 별도 검토 대상으로 유지한다.

`reviews/atelier-runtime-binding-review.json`은 전체 소비 파일과 정확한 인자 지문, 소비 함수, TypeScript 변수 심벌의 실제 참조 위치에 연결한다. 기존 14개 업무 데이터 검토와 새 일곱 개의 허용 범위는 서로 구분한다. 두 범위가 서로의 판정을 물려받거나, 다른 소스·인자·참조를 적용하면 검사가 실패한다.

제품 실행 소스, 권한·세션·암호화·업무 정책과 표시 문구는 변경하지 않았다. 업무 함수, 외부 요청, 데이터베이스 작업과 암호화 함수를 실행하지 않았고 실제 키나 인증 정보를 읽지 않았다.

큐 디자인 커밋 `9537162`의 전체 판정 보고서와 대조했다. 해당 일곱 개의 미분류 판정만 업무 데이터로 변경됐고 나머지 모든 판정, 인자·소스 지문과 보고서 메타데이터는 동일했다. 대조 기록은 `reviews/atelier-runtime-binding-decision-migration.json`이다. 이전 범위까지 함께 확인한 회귀 검사 4개가 통과했다.

회귀 검사 4개와 최종 `extract-all --check --only=Q-Atelier,Q-Works,Q-Forge`가 종료 코드 0으로 통과했다. 원본 사본 111개와 제품 아이콘 32개가 일치했고, 금지 문자·변경 공백 검사도 통과했다. 실행 소스 변경이 없으므로 브라우저 검사와 운영 빌드를 다시 수행하지 않았다.

아뜰리에 미분류는 877개에서 870개로 줄었다. 메종·카르넷은 계속 0개다. 분류 작업을 디자인 중앙화 완료나 시각 수정으로 세지 않는다. 정본 구현 29개 파일, 부속 렌더러 5개, 등록 주소 540개와 업무 화면 이미지 판정 2,330개 집계는 유지한다. 새 업무 화면이나 설치 기기 검수를 추가한 기록은 아니다. 제품 실행 소스 변경이 없어 58번 기록의 메종 운영 배포와 직전 앱 산출물을 유지한다.

남은 실제 스타일과 호출부 인자, 추가 화면 상태와 iOS·설치 기기·서명 검토는 계속 남아 있다. 큐 디자인 수정은 생성·동기화, 검사, 빌드와 배포를 거쳐 반영한다. 시스템의 모든 인자가 이미 중앙 제어된 상태라고 인증하지 않는다.
