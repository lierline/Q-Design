# 메종 문서 이미지 크기 검수

문서 내 로고·서명·사진의 표시 크기를 만드는 실제 네 곳과 이미지 삽입 경로를 검수했다. 로고·결재 서명·사진 상자는 각각 `qdPrint.docxBoxes.logo`, `qdPrint.signatures.approval`, `qdPrint.docxBoxes.photo`에서 오며, 제품 사본의 본문·지문이 큐 디자인 원본과 일치하는지 검사한다.

미분류 17건을 개별 판정했다. PNG·JPEG 원본 픽셀 크기 4건은 입력 좌표, 비율을 유지하며 중앙 상자에 맞춘 크기와 XML 출력 10건은 검증된 스타일 조합, 그림의 원점과 효과 영역 0값 3건은 구조 값이다. 이미지 크기를 읽지 못했을 때 적용하는 별도의 4:3 기본 비율 2건은 미분류로 유지했다. 파일 이름이나 속성 이름만으로 예외를 만들지 않았다.

전체 입력·출력 모듈의 검수 지문을 고정했다. 새 이미지 상자 생성 위치, 별도 숫자, 호출부 변경은 재검수를 요구한다. 전체 보고서 역변환은 17개 판정 외의 변경과 빌린 근거를 거부한다. 과거 새로고침·문구 검사는 정확한 이전 보고서로 복원해 기존 검수 기준을 유지한다.

실제 XML 생성기로 네 상자 생성 위치와 이미지 비율 다섯 종류, 총 20개 조합을 검사했다. 모든 크기는 상자 안에 들어가며 원본 비율을 유지했다. 중앙 상자를 1.5배 바꾼 조합에서는 실제 출력 크기가 함께 바뀌었다. 기존 제품 이미지 단위 검사 18개와 새 이미지·새로고침·생산 문구·업무 문구 통합 검사 14개가 통과했다. 다운로드·저장·운영 데이터 변경은 실행하지 않았다. Word의 실제 페이지 렌더링 검수 완료를 뜻하지 않는다.

메종 미분류는 643건에서 626건으로 줄었다. 제품의 표시나 데이터는 이번 판정에서 수정하지 않았다. 현재 운영 제품 커밋은 `1e27ab26c9900690a1013d0f4b5bcb541341a7c4`다. 다른 메종 작업의 `lib/app-version.ts`를 보존했다. 계정 사용량 확인값은 45%이며 전체 릴리스 검사는 아직 통과하지 않았다.
