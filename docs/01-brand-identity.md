# 1장 · 정체성

이 장은 디자인이 왜 이렇게 생겼는지를 정합니다. 이름의 뜻, 그 뜻이 화면으로 옮겨진 방식, 디자인 원칙 다섯과 이 시스템을 알아보게 하는 시각적 서명을 적습니다.
까닭을 모르면 옮길 때 값만 베끼게 되므로, 값보다 먼저 이 장을 읽습니다.

## 정체성이 화면으로 옮겨진 방식

| 브랜드 가치 | 화면에서 |
|---|---|
| 장인정신 · 정밀 | 1px 헤어라인, 10px 모서리 단일값, 4px 간격 리듬 |
| 에디토리얼 | 매거진 구분자(큰 숫자 + mono 라벨 + 사라지는 선), 넓은 여백 |
| 절제 | 한 화면에 강조 하나. 회전 금지, scale 금지 |
| 따뜻한 고급감 | 순백 대신 크림(`#f0ebe0`), 순흑 대신 `#0c0c0c`, 샴페인 골드 |
| 접근성 우선 | 복잡한 cockpit 대시보드 배제. 전 색상 WCAG AA |
| 모바일 1급 | 어디서나 같은 품질. 44px 터치 타겟 |

## 디자인 원칙 다섯

**1. 위계는 글꼴이 아니라 굵기로.**
Pretendard 단일 글꼴입니다. 세리프를 섞으면 한글이 튑니다. 자세한 규칙은 [3장 글자](03-typography.md)에 있습니다.

**2. 회색을 쓰지 않습니다.**
중성 회색이 필요한 자리에 브랜드색을 4~22% 섞은 면을 씁니다.
스크롤바와 선택 영역에 순수 회색이 없습니다. 섞는 법은 [2장 색](02-color.md)의 «색을 쓰는 관용구» 에 있습니다.

**3. 모션은 «떠오름» 뿐입니다.**
회전 금지, scale 금지. `translateY` 6~8px 와 `opacity` 만 씁니다.
이징은 언제나 `cubic-bezier(0.16, 1, 0.3, 1)` (ease-out expo). 시간과 쓰는 곳은 [5장 모양 · 깊이 · 움직임](05-shape-elevation-motion.md)에 있습니다.

**4. 강조는 한 화면에 하나.**
샴페인 골드는 아껴 씁니다. 골드 그라디언트는 로그인 히어로 같은 «얼굴» 화면 전용이고,
업무 화면은 단색으로 절제합니다.

**5. 인쇄는 일급 시민입니다.**
규제 문서를 다루므로 심사원이 출력물을 읽습니다.
`@media print` 에서 팔레트가 통째로 갈리고 A4 여백과 워터마크가 붙습니다([2장 색](02-color.md)의 «인쇄», [8장 종이 · 문서](08-paper.md)).

## 시각적 서명 다섯

이 시스템을 이 시스템으로 보이게 하는 구체적 장치들입니다.
색만 옮기면 「단조롭다」는 말을 듣습니다. **옮겨야 할 것은 이 장치들입니다.**

**① 제목 위의 금색 짧은 선**
`PageHd` 상단, 32×1.5px 샴페인 막대. 페이지마다 반복되는 서명입니다.

**② 매거진 구분자**
```
32px 얇은 금색 숫자  ·  mono 대문자 라벨  ·  제목  ·  오른쪽으로 사라지는 금색 선
```

**③ 순차 등장**
`.qa-stagger` 컨테이너의 직계 자식이 35ms 간격으로 6px 떠오릅니다.
한꺼번에 뜨는 것과 인상이 완전히 다릅니다.

**④ 로딩 자리의 면**
로딩 자리에 「Loading…」 글자를 두지 않고, 자리 모양의 면(`surface2`)이 투명도만 바꾸며 숨 쉽니다.
모양과 시간은 [6장 부품](06-components.md)의 `Skeleton` 에 있습니다.

**⑤ 리본 배경**
샴페인 SVG 리본 두 겹이 32초 / 38초 주기로 아주 느리게 흐릅니다.
로그인은 opacity 0.14 / 0.08, 앱 내부는 0.07 / 0.04.

**액센트에서 색을 빼면 이 시스템은 무너집니다.** 그 실험은 `source/BRAND_THEME_METALLIC.md` 에 남아 있습니다.
