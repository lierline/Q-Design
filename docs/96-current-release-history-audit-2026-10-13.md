# 최신 소스와 릴리스 검수 근거 연결

메종 기능 이식 이후 기존 검수 도구가 최신 소스를 따라가는지 전체 릴리스 검사를 실행했다. 최초 전체 실행은 `ListStats` 문구 변경 후의 소스 지문 차이로 중단됐다. 이후 남은 모든 단계와 브라우저 검사를 실패를 숨기지 않는 별도 진단 실행으로 끝까지 진행했다. 최초 전체 실행과 후속 진단은 한 번의 전체 통과 결과로 합산하지 않는다.

후속 단위 검사는 625개 통과, 3개 실패였다. 실패 원인은 이동 링크 전체 소스 목록 지문과 생산 양식의 과거 레이아웃 검수 지문이었다. 별도 검사 단계에서는 과거 문구 규칙, 스타일 인자 색인과 메종 미분류 626건도 실패로 기록했다. 후속 실제 브라우저 검사 32개 도구는 모두 통과했다. 준비 표 48개 조합은 가로 넘침 0, 안전 서식 16개 조합은 셀 잘림 0이다. 실제 기기 설치나 모든 운영 업무 화면의 전수 검수를 뜻하지 않는다.

수정은 다음과 같이 범위를 제한했다.

- `ListStats`는 검수된 문구 다섯 개만 역변환하고 기존 열 전달 근거와 비교한다. 대상·근거·레코드 추가 변조는 거부한다.
- 기존 전문 문구 검사는 최신 문구 변경을 역변환하고 정확한 과거 규칙 집합으로 비교한다. 30개 파일·58개 문구·1,328개 스타일 인자가 기존 근거와 일치한다.
- 메종 상위 이동 링크 147개는 경로·클래스·위치·소스 지문이 모두 동일했다. 전체 앱 목록 지문만 최신 커밋에 연결했다. 실제 앱 소스 전체를 해당 커밋과 대조하고, 다른 링크나 중앙 레시피 변경은 거부한다.
- 제거된 과거 레이아웃 10곳은 생산 양식의 검수된 문구 변경만 역변환한다. 기존 스타일 제거 근거와 나머지 본문은 유지한다.
- 아뜰리에 공개 사본 3개의 실제 본문과 중앙 지문을 대조했다. 공개 화면 인자 2,940건 중 체크 표시 크기 12곳만 이미 배포된 중앙 변수 참조로 갱신했다. 기본 16px과 내부 비율 0.75는 유지된다. 다른 판정·인자·소스 위치 변경은 거부한다. 미분류 580건은 그대로다.
- 세 제품 스타일 인자 색인을 최신 소스로 다시 생성했다. 새로운 판정이나 예외를 추가하지 않았다.

복구 관련 단위 검사 12개가 통과했다. 기존 아뜰리에 문구·열·글꼴·타이포그래피 검사 12개 중 11개가 통과했고, 나머지 하나는 새 거부 메시지와 기존 기대 메시지의 차이였다. 변조를 거부하는 동작은 유지하면서 메시지를 맞춘 뒤 해당 검사도 통과했다. 중앙 글리프·상위 이동·스타일 색인 검사도 통과했다.

아뜰리에 스타일 검사에 읽기 전용 `--check`를 추가했다. 새 보고서의 소스 일치와 미분류 수를 함께 검사한다. 현재 미분류 580건 때문에 종료 코드 1을 반환하며 보고서는 변경되지 않는 것을 확인했다. 전체 릴리스에 이 검사를 연결해 아뜰리에 미분류가 누락된 채 통과하지 않도록 했다. 긴 컴포넌트 검사도 단계별 출력을 바로 보여주도록 바꿨다.

운영 메종의 안전·건강 이상 보고, 계약 검토·변경, 입고·공정·완제품 검사 양식을 320px에서 직접 열어 검수했다. 확인한 입력칸 모서리는 10px이며 화면 밖 가로 넘침이 없었다. 긴 업무 표는 내부에서 스크롤된다. 추가로 취소 버튼의 너비 약 40.48px와 구어체 안내를 발견했으며 후속 수정 대상이다. 캡처는 `tmp/qd-phase95-safety-new-320.png`, `tmp/qd-phase95-contract-new-320.png`, `tmp/qd-phase96-inspection-new-320.png`다. 저장·등록·판정·업무 데이터 수정은 실행하지 않았고 화면 크기를 복원했다.

현재 미분류는 아뜰리에 580건, 메종 626건, 카르넷 0건으로 총 1,206건이다. 전체 릴리스는 아직 통과하지 않았다. 현재 메종 운영 커밋은 `1e27ab26c9900690a1013d0f4b5bcb541341a7c4`다. 이번 검수 기록 수정은 제품 UI 변경이나 추가 운영 배포가 아니다. 다른 작업의 `lib/app-version.ts`와 미검토 파일을 보존했다. 계정 사용량 확인값은 47%다.
