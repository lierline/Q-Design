# 공통 부품 전달 규칙과 운영 모바일 확인

진행률 링의 색상·선 두께, 펼침 애니메이션의 시간·스타일, 아이콘 버튼·상자·알림·모달 등의 스타일과 폭을 실제 TypeScript 심볼로 추적했다. 인자 전달 기록은 40개에서 55개로 늘었다. 각 인자의 기본값, 실제 JSX 사용처, 원래 인자 지문과 다른 참조를 별도로 보존한다. 미해결 펼침 인자·미수록 값·다른 호출 참조는 없다. 전달 경로를 확인한 사실로 호출자의 임의 스타일을 승인하지 않는다.

같은 진행률 링의 크기와 선 두께를 동시에 추적할 때 한 심볼의 인자 기록이 다른 인자 기록을 덮어쓰지 않도록 검사를 보강했다. 두 기록에 실제 사용처 2개가 모두 남아야 한다. 전체 판정 53,986개와 제품 소스를 다시 대조해 정확한 사용처 8개만 미분류에서 전달 규칙 검증으로 이동했다. 나머지 전체 기록과 원문은 그대로다. 근거는 `reviews/atelier-renderer-leaves-ledger-migration.json`이다. 아뜰리에 미분류는 859개에서 851개로 줄었으며 메종·카르넷은 0개다.

실제 함수 선언을 격리해 진행률 링의 중앙 크기·선 두께를 바꾸고 결과를 확인했다. 중앙 설정 변경이 원의 중심·반경·선 두께에 반영되고 화면에서 직접 지정한 크기·색상은 유지된다. 업무 진행률은 0~100 범위로 제한되며 중앙 크기를 바꿔도 업무 수치를 바꾸지 않는다. 펼침의 중앙 열림·닫힘 시간도 실제 렌더러에 반영되며 직접 지정한 시간 0ms·148ms와 닫힌 접근 제한을 유지한다. 초기 서버 렌더링 검사이며 실제 기기의 애니메이션 완료나 동작 줄이기 설정까지 승인하지 않는다. 관련 전달 검사 10개와 실제 기본값 전파 검사 2개가 통과했다.

운영 아뜰리에의 공개 로그인 자산 21개를 읽고 로딩 높이 14·12 참조가 배포된 번들에 있는 것을 확인했다. `reviews/atelier-skeleton-public-assets.json`에 정적 자산 지문을 기록했다. 로그인 뒤 390px 설정 화면에서 메뉴·알림 버튼과 입력창의 실제 모서리가 10px이며 가로 넘침이 없음을 확인했다. 이 계정에는 플랫폼 운영자 화면이 표시되므로 조직용 구독 버튼까지 확인했다고 확대하지 않는다.

운영 메종의 390px 매장 판매 등록 양식도 실제로 확인했다. 메뉴·알림 버튼과 날짜·일반 입력창의 모서리는 10px이며 가로 넘침이 없다. 주문 표는 내부 가로 스크롤을 사용한다. 다만 상단 뒤로가기 링크는 약 16px 높이로 확인돼 공통 뒤로가기 규칙으로 옮길 수정 대상으로 남긴다. 이 단계에서 업무 자료를 저장하거나 계정 권한을 변경하지 않았다.

세 제품 전체 릴리스 검사가 통과했으며 생성 사본 111곳과 앱 아이콘 32개가 정본과 일치한다. iOS는 제외하며 Android 실제 설치는 연결 기기가 없어 아직 검증하지 못했다. 중앙 정본 변경이 사용자 화면에 반영되려면 생성·동기화·제품 빌드와 운영 배포가 모두 필요하다.
