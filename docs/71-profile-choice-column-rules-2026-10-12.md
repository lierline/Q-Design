# 제품 프로필 선택 항목의 중앙 열 규칙 연결

아뜰리에 `ProductProfileWizard`의 선택 그룹 9곳에서 직접 지정하던 2·3·4열을 `QDPresentation.rendererInputs.gridColumns`로 연결했다. 기존 중앙 값과 같은 값을 사용하므로 항목, 설명, 선택 상태, 선택 해제 동작과 현재 배치는 유지한다. 제품 변경 커밋은 `498584bb`이며 이 파일의 9개 표현식만 변경했다.

## 규칙과 검증 범위

- 중앙 런타임 정본과 제품 사본을 대조하고, 실제 로컬 `RadioGrid`로 전달되는 9개 입력의 심볼을 확인했다. 이름이 같지만 다른 변수인 경우는 승인하지 않는다.
- 원래 파일 전체와 수정 파일 전체를 대조했다. 선택 항목, 콜백, 렌더러 원문 등 다른 부분은 동일하다. 임의 추가 코드, 잘못된 열, 이전 숫자 입력 복원, 선택 해제 동작 변경을 거부하는 시험을 포함한다.
- 실제 렌더러와 실제 선택 항목을 격리한 브라우저에서 밝은·어두운 테마 및 375/390/768/1280px를 검사했다. 기존 격리 너비 8개 사례에 운영 카드의 내부 여백을 재현한 8개 사례를 추가했다. 16개 사례의 9개 그룹이 이전 배치와 같았다. 중앙 열 값을 1로 바꾸면 모든 그룹에 전파되고 선택 상태·문구·모서리는 유지되며 내부 넘침도 없었다. 네트워크와 제품 저장 기능은 실행하지 않았다. 기존 배치의 내부 넘침은 별도 기록하며 해결 판정으로 바꾸지 않는다.
- 이전 보고서 6개의 인자 4곳, 선언 근거 34곳, 반복 보관된 호출자·선언 지문 28곳을 다시 대조했다. 호출자 JSX 전체, 실제 인자와 근거 줄이 바뀌지 않았을 때만 새 파일 지문으로 갱신한다. 갱신의 정확한 역변환으로 이전 보고서 전체 지문도 확인한다.
- 전체 판정 53,991개를 순서대로 대조했다. 중복 기록도 보존하며 정확히 9개 열 입력만 미분류에서 중앙 참조로 변경됐다. 나머지 53,982개의 판정과 인자는 그대로다.

현재 아뜰리에 미분류는 813건이다. 실제 스타일로 확인된 후보는 513건이며, 이 수가 모두 하드코딩 오류라는 의미는 아니다. 메종·카르넷의 기존 미분류 0건도 모든 기능·모든 화면의 재검수 완료를 의미하지 않는다.

## 실제 운영 화면

사용자가 다시 로그인한 세션에서 R&D 목록, 기존 프로젝트 상세, 제품 정보, 제품 프로필 편집 양식을 열어 관찰했다. 입력과 선택은 바꾸거나 저장하지 않았다. 모바일 390px의 9개 선택 그룹 모서리는 모두 10px이고 간격은 8px다. 데스크톱 1280px에서는 내부 너비 880px의 9개 그룹이 모두 넘침 없이 같은 열 수를 유지했다. 검수 후 저장하지 않고 양식을 닫았다.

운영 양식의 내부 너비는 278px다. 멸균 및 작동 원리 그룹에서 긴 영문 설명의 최소 너비 때문에 각각 약 18px와 25px의 내부 넘침을 확인했다. 페이지 전체가 넘치지 않아 격리 브라우저의 페이지 넘침 검사만으로는 드러나지 않았다. 추가한 로컬 카드 사례도 390px에서 같은 두 그룹의 내부 넘침을 드러내며, 375px에서는 페이지 너비도 넘었다. 이번 열 입력 연결은 원래 배치를 보존하므로 이 문제를 해결했다고 처리하지 않는다. 다음 수정은 중앙 그리드의 최소 열 너비와 긴 문구 줄바꿈 규칙을 실제 카드 내부 너비로 검증해야 한다.

관찰 기록은 `reviews/phase71-operating-profile-before.json`, 브라우저 근거는 `reviews/profile-grid-browser.json`이다. 실제 이미지는 같은 접두사의 PNG로 로컬 보관한다.

다음 수정 후보는 이미 가져오는 중앙 `foldGrid`와 `QDPresentation.visual.choiceMinColumn[110]`을 사용하는 반응형 선택 그룹이다. 운영 카드에서는 3·4열을 2열로 접고 데스크톱에서는 원래 열 수를 유지하는지 실제 문구로 먼저 검사해야 한다. 아직 제품에 적용하거나 완료 판정하지 않았다. 위저드 안내의 `공공 DB 에서`(제품 파일 570행)도 `공공 DB에서`로 정돈할 후보이며 이번 소스 변경 범위에는 포함하지 않았다.

## 릴리스 상태와 남은 범위

제품 운영 빌드와 선택 항목·기존 인자 전달 시험 7개는 통과했다. 최종 세 제품 릴리스 검사도 종료 코드 0으로 통과했다. 정본과 제품 사본이 일치하며 앱 아이콘 32개도 정본과 일치한다. 문자·변경 공백 검사도 통과했다. 이후 브라우저의 내부 너비 측정만 추가해 16개 사례의 이전 배치 일치와 중앙 값 전파를 다시 검사했다. 제품과 판정 인자는 추가 변경하지 않았다. 검사 로그는 로컬 `D:/Claude/tmp/qd-phase71-release-complete.log` 및 `D:/Claude/tmp/qd-phase71-card-browser.log`에 보관한다. 정상 푸시 훅의 타입 검사·단위 테스트 4,667개·린트 오류 0건도 통과했다. 기존 린트 경고 1,573개, 예정된 실패 1개와 건너뛴 시험 3개는 별도 상태다. 운영 배포 지문은 완료 후 기록한다.

큐 디자인 변경은 생성·사본 동기화·제품 빌드·운영 배포를 거쳐 반영한다. 중앙 열 입력의 변경 전파는 실제 렌더러로 검사했지만 파일 저장만으로 운영이 즉시 바뀌지는 않는다. 이전 540개 대상과 2,330개 이미지 전체를 이번 단계에서 다시 촬영하지 않았다. Android 설치 기기 검증은 남아 있으며 iOS는 사용자 요청에 따라 제외한다.
