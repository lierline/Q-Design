# 메종 새로고침 표시의 공통 디자인 연결

아뜰리에의 기존 큐 디자인 원본에서 새로고침 표시의 대기 위치, 투명도 계산 거리, 회전 비율, 아이콘 크기와 상단 안전 영역을 추출해 메종에 연결했다. 새로운 숫자를 별도 원본으로 복제하지 않았다. `dist/q-design.pull.ts`와 메종 `lib/design/q-design-pull.ts`는 생성물이며 원본 지문과 동기화 검사를 받는다.

메종 표시 컴포넌트의 다섯 표현식을 바꾸고, 제스처 판정·이벤트·새로고침 실행은 유지했다. 기존 상태 40개 조합의 전체 마크업이 변경 전후 동일했다. 원본 값을 변경한 검수 조합에서는 위치·투명도·회전·아이콘·상단 영역이 함께 바뀌었다. 이는 컴포넌트 검사이며 실제 Android 설치나 기기 제스처 검수 완료를 의미하지 않는다.

새로고침 관련 미분류 9건을 검수했다. 터치 좌표 2건은 입력 좌표로 구분하고, 나머지 7건은 검증된 중앙 디자인 참조로 연결했다. 다른 항목의 판정은 유지했다. 기존 검수 도구의 변경에 영향을 받은 근거 151건은 정확한 도구 본문 전환을 검증해 재연결했다. 전체 보고서 역변환은 다른 판정 수정과 빌린 근거를 거부한다.

기존 문구·설비 표와 새로고침 검사 13개, 추가 전체 보고서 변조 거부 검사, 메종 전체 타입 검사와 정상 커밋 훅이 통과했다. 아이콘 검사는 27개 파일·69개 사용 위치에서 통과했다. 컴포넌트 등록부는 메종 공개 렌더러 95/95개와 중앙 복사본 25개를 확인했다. 등록부 수는 모든 업무 화면의 시각적 검수 완료를 뜻하지 않는다.

제품 커밋은 `1e27ab26c9900690a1013d0f4b5bcb541341a7c4`다. 운영 배포 `dpl_AeR7fxBs4iNzHTUpNsEjLve8VKvP`의 READY, 정확한 SHA와 `maison.medqraft.app` 연결을 확인했다.
