# 업무 데이터 인자의 추가 분류

높이·너비 후보로 잡힌 지역 변수 `h`, `w` 14개를 실제 선언과 소비 위치까지 확인했다. 허가 정보와 제품 프로파일 제안, 결재 이력, 진단 응답 헤더, 알림 이력, Markdown 제목 분석, 업무 권한, 등급·준수 점수·모델 가중치와 비용 추정에 쓰이는 데이터였다. 각각의 변수만 업무 데이터로 분류했다.

`reviews/atelier-domain-binding-review.json`은 전체 파일 지문, 정확한 인자 지문, 구문 트리 위치, 소비 함수와 참조 위치에 연결한다. TypeScript의 실제 변수 심벌을 비교하므로 같은 이름을 가진 다른 변수나 속성은 소비 근거에 포함하지 않는다. 다른 위치, 다른 표현, 소스 변경과 시각 속성에는 기존 판정을 적용할 수 없다. 제품 실행 코드, 점수·권한·암호화 정책과 입력·표시 내용은 변경하지 않았다. 업무 함수, 외부 요청과 모델 호출도 실행하지 않았다.

큐 디자인 커밋 `444084b`의 전체 판정 보고서와 대조했다. 미분류에서 업무 데이터로 바뀐 해당 14개 판정만 달라졌고, 나머지 판정, 모든 인자·소스 지문과 보고서 메타데이터는 동일했다. 대조 기록은 `reviews/atelier-domain-binding-decision-migration.json`이다. 회귀 검사 2개는 실제 변수 해석과 변경·위치·인자·참조 변조의 거부를 확인한다.

회귀 검사 2개와 최종 `extract-all --check --only=Q-Atelier,Q-Works,Q-Forge`가 종료 코드 0으로 통과했다. 원본 사본 111개, 제품 아이콘 32개 지문, 금지 문자와 변경 공백 검사도 통과했다. 58번 기록의 실제 브라우저 검사와 메종 운영 배포는 유지한다. 새 업무 화면이나 앱 설치 기기를 추가 검수한 것으로 세지 않는다.

아뜰리에 미분류는 891개에서 877개로 줄었다. 메종·카르넷은 계속 0개다. 업무 데이터 분류를 시각 수정이나 디자인 중앙화 완료로 세지 않는다. 정본 구현 29개 파일, 부속 렌더러 5개, 등록 주소 540개와 업무 화면 이미지 판정 2,330개 집계는 유지한다. 실행 소스 변경이 없으므로 직전 운영 배포와 앱 산출물을 유지한다.

실제 스타일 미분류, 추가 화면 상태와 iOS·설치 기기·서명 검토는 계속 남아 있다. 큐 디자인 수정은 생성·동기화, 검사, 빌드와 배포를 거쳐 시스템에 반영한다. 전체 시스템의 모든 인자가 이미 중앙 제어된 상태라고 인증하지 않는다.
