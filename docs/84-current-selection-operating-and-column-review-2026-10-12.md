# 운영 선택 부품 확인과 상대 열 인자 검수

메종 d5a9c06a 운영의 /inspections/new 화면에서 실제 선택 부품을 확인했다. 6개 라디오 모두 qd-radio를 사용하며 표시 크기는 16×16px, 강조색은 rgb(184, 147, 90), 라벨 글자 크기는 13px, 높이는 44px, 모서리는 10px이다. 1280px 화면의 문서 폭 초과는 없었다. 기존 기본 선택 상태와 선택지 이름은 유지됐다. 합격 판정 개수 (Ac), 샘플링 안내, 미판정 항목 일괄 적합 판정 문구도 운영 화면에 표시됐다. 등록이나 판정은 실행하지 않았다.

메종의 cols 후보 23건 중 명시적 ChoiceBoxes·ChoiceGrid 호출 7건을 검증했다. 실제 TypeScript 심볼이 정본 부품을 가리키는지 확인하고, 1~12열의 허용된 이름만 실제 Tailwind로 생성해 repeat(n, minmax(0, 1fr)) 출력과 대조했다. 임의 치수, 임의 선택자, 다른 유틸리티, 인쇄 표의 비율 배열은 승인하지 않는다. 화면 폭에 따른 접힘은 정본 선택 부품이 담당한다. 변경된 소스나 소비 부품은 기존 지문을 승계하지 않는다.

새 소비자 검증과 부정 테스트 2개를 통과했다. 메종 미분류는 984건에서 977건으로 줄었고, 아뜰리에 580건과 카르넷 0건을 합하면 1,557건이다. 전체 소스 감사 완료나 전체 화면 시각 검수 완료를 의미하지 않는다.

공통 표시 크기 변경과 이전 문구·선택 열 검증을 중첩할 때, 이미 되돌린 과거 기준에 새 변환을 다시 적용하는 검사 충돌을 수정했다. 이미 검증된 전체 보고서 지문과 정확히 일치할 때만 해당 단계를 생략한다. 다른 값·결정·소스 변경은 계속 거부한다. 기존 아뜰리에 선택 열 테스트 2개를 다시 통과했다.

최신 전체 릴리스 실행은 D:/Claude/tmp/qd-phase84-release-current.log이다. 전체 릴리스가 통과한 것으로 보고하지 않는다. 앞선 실행에서 앱 오프라인 산출물의 낡은 CSS와 중첩 지문 충돌을 발견하고 수정했다. 아이콘 32/32 대조는 유지됐다.

Android 오프라인 자원은 세 앱에 로컬 커밋했다. 아뜰리에 앱은 원격 저장소에 푸시했다. 메종·카르넷 앱은 origin이 없어 원격 주소를 요청한 상태다. 앱 설치는 실행하지 않았다.
