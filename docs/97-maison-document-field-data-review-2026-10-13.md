# 메종 문서 채움 데이터 검수

품질 시스템 변경 요청·검토·보고 서식의 미분류 스프레드 19건을 실제 문서 내용으로 구분했다. 각 위치는 `ModuleFormResult` 반환값의 `values` 안에 있으며, TypeScript가 해석한 로컬 함수 `numbered` 17곳과 `parentValues` 2곳에서 문자열 필드를 받는다. 조립 경로와 실제 `doc.render` 호출까지 검수했다.

번호가 붙는 필드 접두어와 부모 기록의 여섯 필드를 각각 확인했다. 호출부·출력 경로·타입 설정의 전체 소스 지문을 고정했다. 같은 이름의 다른 함수, 스타일 객체, 다른 호출 위치와 변경된 소스는 근거를 재사용할 수 없다. 다른 스프레드나 시각 요소를 파일 이름으로 승인하지 않았다.

실제 번호 생성 함수로 줄바꿈·공백·특수문자와 항목 순서를 확인했다. 전체 보고서 역변환은 19건 외의 변경과 빌린 근거를 거부한다. 기존 문서 이미지·새로고침·생산 문구·업무 문구 검사를 포함한 17개 검사가 통과했다. 데이터베이스 조회·저장이나 문서 다운로드를 실행하지 않았다.

메종 미분류는 626건에서 607건으로 줄었다. 아뜰리에 580건, 카르넷 0건과 합하면 총 1,187건이다. 디자인 값의 추가 중앙화나 운영 제품 변경은 이번 판정에서 실행하지 않았다. 실제 제품은 기존 커밋 `1e27ab26c9900690a1013d0f4b5bcb541341a7c4`를 유지한다. 전체 릴리스는 미분류 항목 때문에 여전히 통과하지 않는다.
