# 메종 문서 내용 필드 검수

문서 채움 모듈의 미분류 후보 19건 중 13건을 문서 문자열·표 내용·체크 항목 이름으로 확인했다. 외관 분류명, 시정 조치 내용, 회의 참석자·검토자 직급 표기, 계측기·교정 정보, 점검 결과 이름과 계약·심사·공통 문서 문자열 조립이다. 같은 이름의 CSS appearance·content·position·scale 값으로 간주하지 않았다.

전체 문서 채움 모듈과 실제 doc.render 호출, 직급 표기·점검 결과 공급 파일 및 체크 항목 전처리 파일을 고정했다. 각 위치의 문자열 타입이나 문자열 인덱스 자료형, 문서 반환 역할과 실제 소비 경로를 확인했다. 체크 결과 메타데이터의 tone 필드는 해당 함수에서 사용하지 않으며 anchor와 checked의 이름만 넘긴다.

나머지 6건은 도면 축척, 계약 검토 직급과 교육 기록의 네 조립 인자다. 전체 프로젝트 타입 설정으로 확인해도 조회 결과가 any로 해석되어 이번 근거로 승인하지 않았다. 이 인자들은 미분류로 유지했다. 실제 업무 기능이나 조회 자료형을 변경하지 않았다.

실제 시정 조치 문자열 생성 함수와 워드 체크 항목 전처리 함수를 격리해 검사했다. 원문의 줄바꿈·앞뒤 공백은 유지되고 문자열이 아닌 내용은 빈 문자열이 된다. 점검 결과 이름만 체크하고 다른 항목은 유지한다. 다른 자료·판정·근거 변경은 전체 자료 역변환에서 거부한다. 문서 내용·회의록·준비 기록·공통 업무 화면·문서 이미지·기존 문서 필드를 포함한 17개 검사가 최종 실행에서 모두 통과했다.

메종 미분류는 571건에서 558건으로 줄었다. 아뜰리에 573건, 카르넷 0건과 합하면 총 1,131건이다. 메종의 엄격 검사는 잔여 미분류 때문에 실패한다. 이번 판정은 화면 소스를 변경하지 않으므로 새 운영 배포는 없다. 전체 릴리스와 모든 화면 연결 완료를 주장하지 않는다.
