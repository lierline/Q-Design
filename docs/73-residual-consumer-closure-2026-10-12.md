# 남은 인자의 실제 소비자 추적

811건 중 75건을 실제 소비자와 대조해 분류했다. 남은 미분류는 736건이다. 이번 단계는 판정 근거를 보강한 작업이며 제품의 화면 코드와 운영 배포는 변경하지 않았다.

## 판정 범위

47건은 변경되지 않는 지역 객체와 지역 함수의 반환 객체가 실제 JSX `style` 또는 `itemStyle`에 전달되는 연결이다. 연결을 찾았다는 이유로 객체 전체를 승인하지 않는다. 각 속성 값은 별도로 구조적 키워드·초기화 값임을 증명해야 한다. 임의 크기·색상·함수 인자는 미분류로 유지한다. 쓰기, 별칭을 통한 변경, 외부 함수로의 객체·함수 전달, 같은 이름의 다른 심볼과 알 수 없는 함수는 연결 근거가 되지 않는다.

28건은 사람이 사용처를 확인한 업무 값이다. 한국어 필터 명칭, 계정·변경 요청 수, 목록 조건, 실시간 수신 조건, 댓글·CAPA 본문, 경영검토 입력 분류와 HTTP 요청 헤더가 해당한다. 정확한 파일 전체 지문, 인자 지문과 AST 소비자를 고정한다. `filter`, `content`, `all`, `h`처럼 CSS와 같은 이름이라는 이유로 다른 사용처를 면제하지 않는다. 실시간 수신 조건의 의미는 [Supabase 공식 문서](https://supabase.com/docs/guides/realtime/postgres-changes)의 행 필터 설명과도 대조했다.

전체 53,991개 기록에서 기존 미분류 75개만 판정·사유·근거를 변경했다. 나머지 53,916개 기록은 모든 필드와 순서가 같다. 제품 파일, 인자 값·지문, 기존 판정과 보고서 메타데이터는 변경되지 않았다. `atelier-residual-ledger`는 실제 소스를 다시 분석해 이 차이를 검증하고 과거 검사의 입력을 정확한 이전 보고서로 되돌린다.

과거 프로필 검사는 해당 과거 커밋의 감사 목록으로 검증하도록 수정했다. 이후 추가한 보고서를 과거 목록에 넣어 존재하지 않는 파일을 읽던 오류를 바로잡았다. 신규 보고서는 현재 소스를 대상으로 별도 릴리스 검사에 포함하며 과거 검증을 생략하지 않는다.

## 검증과 다음 범위

별칭·지역 함수 반환 연결의 긍정·부정 사례, 업무 값의 변경 지문·잘못된 판정·범위 밖 인자, 전체 보고서의 관계없는 변경을 검사했다. 관련 시험 48개와 두 과거 소스 변환의 전체 보고서 검증이 통과했다. 전체 세 제품 릴리스 검사는 종료 코드 0으로 통과했고 앱 아이콘 32개도 모두 일치했다. 실행 로그는 `D:/Claude/tmp/qd-phase73-final-tests.log`, `qd-phase73-historical.log`, `qd-phase73-responsive-historical.log`와 `qd-phase73-release.log`에 보관한다.

남은 인자는 실제 디자인 값과 추가 연결 증명이 필요한 값이 섞여 있다. 다음 범위는 지역 함수 반환에서 선택한 공통 색상, 전달되는 공통 부품 인자, 툴팁과 표의 실제 측정 좌표, 아이콘과 독립 문서의 표시 인자다. 업무 값 분류는 화면 디자인 수정이나 중앙 연결 완료를 뜻하지 않는다. `전부`와 `전체`의 화면 문구 차이도 후속 중앙 문구 규칙에서 확인한다.

계정 사용량 50%를 상한으로 남은 감사와 필요한 제품 수정을 계속 진행한다. Android 실제 설치 검사는 남아 있으며 iOS는 사용자 요청에 따라 제외한다.
