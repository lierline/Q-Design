# 네이티브 시작 색상과 안내 메시지 규칙

세 Android 앱의 시작 화면·아이콘 바탕·보조 글자 색상 6개씩과 기존 아뜰리에 iOS의 시작 색상·안내 메시지 색상·불투명도를 `patterns/native/palette.json`에 연결했다. 공용 바탕은 기존 검증된 웹 팔레트를 계속 따른다. 제품별 시작 강조색·빛·어두운 바탕 보조 글자색의 기존 차이는 명시적인 제품 규칙으로 유지한다. 로고·앱 아이콘 그림·글꼴 파일과 플랫폼 제공 조작부는 이 규칙의 소유 범위가 아니다.

Android 기본 색상 파일 3개에서 색상 18개를 생성 리소스 참조로 바꿨다. 원래 선언값과 중앙 규칙의 값은 모두 같다. iOS `Palette`의 색상 선언 4개도 생성값을 참조한다. iOS 시작 화면은 빛 색상의 RGB 채널 3개를 생성값에서 읽고, 안내 메시지는 면·글자 색과 불투명도를 참조한다. 빛의 RGB 채널, 안내 면·글자 색과 불투명도 0.94가 원래 값과 일치함을 대조했다. 나머지 전체 파일 문자는 동일하다.

범위와 변경 근거는 `reviews/native-palette-consumer-migration.json`과 `reviews/native-palette-view-migration.json`에 저장했다. 알 수 없는 제품·역할, 누락된 값, 잘못된 색 형식과 불투명도를 거부한다. 독립 색상, 중복 선언, 주석 속 참조만으로는 소비 검사를 통과하지 못한다. 각 제품 강조색을 다르게 바꾸고 공용 보조색·안내 색·불투명도를 바꾼 임시 작업 공간에서 Android·iOS 산출물에 각각 전파됨을 확인했다. 회귀 검사 12개가 통과했고 전체 릴리스 검사에 포함했다.

기존 SDK와 오프라인 캐시로 세 Android 앱의 릴리스 APK·AAB를 다시 빌드하고 릴트를 실행했다. 모두 성공했다. 실제 APK에서 공용 바탕과 시작 색상 24개, 시작 색상 참조 18개, 줄바꿈 전략과 낮·밤 바탕 참조를 대조했다. APK·AAB 6개의 포함 오프라인 자산도 정본과 일치했다. 린트 오류는 0개이며 앱별 기존 경고 9개를 유지한다. 기록은 `reviews/native-release-build-results.json`이다. AAB의 컴파일 색상을 별도로 해독한 검사나 설치 기기 시각 검사로 확대하지 않는다.

최종 `extract-all --check --only=Q-Atelier,Q-Works,Q-Forge`가 종료 코드 0으로 통과했다. 원본 사본 111개와 아이콘 32개가 정본과 일치했고, 금지 문자·변경 공백 검사도 통과했다. 웹 실행 소스와 업무 화면 집계는 변경하지 않았다. 웹 미분류는 아뜰리에 867개, 메종·카르넷 0개다. Android 시작 화면 Java 정본과 구문 트리 범위는 그대로 유지한다.

Android 소스의 로컬 커밋은 아뜰리에 `064e2eb`, 메종 `d530978`, 카르넷 `43e7886`이며 iOS는 `62253fb`다. 앱 저장소에는 푸시하지 않았다. 산출물은 서명 전이며 기존 서명 배포 파일은 변경하지 않았다. 실제 기기·서명·배포와 iOS 컴파일은 남아 있다. iOS 변경은 Windows에서 소스·생성·참조·값을 검증한 범위이며 Mac에서 빌드·설치 검증을 해야 한다. 중앙 규칙 변경은 생성·동기화와 해당 제품 빌드·서명·배포를 거쳐 설치 앱에 반영한다.
