# 로그인 소셜 링크의 터치 영역 정돈

운영 아뜰리에 로그인 하단의 소셜 링크는 보이는 크기가 32px였다. 기존 터치 전용 CSS는 클릭 영역을 가로 44px, 세로 64px로 넓혔지만, 링크 사이 간격이 8px라 인접 영역이 4px 겹쳤다. 이 차이는 화면 폭만 좁힌 브라우저에서는 드러나지 않고 실제 coarse 포인터 조건에서 확인됐다.

## 변경과 중앙 규칙

큐 디자인의 `patterns/foundation/atelier.css`에 소셜 링크 규칙을 추가했다. 모바일 폭 또는 터치 포인터에서는 최소 너비·높이가 공통 `--qd-control-height`를 읽는다. 현재는 44px다. 소셜 링크의 터치 가상 요소에는 중복 여백 확대를 적용하지 않는다. 버튼 간격과 모서리, 아이콘 크기는 기존 중앙 값을 유지한다.

기존 CSS의 모든 바이트를 유지하고 끝에 규칙만 추가했다. 생성된 기반 CSS와 아뜰리에 사본까지 동기화했다. 제품의 JSX, 링크 목적지, 로그인 동작, 아이콘 모양은 변경하지 않았다.

## 검증

- 실제 `SocialLinks` JSX와 배포 사본에 일치하는 실제 Globe 아이콘을 로컬 브라우저에서 렌더링했다. 모든 네트워크 요청은 차단했다.
- 밝은·어두운 테마, 폭 375/390/767/768/1280px, fine/coarse 포인터를 조합한 20개 사례를 변경 전후 각각 검사했다.
- 변경 전에는 10개 터치 사례에서 4px 겹침이 있었다. 변경 후 20개 모두 겹침이 0이다. 모바일 또는 터치에서는 44×44, 데스크톱 fine 포인터에서는 기존 32×32다.
- 중앙 높이 44→48, 모서리 10→6 변경이 전파되고 클릭 영역도 겹치지 않는다. 다른 SVG 도형 인자는 그대로다.
- 기존 검수 보고서 6개에서 근거 458곳을 재확인했다. 236개 중앙 CSS 참조와 222개 제품 사본 참조다. 색상 전달 경로가 반복 보관하는 같은 선언의 근거 11곳도 정확한 JSON 위치별로 재확인했다. 소비자 전체 원문과 이전 선언 줄은 그대로이며, 검수 판정·인자·문맥은 바꾸지 않았다.
- 이전 스켈레톤·토스트·양식 라벨 검사는 이번 변경의 정확한 역변환으로 원래 지문을 검사한다. 새 변경과 현재 근거도 별도로 검사한다.
- 아뜰리에 운영 빌드, 타입 검사, 단위 테스트 4,667개, 린트 오류 0건으로 통과했다. 기존 린트 경고 1,573개, 예정된 실패 1개와 건너뛴 시험 3개는 별도 상태다.
- 세 제품 전체 릴리스 검사 통과. 원본 지도 111곳과 생성 사본이 일치하고 앱 아이콘 32개도 정본과 일치한다. 문자·변경 공백 검사도 통과했다.
- 아뜰리에 커밋 `1c0a3f8e`의 운영 배포 `dpl_zTDgwDLdEaGmtLTXYEfsrbqCQ4nv`가 READY이며 세 운영 도메인에 연결됐다. 상세 근거는 `reviews/phase70-operating-deployment.json`이다.
- 공식 운영 로그인 화면에서 변경 전 32px와 변경 후 44×44px를 폭 390px로 직접 대조했다. 링크 간격 8px, 모서리 10px, 아이콘 16px를 유지하며 가로 넘침은 없다. 실제 터치 포인터의 가상 요소와 중앙 값 변형은 위 로컬 브라우저 검사로 구분한다.
- 로그인된 운영 설정 화면을 새 버전으로 다시 열었다. 메뉴·뒤로·알림 버튼과 입력칸 10개의 높이는 44px, 모서리는 10px이며 가로 넘침이 없다. 입력값과 계정·정책은 수정하지 않았다. 측정은 `reviews/phase70-operating-settings.json`과 `reviews/phase70-operating-social.json`, 실제 이미지는 같은 접두사의 PNG에 로컬 보관했다.

현재 미분류는 아뜰리에 822건, 메종 0건, 카르넷 0건이다. 새 중앙 소셜 링크 선택자에 연결된 1건만 이번에 추가로 해결했다. 전체 시스템의 미분류가 모두 해소됐다는 의미는 아니다.

이번 실제 화면 재검수는 로그인과 설정에 한정된다. 기존 540개 대상과 2,330개 이미지 전체를 이번에 다시 촬영하지 않았다. 다음 중앙 연결 후보는 ProductProfileWizard의 RadioGrid 열 수 9곳(2/3/4열)과 기본 스켈레톤 너비 3곳(100%, 제목 38%, 마지막 본문 55%)이다. 이 값들은 서로 다른 화면 역할을 보존하면서 규칙에 연결해야 하며, 이번 단계에서 변경하거나 검수 완료로 처리하지 않았다. iOS는 사용자 요청으로 제외하며 Android 설치 기기 검증은 아직 남아 있다.

큐 디자인의 규칙을 변경한 뒤 생성·동기화·제품 빌드·배포를 거쳐 운영에 반영한다. 파일 저장만으로 운영 제품이 즉시 바뀌지는 않는다.
