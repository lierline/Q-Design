# 메종 생산 준비 데이터와 문서 이미지 크기 별칭 검수

생산 준비 기록 조립 17건과 문서 이미지 크기 별칭 4건을 실제 타입·호출 경로로 판정했다. 메종 미분류는 607건에서 586건으로 줄었다. 아뜰리에 580건, 카르넷 0건과 합하면 1,166건이다.

생산 준비 17건은 준비 기록의 필드·행·그룹을 조립하고 실제 생산 등록 양식에서 materials와 prep_items로 전달한다. 생산 준비 모듈, 소비 양식, 검증 스키마와 저장 액션의 전체 소스를 고정했다. TypeScript로 각 위치의 자료형과 필드를 확인했다. 기존 생산 준비 검사 23개가 통과했다. 데이터베이스 저장은 실행하지 않았다.

문서 이미지 4건은 SIGN_BOX와 PHOTO_BOX의 너비·높이 별칭이다. 가져오기와 상수 선언을 해석해 큐 디자인의 승인 서명과 문서 사진 크기까지 확인했다. 기존 이미지 출력 경로·정본 사본·실제 XML 크기 계산 검사를 재사용해 독립적으로 검증했다. 새 이미지 크기를 승인하거나 제품 값을 바꾸지 않았다.

전체 판정 역변환은 이 21건만 이전 미분류 상태로 되돌린다. 다른 소스, 값, 판정, 개수 변경과 빌린 이미지 근거는 거부한다. 생산 준비와 이미지 별칭의 근거 자료는 생성 후 다시 동일하게 재현되는지 확인한다. 모든 과거 업무 화면 판정 검사는 이 역변환을 거쳐 기존 전체 자료와 비교한다.

관련 검사 묶음 16개 중 15개가 첫 실행에서 통과했다. 남은 하나는 과거 검사에서 최신 메종 잔여 개수를 그대로 비교한 문제였으며, 정확한 21건 역변환을 적용한 뒤 공통 업무 화면 검사 2개가 모두 통과했다. 개별 재실행을 포함해 16개 고유 검사 모두 통과했다. 같은 묶음의 전체 재실행을 수행했다고 주장하지 않는다. 정본 참조 검사에는 누락이 없고 금지 문자와 변경 파일 공백 검사도 통과했다.

이번 변경은 판정 도구와 근거 자료에 한정된다. 제품의 화면·업무 기능을 변경하지 않았으며 별도 운영 배포는 필요하지 않다. 전체 릴리스는 남은 미분류 때문에 통과하지 않는다. 전체 화면이 큐 디자인에 완전히 연결됐다고 주장하지 않는다.
