# 카르넷 홈 존칭 띄어쓰기 수정

홈 인사말의 사용자명과 존칭 사이 공백을 제거했다. 운영에서 표시된 `아침 인사드립니다, 개발 계정 님`은 `아침 인사드립니다, 개발 계정님`으로 수정했다. 사용자명 내부의 공백은 보존한다. 큐 디자인의 카르넷 문구 규칙에 해당 홈 위치의 조항을 추가하고 기존 문구 연결 자료에 정확한 새 위치를 등록했다.

전체 홈 소스는 배포 전 커밋 579120df7107af56c137f8aac8a56af87849ef91과 비교했다. 문구 한 곳만 변경됐으며 모든 완전한 스타일 인자는 동일하다. 전체 판정 역변환은 홈의 스타일 인자 108건에서 소스 지문만 복원하며 다른 값·판정·근거·파일 변경을 거부한다. 다른 제품과 기존 카르넷 문구 연결도 그대로 유지한다. 미래에 중앙 문구 조항을 바꾸면 이미 등록된 홈 위치가 다시 변경되는 것을 격리 검사했다.

관련 검사 11개 중 10개는 첫 실행에서 통과했다. 한 검사는 미분류 0건일 때 존재하지 않는 counts.unknown 필드를 확인한 문제였고, 항상 존재하는 unknownCount를 비교하도록 보정한 뒤 존칭 검사 3개가 모두 통과했다. 개별 재실행을 포함한 고유 검사 11개 모두 통과했다. 타입 검사와 문구 연결 검사, 카르넷의 엄격한 디자인 판정 검사도 통과했다. 새로운 화면 기능·계정·데이터베이스 변경은 없다.

카르넷 커밋 4ad802972c8af6352812b357e79172f50d0b02c5를 main에 푸시했다. 운영 배포 dpl_EamfYMGxeqgckVFzohVeiGLxE21H의 READY 상태와 carnet.medqraft.app 연결을 확인했다. 로그인된 운영 홈에서 수정된 제목과 Pretendard 글꼴을 실제 확인하고 `D:/Claude/tmp/qd-phase103-carnet-honorific-production.png`에 증거를 저장했다. 이 관찰은 전체 모바일 업무 화면 검수를 의미하지 않는다.

남은 미분류는 아뜰리에 573건, 메종 558건, 카르넷 0건으로 총 1,131건이다. 전체 릴리스는 아직 통과하지 않는다. 다른 화면의 사용자명 뒤 공백과 조사 앞 띄어쓰기는 추가 검수가 필요하다. Android 메종·카르넷 원격 작업과 iOS 검사는 이번 단계에서 실행하지 않았다.
