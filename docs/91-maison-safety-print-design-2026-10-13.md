# 메종 안전관리 인쇄 규칙 연결

건강 이상 발생 조치 기록지와 작업 환경 점검표의 디자인 값을 큐 디자인에 연결했다. 메종 미분류는 701건에서 653건으로 줄었으며, 두 서식 파일의 미분류는 각각 0건이다.

## 디자인 연결

기존 `qdPrint`에서 글자 크기, 행 높이, 표 간격, 고정 열 너비를 받는다. 새 중앙 파일 `patterns/foundation/maison-safety-print.ts`에서 월간 점검표의 일자 열 너비, 구역 열의 전체 비율, 미측정 사선을 정의한다. `sync-parts.mjs`가 제품의 `lib/design/q-design-safety-print.ts`로 지문이 포함된 사본을 배포한다.

24개 소스 위치를 변경했다. 긴 문구가 있는 세 칸의 기존 `wordBreak: break-word`를 표준 `overflowWrap: break-word`로 정리했다. 원본 서식의 제목·공장 표기·기록 필드·결재 인자·빈 행·날짜 행 생성은 유지했다.

중앙 규칙을 바꾼 뒤 동기화하고 제품을 다시 빌드하면 실제 두 서식에 반영된다. 글꼴·간격·행 높이·열 너비·사선 색상을 바꾸는 검수에서 기록 내용과 셀 수가 그대로 유지되는 것을 확인했다. 다른 화면을 모두 연결했다고 주장하지 않는다.

## 검증

- 실제 서식 8개 경우의 전체 렌더링은 의도한 세 줄바꿈 속성 외에 동일하다.
- 두 서식의 중앙 값 변경 전파와 데이터 보존을 확인했다.
- 정상 포맷 이후 단위 검사 5개가 통과했다. 다른 값·행 수·업무 필드·시각 값 우회는 기존 검수 근거를 재사용하지 못한다.
- 실제 Edge에서 390px·1280px, 밝음·어두움, 변경 전·후 총 16개 렌더의 셀 가로 넘침은 0이다. 제품 CSS와 글꼴 바이너리를 사용했다.
- 메종 전체 타입 검사, 정상 ESLint·Prettier 커밋 훅이 통과했다. 다른 메종 작업의 `lib/app-version.ts`는 포함하지 않았다.
- 검사·제조·문구·DB·안전관리의 통합 검사 24개가 통과했다. 커밋 훅 포맷 변경 후 24개 전체를 다시 통과시켰다.

로컬 합성 기록을 사용했고 업무 DB 작업은 실행하지 않았다. 물리 A4 지면을 유지하며 모바일 전체 지면 맞춤, 실운영 기록 내용, 실제 인쇄 페이지 분할을 통과했다고 주장하지 않는다.
