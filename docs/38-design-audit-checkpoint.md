# 세 제품 디자인 감사 중간 보고

2026-10-10. 사용자의 요청에 따라 이번 진행분의 수정과 검증을 마무리하고 중단한다. 전체 디자인 감사의 완료 보고는 아니다. 이전 경과는 37번 보고서에 보존한다.

## 이번에 완료한 수정

아뜰리에 변경 영향 평가의 선택 단추 10개에서 선택 전후 높이가 32px와 35px로 달라지는 현상을 실제 화면에서 확인했다. 두 개의 반복 렌더링 원본에 공통 `qd-choice` 규칙을 연결했다. 수정 후 실제 업무 화면에서 선택 여부와 무관하게 36px로 유지된다. 제품의 별도 치수를 추가하지 않고 큐 디자인의 기존 공통 규칙을 사용한다.

원본 컴포넌트를 사용하는 독립 브라우저 검사에서도 세 선택 상태와 두 입력 환경, 총 6개 조합을 확인했다. 일반 입력은 36px, 터치 입력 조건은 44px이며, 중앙 규칙을 40px와 48px로 변경하면 소비 컴포넌트에 반영된다. 이 검사는 실제 모바일 업무 화면 전체 검수를 대신하지 않는다.

아뜰리에 커밋은 `8f9c96d5`이다. 업무 동작을 보존하는 역변환 및 근거 검사 8개와 TypeScript 검사가 통과했다. 현재 남은 `tsconfig.build.json` 작업 변경은 기존 임시 검사 설정이며 이번 커밋에 포함하지 않았다. 푸시와 배포는 수행하지 않았다.

## 최종 자동 검사 결과

`node tools/extract-all.mjs --check --only=Q-Atelier,Q-Works,Q-Forge` 최종 실행이 종료 코드 0으로 통과했다. 여기서 Q-Works는 메종, Q-Forge 대상 경로는 카르넷이다. 소나르는 이번 범위에서 제외된다.

제품 앱 아이콘 32개가 동결된 정본 지문과 모두 일치한다. 정본 지문을 새 결과로 덮어 승인하지 않았다. 사용한 렌더러는 Chromium 151.0.7922.34, Playwright 1.62.1, sharp 0.34.5, libvips 8.17.3이다.

기초 디자인의 제품·테마·화면 폭 18개 조합과 편집기 적용, 초기화, 오프라인 검사도 통과했다. 편집기 검사는 실제 렌더링 완료를 기다리도록 보정했으며 치수 기준을 완화하지 않았다. 중앙 소스 사본 110개가 일치하고, 최신 커밋을 반영한 컴포넌트 목록도 갱신했다. 기존 검토 근거는 정확한 소스 역변환과 인자 대조 후 갱신했다.

자동 검사의 통과는 모든 업무 화면의 시각·상호작용 검수 완료를 뜻하지 않는다. 정적 참조가 발견되지 않은 아뜰리에 접근 시뮬레이터 사본 1곳은 동적 경로와 간접 연결을 추가 확인해야 한다.

## 실제 화면 검토 범위

이번 진행분에서 아뜰리에 변경 평가 양식과 상세 화면 16장, 메종 감사 및 CAPA 생성 양식 14장, 총 30장의 정확한 이미지에 검토 기록을 추가했다. 양식 제출이나 업무 데이터 저장은 하지 않았다.

| 제품 | 검토 대상 | 캡처된 대상 | 사용 가능한 화면 근거가 있는 대상 | 별도 확인된 경계 화면 | 검토한 이미지 / 전체 이미지 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 아뜰리에 | 201 | 200 | 156 | 1 | 598 / 661 |
| 메종 | 277 | 277 | 190 | 0 | 590 / 855 |
| 카르넷 | 62 | 62 | 60 | 2 | 295 / 295 |

대상은 역할별 경로와 검토 상태를 포함한다. 캡처나 이미지 검토 기록이 있어도 로딩 중 화면, 접근 경계, 부분 검토 등은 사용 가능한 화면 근거 수와 구분한다. 이 수치는 모든 테마, 반응형 크기, 권한, 펼친 상태, 오류 상태의 통과율이 아니다.

## 남은 작업

아뜰리에 디자인 인자 분류는 53,389개 기록 중 미분류 1,036개가 남아 있다. 메종과 카르넷의 현재 분류 미확정 수는 0이지만, 이것만으로 공통 규칙의 적용이나 화면 품질을 보증하지 않는다.

메종 감사 생성 화면의 `정기` 선택 단추는 실제 높이가 약 29.98px이며 공통 선택 상태 색상만 연결되고 기본 `qd-choice` 규칙이 빠져 있다. 같은 형태의 후보 25곳을 18개 파일에서 발견했다. 개별 치수 및 정사각형 단추 용도를 확인하기 전 일괄 수정하지 않았다. 이번에 메종 제품 코드를 수정하지 않았으며 이 목록은 다음 검토 대상으로 남긴다.

아뜰리에 `/onboarding` 1개 대상의 캡처, 나머지 미검토 이미지와 역할·테마·모바일·동적 상태 검수가 남아 있다. 이미 허용된 로컬 테스트 초대 1개 외에 추가 초대를 만들지 않았다. 가입, 비밀번호 입력, 계정 생성, 초대 사용, 외부 발송을 하지 않았다.
