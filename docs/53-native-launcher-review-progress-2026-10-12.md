# Android 시작 화면 정본 연결 검수 기록

세 Android 앱의 시작 화면 구현을 Q-Design 한 템플릿에 연결했다. 제품별 패키지명과 제품명만 치환하고 기존 표시와 동작을 보존했다. 이번 단계는 시작 화면 소스의 중앙 소유와 동기화 검사이며 설치 기기의 시각 인증은 아니다.

## 중앙 규칙과 실제 연결

정본은 `patterns/native/launch-view.java.tpl`이다. `tools/build-native-launcher.mjs`가 제품별 Java 파일과 `dist/q-design.native-launchers.json`을 생성한다. 전체 생성·동기화·검사 절차에도 연결했다. 검사에서는 템플릿으로 만든 전체 파일을 실제 세 앱 파일과 비교한다. 줄 끝 CRLF/LF만 정규화하고 그리기·시간·좌표·접근성·생명주기 코드를 생략하지 않는다.

채택 전 커밋 아뜰리에 `ce01b0a`, 메종 `1e5f836`, 카르넷 `82b5943`의 전체 시작 화면 소스와 생성 결과가 일치한다. 제품 소스 변경은 없으며 이 사실을 `reviews/native-launcher-adoption.json`에 보관했다. 과거 일치 기록은 이후 템플릿 변경이나 설치 화면의 승인이 아니다.

글자 크기, 공통 바탕색, 안내 문구 줄바꿈 전략은 기존 중앙 리소스를 사용한다. 템플릿의 그리기·배치·동작은 한 곳에서 바뀐다. 실행 중의 화면 크기·대기 상태·시스템 애니메이션 배율과 로고·글꼴 파일 내용은 따로 관리하는 입력이다. 제품별 시작 화면 사본에 독립 값을 추가하면 검사가 실패한다.

## 인자 목록과 변경 전파

JDK 컴파일러의 구문 트리를 사용해 세 실제 시작 화면의 리터럴, 변수 초기화, 호출·생성자 인자, 메서드 매개변수와 대입 값을 기록했다. 파싱만 수행하며 Android 코드나 주석 처리기를 실행하지 않는다. 제품별 428개, 합계 1,284개 표현이다. 중첩 표현이 겹치므로 독립 디자인 조절값 1,284개라는 뜻은 아니다.

전체 소스 일치로 정본 소유를 확인하고 각 표현의 실제 위치·원문·파일 지문을 저장한다. 매개변수는 플랫폼·렌더러 입력으로 구분한다. 다른 앱 클래스나 모든 Java 구문 종류를 이 목록의 검수 완료 범위로 포함하지 않는다.

회귀 검사 3개는 전체 실제 소스 일치, 미검토 제품·치환값 거부, 공통 템플릿 한 곳 수정의 세 사본 전파를 확인했다. 전파 검사는 별도의 임시 작업 공간에서 생성 전의 낡은 세 앱 사본이 실패하고 동기화한 뒤 모두 통과하는지 검증한다. 실제 앱의 시간이나 제품명은 변경하지 않았다.

## 검사 환경 문제와 조치

전체 재검사에서 Windows 격리 환경의 기본 브라우저 경로가 실제 설치 위치와 달라 정본 아이콘 렌더러가 실행되지 않았다. 이미 설치된 정본 Playwright 브라우저 경로를 명시하고 재검사했다. 아이콘 버전이나 지문을 변경하지 않았다.

실제 알림 타입의 오류 재현 검사도 메종에서 실패했다. TypeScript의 경로 처리에서 pnpm 연결 경로가 물리 경로로 풀리지 않아 React의 CSS 선언 의존성이 누락됐고, `skipLibCheck` 아래에서 일부 타입이 `any`로 해석됐다. 검사 도구의 컴파일러 호스트가 작동하는 Node 경로 API를 사용하도록 수정했다. 설치된 React가 사용하는 실제 `csstype` 선언의 프로그램 포함과 오류 주입의 실제 소스 교체도 반드시 확인한다. 제품 타입 설정을 완화하지 않았다.

세 실제 알림 어댑터의 타입 검사와 아뜰리에·메종의 과거 CSS 속성 오류 재현 검사가 모두 통과했다. 최종 `extract-all --check --only=Q-Atelier,Q-Works,Q-Forge`는 종료 코드 0으로 통과했다. 공통 컴포넌트 계약, 세 실제 시작 화면 정본과 구문 트리 목록, 문구·팔레트·동기화를 포함한다. Chromium 151.0.7922.34, Playwright 1.62.1, sharp 0.34.5, libvips 8.17.3의 기존 정본 조합으로 앱 아이콘 32개 지문이 모두 일치했다. 문서 금지 문자 검사와 변경 공백 검사도 통과했다. 이번 단계의 시작 화면 브라우저·설치 기기 시각 검사로 확대 해석하지 않는다.

## 남은 범위

업무 화면 기록은 540개 역할별 주소(실제 화면 523개, 정상 제한·주소 이동 17개), 검토 이미지 2,330개로 유지한다. 이번 구문 트리와 임시 전파 검사를 업무 화면 이미지에 더하지 않았다. 웹 미분류 스타일 인자는 아뜰리에 900개, 메종 0개, 카르넷 0개다.

iOS 파일도 추가로 읽었다. `ToastView.swift`에는 배경·글자색, 여백과 애니메이션 시간이 아직 직접 지정돼 있고, `Palette.swift`에는 강조·보조 색이 남아 있다. iOS 시작 화면의 그리기·애니메이션도 Android 정본 연결 범위에 포함되지 않는다. 이를 완료로 승인하거나 지문만 맞추지 않았다. 다른 Android 클래스의 플랫폼 알림·WebView·시스템 영역과 추가 모바일·테마·상호작용 상태도 후속 범위다.

직전 알림 단계에서 Android APK·AAB 6개를 현재 자산으로 빌드하고 포함 자산·팔레트·줄바꿈 리소스를 확인했다. 이번 시작 화면 채택은 실제 앱 소스를 바꾸지 않아 그 산출물의 시작 화면 코드도 유지된다. 서명·설치 기기 확인과 iOS 빌드는 수행하지 않았다. 웹은 직전 세 제품 운영 배포를 유지한다. 중앙 규칙 변경은 생성·동기화 후 웹 빌드·배포 또는 앱 재빌드·서명·배포를 거쳐 사용자에게 반영된다.
