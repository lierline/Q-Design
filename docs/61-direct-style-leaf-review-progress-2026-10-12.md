# 공용 스타일 전달 검증 보완

공용 `Reveal.style` 한 곳과 `Panel.style` 두 곳을 실제 TypeScript 변수 심벌과 소비 위치에 연결했다. 세 인자는 스타일을 전달하는 경계다. 전달하는 화면의 색상·크기·간격 등을 승인하거나 공용 토큰으로 변경한 기록은 아니다. 현재 `Reveal` 호출은 없고 `Panel` 호출 두 곳은 모두 스타일 인자를 생략한다. 두 컴포넌트에 자체 스타일 기본값도 없다.

새 전달 관계 두 개를 포함한 인자 추적 목록은 40개다. 기존 목록은 38개였으나 검사에 쓰인 기대 수가 37개로 남아 있었고 해당 테스트가 전체 릴리스 검사에 포함되지 않았다. 기대 수를 실제 목록에 맞추고 해당 테스트를 릴리스 검사에 포함했다. 동일 이름의 내부 변수와 임의 스타일 기본값은 전달 근거를 물려받지 못하는 회귀 사례도 추가했다.

목록을 다시 계산하면서 `ChoiceChip.color`와 `Tag.color`에 연결된 호출 파일 두 곳의 오래된 지문도 발견했다. 현재 파일 전체 지문으로 대조했고 기존 호출 수, 위치, 인자 값과 개별 인자 지문은 모두 동일했다. 해당 파일은 연구 검토 화면과 `DocCommentThread`다. 이 갱신은 호출 스타일에 대한 포괄 승인이 아니다. 파일·호출·인자 지문, 미등록 호출, JSX 전달 객체와 미확인 참조가 달라지면 전달 검사가 실패한다.

큐 디자인 커밋 `0d3c781`의 전체 보고서와 대조한 결과 세 인자만 미분류에서 스타일 전달 인자로 바뀌었다. 나머지 모든 판정, 인자·소스 지문과 보고서 메타데이터는 동일했다. 목록의 기존 변경은 위 두 파일의 지문 갱신으로 제한했다. 대조 근거는 `reviews/atelier-direct-style-leaf-decision-migration.json`에 보관했다. 전달 관계와 호출부 회귀 검사 9개가 통과했다.

아뜰리에 미분류는 870개에서 867개로 줄었다. 메종·카르넷은 계속 0개다. 제품 실행 소스와 화면 디자인은 이번 단계에서 변경하지 않았다. 정본 구현 29개 파일, 부속 렌더러 5개, 등록 주소 540개와 업무 화면 이미지 판정 2,330개 집계는 유지한다. 새 업무 화면이나 설치 기기 검수를 추가한 기록은 아니다.

최종 `extract-all --check --only=Q-Atelier,Q-Works,Q-Forge`가 종료 코드 0으로 통과했다. 원본 사본 111개와 제품 아이콘 32개가 일치했고 새 인자 전달 테스트도 전체 검사에 포함됐다. 금지 문자와 변경 공백 검사도 통과했다. 실행 소스 변경이 없으므로 새 운영 빌드나 배포 대상은 없다. 큐 디자인 수정은 생성·동기화, 검사, 제품 빌드와 배포를 거쳐 반영한다. 남은 실제 스타일·호출 인자와 추가 화면 상태, iOS·설치 기기·서명 검수는 계속 남아 있으며 시스템 전체 중앙화 완료로 인증하지 않는다.
