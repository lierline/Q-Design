# iOS 안내 메시지의 공통 모서리 연결

iOS 안내 메시지의 `layer.cornerRadius = 10`을 `QDesignGeometry.cornerRadius`로 바꿨다. 이 값은 `tools/build-native-offline.mjs`가 웹 공용 조작부와 같은 `patterns/components.css`의 `--qd-radius`를 해석해 생성한다. 기존 생성 Swift 파일에 `CGFloat` 값 한 개를 담은 `QDesignGeometry`를 추가했다. 기본값은 10으로 유지하며 글꼴 값 3개와 안내 메시지의 나머지 모든 소스는 동일하다. 현재 `cornerCurve = .continuous`도 유지한다.

별도 임시 작업 공간에서 공통 모서리를 14px로 바꾸면 생성된 iOS 값도 14가 되는지 확인했다. 실제 시작 화면·안내 메시지 정본과 생성 파일·앱 소스 일치 검사를 유지했다. 안내 메시지가 독립 숫자나 주석 속 참조만 사용하거나 나중에 모서리 값을 다시 덮어쓰면 검사에 실패한다. 숫자가 아닌 공통 모서리 값은 네이티브 변환에서 거부한다. 글꼴·팔레트·오프라인 자산 검사까지 묶은 회귀 검사 8개가 통과했다.

기존 iOS 커밋 `b3f9328`과 전체 파일을 대조했다. 안내 메시지에서 변경된 것은 해당 대입 한 곳이고, 생성 파일은 기존 글꼴 선언 뒤에 모서리 선언을 추가한 것뿐이다. 콜백, 안내 시간, 여백, 색상, 접근성과 동작 처리는 동일하다. 근거는 `reviews/ios-shared-radius-migration.json`이다. 62번의 소스 불변 기록은 이번 수정 전 정본 채택 단계에 관한 이력으로 유지한다.

최종 `extract-all --check --only=Q-Atelier,Q-Works,Q-Forge`가 종료 코드 0으로 통과했다. 원본 사본 111개와 정본 아이콘 32개가 일치했고, 금지 문자·변경 공백 검사도 통과했다. Android와 웹 실행 소스 및 자산은 변경하지 않았다. 웹 미분류 수는 아뜰리에 867개, 메종·카르넷 0개다. 업무 화면 수와 이미지 판정 집계도 변경하지 않았다.

현재 Windows 환경에는 Swift 컴파일러와 Apple SDK가 없어 iOS 컴파일·시뮬레이터·설치 기기·서명·배포를 확인하지 못했다. 이번 소스 변경은 iOS 앱을 다시 빌드·검증한 후 배포해야 설치 앱에 반영된다. 다른 iOS 색상과 모션 값, 네이티브 컴포넌트와 추가 화면 상태는 계속 검토 대상으로 유지한다.
