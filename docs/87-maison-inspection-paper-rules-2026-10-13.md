# 메종 검사 기록지 공통 규칙 연결과 표본 번호 줄바꿈 수정

기능 이식 후 검사 기록지 부품에 개별 치수와 서체 값이 남아 있었다. 기존 인쇄 정본의 값을 사용하도록 인라인 값 60곳과 측정 열의 43.4% 분배 인자 1곳을 연결했다. 부족한 치수·서체 값 16개와 측정 열 역할 1개를 patterns/foundation/maison-print.ts에 추가했다. 기존 인쇄 정본의 모든 값은 유지하며 lib/design/q-design-print.ts는 정상 내보내기로 갱신했다. tokens.ts는 변경하지 않았다.

이미지 검수에서 육안·치수 검사 표의 #001 표본 번호가 두 줄로 나뉘는 문제를 발견했다. 두 출력 위치에 nowrap과 공통 8.5pt 글꼴을 적용했다. 열 너비, 표본 순서, 기록 내용, 판정·서명·결재 칸은 유지한다. 총 63개 원본 위치의 연결·표시 수정을 기록했다.

실제 검사 부품 다섯 서식에서 표본 0·1·41개와 측정 항목 0·1·3개를 조합한 45개 출력물을 비교했다. 의도한 표본 번호 스타일을 제외한 전체 HTML은 기존과 동일하다. 중앙 제목 크기·간격·열 너비·측정 분배 값을 바꾸면 실제 출력에 반영되면서 글자와 셀 수는 유지된다. 분모 변조, 빈 측정 항목의 안전 처리 삭제, 임의 헤더 간격, 미검수 실행 코드는 거부한다. 관련 테스트 5개와 기존 구매·인쇄 테스트 18개가 통과했다. 설치된 프로젝트 TypeScript로 전체 타입 검사도 통과했다.

실제 제품 CSS와 저장된 글꼴 파일을 넣은 독립 Edge에서 다섯 서식을 390px·1280px로 검수했다. 10개 화면에서 표본 번호가 모두 한 줄이며 셀의 가로 잘림은 0건이다. 캡처 D:/Claude/tmp/qd-phase87-inspection-print-fixture.png를 직접 확인했다. A4 지면은 두 크기에서 약 793.7px의 물리 너비를 유지한다. 390px 검수는 셀과 번호의 표시 검사이며 지면 전체가 휴대폰 너비에 들어간다는 의미가 아니다. 이 검사는 로컬 자료로 실제 부품을 렌더링한 것이며 운영 업무 기록이나 인쇄 대화상자·쪽 나눔 검사를 대신하지 않는다. 데이터 서비스·저장·업로드는 실행하지 않았다.

기존 인쇄 인자가 변하지 않았는데 전체 정본 지문이 달라진 경우, 현재 인자·소비자 원본·다른 근거가 완전히 같은 항목만 다시 대조했다. 실제 조건부 헤더 간격과 측정 열 계산 3곳도 각각 소비자를 검사했다. 현재 검사 기록지 부품 미분류는 0건, 메종 전체는 974건에서 864건으로 줄었다. 아뜰리에 마지막 검증 580건과 카르넷 0건을 합하면 1,444건이다. 제조기록서 109건 등 추가 검수는 남아 있다.

메종 c2f0bc5c와 28ccbd4edb8f006ceaa722b21006fee31dea3bb8을 정상 훅으로 커밋·푸시했다. dpl_BsdBXnBmWPJYBywZSUGnhtFfcJES의 READY, 정확한 커밋과 maison.medqraft.app 별칭을 확인했다. 운영 검사 개요도 열어 확인했지만 현재 검사 기록은 0건이므로 운영 기록의 실제 인쇄 지면 확인을 완료한 것으로 기록하지 않는다. 그 전 공문서함 854d0bf3 배포는 READY와 운영 화면의 중앙 4열 값을 확인했다.
