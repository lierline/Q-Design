# 로그인 아이콘과 원형 진행률 인자 검수

로그인 화면의 소셜 아이콘과 원형 진행률에서 미분류 28건을 개별 검수했다. 제품 화면의 버튼 모서리와 SVG 내부 좌표를 구분하고, 실제 렌더러에 중앙 값 변경을 넣어 영향을 확인했다. 제품 코드는 변경하지 않았다.

## 확인한 규칙

- 소셜 아이콘의 바깥 크기와 선 굵기는 `QDPresentation`, 링크 버튼의 모서리는 `QDScale`이 정한다. Instagram 내부 사각형의 18×18, 모서리 5는 24단위 아이콘 도형의 좌표다. 화면 버튼의 모서리 10과 다른 역할이다.
- 소셜 아이콘의 `currentColor`는 링크 색을 상속한다. 선이나 채움의 `none`은 그리기 방식이다. 독립적인 화면 색상 값으로 취급하지 않는다.
- 원형 진행률의 중심은 크기의 절반, 반지름은 `(크기 - 선 굵기) / 2`다. 둘레와 진행 구간은 이 반지름과 0~100으로 제한된 진행률에서 계산된다. 크기·선 굵기의 기본값과 호출부는 기존 별도 검수를 유지한다.
- 다른 SVG, 로그인 공급자 아이콘, 호출부 스타일, 클래스 이름은 이 판정의 적용 범위에 들어가지 않는다. 과거의 두 내부 사각형 검수는 원래 근거 그대로 보관하고, 현재 원문 지문에 맞는 새 검수를 적용했다.

## 근거와 검증

두 검수 도구는 함수의 전체 AST 지문과 정확한 속성을 검사한다. 소셜 아이콘의 중앙 입력은 실제 import 심볼을 대조한다. 원형 진행률에서는 `Math`가 다른 값으로 가려지지 않는지도 확인한다. 원문이나 참조 근거가 달라지면 과거 판정을 적용하지 않는다.

6개 회귀 시험이 통과했다. 아이콘 크기 16→22, 선 굵기 1.8→2.25, 링크 모서리 10→6 및 상속 색 변경을 실제 JSX에 넣어 내부 도형이 유지되는지 확인했다. 원형 진행률은 기본 크기 56→70, 선 굵기 5→7과 명시적 100/10을 검사하고, 진행률 -5/0/37/100/150에서 중심·반지름·둘레·진행 구간을 대조했다. 이는 실제 렌더러의 정적 렌더링 검사이며 브라우저 상호작용 전체를 대신하지 않는다.

운영 로그인 화면을 폭 390px로 확인했다. 세 소셜 링크 모서리는 모두 10px, SVG 크기는 16px이고 Instagram의 선 굵기는 1.8이다. 내부 사각형 모서리는 5다. 가로 넘침은 없다. 측정은 `reviews/phase69-operating/social-geometry.json`에 보관했다. 링크의 보이는 크기는 32px지만 터치 기기에서는 기존 중앙 CSS의 보이지 않는 클릭 영역 확대 규칙도 적용되므로, 보이는 크기만으로 클릭 영역이 32px라고 단정하지 않는다.

전체 53,986개 기록 중 53,958개의 모든 필드가 이전 커밋과 동일함을 확인했다. 변경된 28개도 원문 지문과 원시 인자 필드는 동일하며 검수 판정·이유·근거만 추가됐다. `reviews/atelier-native-geometry-ledger.json`에 비교 결과를 기록했다.

현재 미분류는 아뜰리에 823건, 메종 0건, 카르넷 0건이다. 아뜰리에 823건 중 직접 또는 확정 스타일 문맥은 513건이다. 미분류 수는 결함 수나 화면 수가 아니다. 새 규칙을 포함한 세 제품 전체 릴리스 검사는 종료 코드 0으로 통과했다. 원본 지도 111곳과 사본, 앱 아이콘 32/32가 일치한다.
