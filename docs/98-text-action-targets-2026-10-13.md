# 공통 텍스트 버튼 조작 영역과 포커스 모서리

짧은 취소·닫기 버튼의 최소 너비를 공통 조작 높이 토큰으로 연결했다. 아뜰리에의 기존 포커스 초기화가 모서리를 1px로 바꾸는 문제도 공통 모서리 토큰으로 보정했다. 기존 업무 화면 CSS와 새 조작 영역 규칙을 조립해 세 제품의 업무 화면 CSS로 배포한다. tokens.ts는 변경하지 않았다.

실제 세 제품 CSS를 사용하는 브라우저 검사 36개가 통과했다. 화면 폭 320·390·1280, 밝은 화면·어두운 화면, 포인터 두 종류를 검사했다. 최소 조작 높이 토큰을 48px로 바꾸면 두 텍스트 버튼의 너비에도 반영되는 것을 확인하고 복원했다. 키보드 포커스 모서리도 10px를 유지한다.

메종 운영의 취소 버튼은 약 40.5px에서 44px로 넓어졌다. 아뜰리에 운영의 닫기 버튼은 44×44px이며 키보드 포커스에서도 모서리 10px를 유지한다. 카르넷 운영의 뒤로 버튼은 높이 44px, 모서리 10px다. 카르넷 홈에는 이번 텍스트 버튼 클래스가 없어 홈 화면만으로 새 규칙 적용을 입증하지 않았다. 세 제품 배포는 정확한 커밋과 운영 도메인의 READY 상태로 확인했다.

제품 커밋은 아뜰리에 61ddd606f1c222c23175a8858e76ce6df75082dd, 메종 d96a51695b94db5f3652aba6683bada9989e6430, 카르넷 579120df7107af56c137f8aac8a56af87849ef91이다. 모두 main에 푸시했다. 아뜰리에 푸시 검사에서는 4,667개 테스트가 통과했고 타입·린트 검사도 통과했다.

현재 미분류는 아뜰리에 580건, 메종 607건, 카르넷 0건으로 총 1,187건이다. 새 두 규칙의 사본·소스·기존 판정 역변환 검사와 관련 검사 40개가 통과했다. 전체 릴리스 첫 실행에서는 과거 오류 문구를 예상한 검사 하나가 실패했다. 최신 업무 화면 변경을 정확히 역변환한 뒤 기존 변경 거부 검사를 실행하도록 보정했고 해당 두 검사가 통과했다. 전체 재실행 결과는 확정 후 기록한다. 전체 화면 및 전체 릴리스 완료를 주장하지 않는다.

운영 검수 중 아뜰리에 사용법의 조사 앞 띄어쓰기와 카르넷 사용자명 뒤 님 앞 띄어쓰기를 추가 발견했다. 아직 수정하지 않았다. Android 메종·카르넷 원격 저장소 작업은 사용자 요청에 따라 Claude가 맡는다. iOS 빌드 검사는 이번 범위에서 제외한다.

전체 재실행은 기존 검사의 반복 비용을 줄이고 미분류 판정을 계속하기 위해 중단했다. 재실행의 전체 통과 결과는 없다. 최종 완료 전 전체 검사를 다시 실행해야 한다.
