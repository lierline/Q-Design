# 메종 생산 준비 표 모바일 정리

320px 운영 화면에서 설비 표의 부모 너비는 236px, 표 너비는 328.89px였다. 오른쪽 항목이 화면 밖으로 나갔다. 검색 목록을 잘리지 않게 하려고 표 스크롤을 비활성화한 기존 구조가 원인이었다.

## 변경한 규칙

큐 디자인의 `patterns/foundation/maison-prep-table.css`가 생산 준비 표의 테두리·모서리·표 너비·줄바꿈·반응형 구조·확인과 삭제의 터치 영역을 소유한다. 정본 사본은 제품 `app/q-design.prep-table.css`이며 `app/globals.css`에서 연결한다.

640px 이하의 설비 표는 설비명, 설비 번호, 검교정 일자를 세로로 배치한다. 확인·삭제는 중앙 터치 높이를 따른다. 검색 목록을 감추거나 표 바깥을 잘라 문제를 숨기지 않는다. 공백 없는 긴 설비명은 데스크톱에서도 줄바꿈한다. 원재료·반제품·부재료·소모품 표는 기존 내부 수평 스크롤을 유지하며 최소 너비는 중앙 규칙에서 받는다.

제품 소스의 9개 표현 변경과 CSS import 1개만 허용하는 전체 소스 역변환 규칙을 추가했다. 모든 JSX 이벤트와 업무 갱신 함수는 변경 전후 동일하다. 전해 연마처럼 설비 항목이 없는 공정에 새 항목을 만들지 않는다.

## 검증

- 공정 4개, 너비 320·390·1280px, 입력 글자 크기 13·15px, 밝음·어두움 조합 48개가 통과했다. 설비가 없는 12개 경우는 빈 상태와 화면 너비를 확인했다.
- 나머지 36개 경우는 실제 React 검색·키보드 선택·확인 해제·초기화·행 삭제를 합성 로컬 데이터로 검증했다. 서비스 호출이나 저장은 실행하지 않았다.
- 실제 Pretendard가 로드된 상태에서 표 너비와 셀 넘침을 검사했다. 화면 가로 넘침과 설비 셀 넘침은 0이다.
- 중앙 모서리 14px, 터치 높이 48px 변경이 실제 표와 조작 영역에 반영되며 가로 넘침이 없었다.
- 단위 검사 3개, 기존 글꼴·아이콘·이식 관련 검사 8개, 메종 전체 타입 검사와 정상 커밋 훅이 통과했다. 아이콘 지문 27개 파일·69개 import도 재검증했다.
- 전체 UI 목록을 갱신하고 정본 사본·앱 import 경로를 확인했다. 공개 부품 등록 범위는 아뜰리에 69/69, 메종 95/95, 카르넷 32/32다. 이 수치는 전체 업무 화면의 시각 검수 완료 수가 아니다.

로컬 실제 컴포넌트 캡처는 `tmp/qd-phase92-equipment-table-mobile.png`다. 메종 미분류는 653건에서 652건으로 줄었다. 전체 릴리스는 미분류가 남아 아직 통과 상태가 아니다.
