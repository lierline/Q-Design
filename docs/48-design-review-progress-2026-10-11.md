# 세 제품 디자인 검수 진행 기록

2026-10-11. 47번 중단 기록 이후 다시 진행한 검수와 수정의 현재 상태다. 전체 디자인 인증은 아직 완료하지 않았다.

## 확인한 화면

등록된 역할별 주소 540개 모두에 검토한 화면 증거가 있다. 아뜰리에 201개, 메종 277개, 카르넷 62개다. 실제 업무 화면은 523개이고, 나머지 17개는 권한 제한 또는 기존 주소의 정상 이동을 확인했다. 이 집계는 기본 데스크톱 화면 기준이며 모든 모바일 폭, 테마, 입력 상태와 설치 앱의 실제 작동까지 뜻하지 않는다.

이미지 2,295개를 검토했다. 긴 라이선스 화면도 아래 끝까지 확인했다. 이전 전문가 설정 화면에서 발견한 큰 입력 높이와 글꼴 차이는 결함 기록을 유지하고, 수정 후 화면을 별도로 확인했다.

허용된 전용 로컬 검수 계정만 승인 상태로 바꿔 초기 설정의 조직 목록과 생성 양식을 확인했다. 조직 생성, 가입, 직무 권한 부여와 운영 계정 변경은 실행하지 않았다.

## 적용한 수정

- 전문가 설정의 일반 입력과 선택창을 중앙 높이 44px, 글꼴 13px, 모서리 10px 규칙에 연결했다. 여러 줄 입력의 자연스러운 높이는 유지한다.
- 연구 검토와 문서 댓글의 삭제 버튼을 공통 아이콘 조작부로 맞췄다.
- UDI 선택 상태와 접근성 상태에 같은 기본값을 사용하고, 선택 표시색을 공통 토큰에 연결했다.
- 역산 일정표의 독립 모서리 지정값을 제거했다.
- 초기 설정 제목을 실제 제목 요소로 바꾸고 공통 여백 규칙을 적용했다.
- 메종 차트, 파일 선택 입력, 인쇄 문구와 권한 설명의 중앙 규칙 및 검증을 추가했다.

## 검증과 운영 상태

공통 인자 전파 408개와 팔레트 36개 브라우저 검사는 실패 0건이다. 파일 선택 입력 36개, 인쇄 문구 8개, 메종 차트 12개 브라우저 검사가 통과했다. 세 제품 생성 파일과 앱 아이콘 32개도 정본과 일치했다.

아뜰리에 수정 커밋은 `98421a2`이며 운영 배포가 READY 상태다. 제품 검사는 테스트 4,664개 통과, 예상 실패 1개, 제외 3개이며 린트 오류 0개와 타입 검사가 통과했다. 메종 운영 기준은 `6a427ac`, 카르넷은 `63e7307`이다.

## 남은 검토

아뜰리에 미분류 인자 963개는 아직 승인하지 않았다. 메종과 카르넷의 해당 집계는 0개다. 사용처, 데이터 계산, 공통 토큰과 실제 표시 결과를 대조해 분류해야 한다. 전문가 가입과 설정의 선택 안내 및 경력 표기 차이도 추가 정리가 필요하다.

Android 디버그 APK 세 개의 오프라인 자산은 중앙 정본과 일치한다. 기존 서명 릴리스 APK에는 이전 자산이 남아 있으며 iOS 빌드와 설치 앱의 최종 검증도 남아 있다.

Q-Design의 원본 변경은 생성, 제품 동기화, 제품 빌드와 배포 과정을 거쳐 적용된다. 운영 화면이 편집 즉시 바뀌는 구조는 아니다. 현재 검사는 공통 규칙의 전달을 입증하지만, 남은 미분류 인자와 화면 상태까지 모두 중앙 제어된다고 인증하지는 않는다.

화면 원본, 검수 계정 자료와 로그인 주소는 비공개 로컬 증거로 보관한다. 이 문서에는 포함하지 않는다.
