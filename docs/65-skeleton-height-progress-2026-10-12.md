# 로딩 표시 높이 통일

아뜰리에의 두 실제 Skeleton 구현을 같은 테마와 폭에서 비교했다. 기본 막대는 기존 공용 구현이 12px, 독립 구현이 14px였고 본문 줄은 각각 10px와 12px였다. 다크·라이트의 1280px, 390px, 375px 폭에서 이 차이를 확인했다.

공용 구현의 기본 높이를 14px, 패널 본문 줄을 12px로 통일했다. 두 구현 모두 `source/design/atelier-runtime.ts`의 `QDPresentation.skeletonHeight`를 읽는다. 공용 구현의 정본은 `patterns/component-implementations/atelier/lib/design/components.tsx`이며 생성기로 제품에 반영했다. 입력 속성 이름, 개별 화면의 높이 지정, 너비, 줄 수, 여백, 모서리, 문구와 동작은 유지했다. KPI의 작은 이름표 줄처럼 역할이 다른 높이는 독립 규칙을 유지한다.

정확한 두 수정은 `reviews/atelier-skeleton-parity-migration.json`에 기록했다. 수정 전 전체 소스도 보존하며 전체 문자 대조로 다른 변경을 거부한다. 기존 감사의 변경되지 않은 인자 35개는 원래 인자와 실제 소비 구문 전체를 대조해 유지했다. 축약된 소비 기록도 원래 전체 구문을 찾아 수정 전후가 같은지 확인했다. 전달 경로 8개 기록부는 현재 TypeScript 심볼로 다시 생성했다. 원래 감사 이력은 덮어쓰지 않았다.

전체 인자 판정 53,986개를 대조했다. 두 높이 참조만 바뀌었으며 나머지 53,984개의 인자와 판정은 같다. 정확한 두 수정으로 바뀐 해당 소스의 지문만 현재 값으로 갱신했다. 판정 집계는 동일하며 미분류는 아뜰리에 867개, 메종·카르넷 0개다. `reviews/atelier-skeleton-ledger-migration.json`이 전체 보고서 대조 근거다.

실제 함수 선언과 독립 컴포넌트를 격리해 렌더링한 브라우저 검사 12개가 통과했다. 두 테마와 세 폭에서 기본·본문 높이와 모서리를 확인했고 중앙 높이를 19px·17px로 바꾸면 두 구현에 함께 전파됐다. 직접 지정한 31px, 스타일로 지정한 29px도 유지된다. 동작 줄이기 설정에서는 애니메이션이 꺼진다. 모든 네트워크 요청을 막았으며 이 검사는 새 업무 화면 검수 건수에 더하지 않는다.

세 제품의 공통 부품 비교 18개와 확장 비교 30개는 차이 0개로 통과했다. 디자인 값 전파 408건과 팔레트 36건도 통과했다. 아뜰리에 운영용 전체 빌드는 성공했고 제품 시험 4,667개가 통과했다. 기존 예상 실패 1개와 생략 3개를 유지한다. 사용자의 `tsconfig.build.json` 변경은 포함하지 않았다.

제품 소스 커밋은 `4e2ab6a4`다. 운영 배포와 최종 릴리스 결과는 검증 완료 뒤 이 문서에 기록한다. iOS는 사용자의 2026-10-12 결정으로 이번 남은 작업에서 제외한다.

아직 전체 디자인 감사 완료를 뜻하지 않는다. 미분류 인자의 실제 사용처, 개별 화면의 상태·반응형 검증과 Android의 설치·배포 검증은 별도 완료 근거가 필요하다. 중앙 정본 수정은 생성·동기화와 각 제품 빌드·배포를 거쳐 사용자 화면에 반영한다.
