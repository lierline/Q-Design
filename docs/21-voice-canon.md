# 화면 말투 정본

세 제품이 사람에게 말을 거는 방식입니다. `tools/check-voice.mjs` 가 이 문서를 검사합니다.

---

## 규칙 셋

**① 화면 «문장»은 합니다체로 끝냅니다.** 합니다 · 입니다 · 습니다.

```
  ○  업종을 가리지 않습니다.
  ○  연락처가 없어 접촉 실행이 안 됩니다.
  ×  업종을 가리지 않는다.
  ×  연락처가 없어 접촉 실행이 안 된다.
```

**② 이름표 · 지표 · 표 머리 · 필터 칩 · 단추 글은 명사로 끝냅니다.** 문장이 아니므로
말투가 없습니다. 여기에 「…합니다」를 붙이면 오히려 어긋납니다.

```
  ○  메일 주소가 있는 곳     ○  담을 수 있음     ○  전체 내려받기
  ×  메일 주소가 있습니다     ×  담을 수 있습니다
```

**③ 해라체(ㄴ다 · 는다 · 이다)는 화면에 쓰지 않습니다.**
코드 주석 · 커밋 메시지 · 설계 문서는 이 규칙 «밖»입니다. 그쪽은 개발자가 개발자에게
하는 말이라 기존 어체를 그대로 씁니다.

---

## 왜 합니다체인가 · 소스가 답했습니다

2026-09-09 감사에서 한 화면 «안»에서 말투가 갈린 것이 드러났습니다. Q-Sonar `/targets`
는 위쪽 문단이 「…가리지 않는다.」인데 아래쪽이 「…넘어갑니다.」였습니다. 말투가 갈리면
읽는 사람은 **누가 말하고 있나**를 매번 다시 정합니다.

어느 쪽이 집안 말투인지는 세 저장소를 실측해 정했습니다.

| 저장소 | 고치기 전 해라체 | 고친 뒤 |
|---|---:|---:|
| Q-Atelier | 28곳 | 21곳 (격언 7 면제) |
| Q-Sonar | 38곳 | **0곳** |
| Q-Forge | 11곳 | 11곳 |

어긋난 쪽이 Q-Sonar 하나였으므로 그쪽을 합니다체로 모았습니다. 나머지 둘은 이 주제
밖이라 **지금 값 그대로 잠갔습니다**(`tools/voice-baseline.json`). 상한은 `--record`
없이는 못 올라갑니다.

## 검사

```bash
node tools/check-voice.mjs            # 상한을 넘으면 exit 1
node tools/check-voice.mjs --list     # 걸린 문장을 전부 찍습니다
node tools/check-voice.mjs --record   # 지금 값을 상한으로 새로 찍습니다
```

**판정은 좁습니다.** 문장 끝이 「다」이고 「니다」가 아니면 해라체입니다.
「자」 「라」 「까」 「네」는 종결로 보지 않습니다. 시제품에서 그렇게 했더니
「공급자」 「품질책임자」 「같습니까?」가 잡혀 Q-Atelier 50건 중 36건이 오탐이었습니다.
**거짓 경보를 한 번 내면 다음부터 아무도 이 검사를 안 봅니다.**

실측으로 걷어낸 오탐이 넷 더 있습니다.

| 형태 | 보기 | 왜 아닌가 |
|---|---|---|
| 부사 「다」 | 둘 다 · 모두 다 | 앞이 공백입니다 |
| 조사 「마다」 | 생산 로트마다 | 종결이 아닙니다 |
| 조사 「보다」 | 서면보다 | 종결이 아닙니다 |
| 문장 안의 인용 | 걸려 「전부 죽었다」처럼 보입니다 | 「」 안은 증상을 흉내 낸 것입니다 |

**보는 자리는 넷입니다.** 태그 사이 글 · `title`/`placeholder`/`aria-label` ·
한글이 든 문자열 리터럴 전부 · 백틱 문자열.

> 🔴 **카피 «키 목록» 을 두지 않습니다.** 처음에는 `why · sub · label …` 열 개를
> 적어 두고 그 키의 값만 봤는데, `lib/diagnostics/mfds-probe.ts` 의 `IMPACT` 는 키
> 이름이 달라 통째로 빠졌습니다. 그것은 `/diagnostics` 화면에 그대로 그려지는 글입니다.
> **이름으로 고르면 이름을 안 맞춘 자리가 조용히 검사 밖이 됩니다.**

> 🔴 **자기 검출력 시험을 먼저 돌립니다.** 네 묶음(해라체 1건 · 문자열과 속성 2건 ·
> 줄 끝 주석 · 조사 꼬리 0건)이 정확히 맞지 않으면 **아무것도 재지 않고 exit 2 로
> 죽습니다.** 초록불을 내는 빈 그물이 가장 위험합니다.

## 면제

`tools/voice-allow.json` 에 **문장 전문**으로 적습니다. 줄번호로 적으면 파일이 자라는
날 어긋납니다.

면제할 만한 것은 «말하는 사람이 화면이 아닌» 글입니다. 지금 들어 있는 것은 Q-Atelier
`components/StudioNote.tsx` 의 격언 일곱 줄입니다(「규제는 제약이 아니라 안전의 언어다」
등). 격언은 화면이 사용자에게 하는 말이 아니라 인용이라 합니다체로 바꾸면 맛이 죽습니다.

고객에게 나가는 «편지» 본문(Q-Sonar `lib/outreach/draft.ts`)은 화면 글이 아니라
사람이 사람에게 보내는 메일이라 이 규칙 밖입니다.
