# 배경부터 세부 인자까지의 확장 감사

2026-10-10. 대상은 Q-Atelier, Q-Maison, Q-Carnet이다. [인계서](28-handoff-to-codex-2026-10-10.md)를 기준으로 기존 결정을 보존하고, 오너가 요청한 디자인 통일과 중앙 규칙 연결을 로컬 제품 코드에 반영했다. 이 문서는 [첫 컴포넌트 감사](32-unification-audit.md) 이후의 확장 결과다.

## 현재 변경 경로

공통 외형은 `patterns/components.css`, 서체·간격·배경·인증 기반은 `patterns/foundation.css`, 제품별 선택자와 출력 규칙은 `patterns/foundation/`에 있다. 제품의 전역 CSS는 이 원본에서 생성한 사본을 가져온다. 메종과 카르넷의 Tailwind 체계도 중앙 원본을 사용한다. 아뜰리에에서 JavaScript 숫자가 필요한 반응형 조건·아이콘·스위치·그리드·투명도는 `source/design/atelier-runtime.ts`가 소유한다.

중앙 파일 변경 후 생성과 동기화를 실행하면 제품 사본이 갱신된다. 배포 목록, 본문 지문, 실제 import 또는 정적 URL 참조를 확인하고 실제 제품 컴포넌트에 값을 바꿔 넣는 검사를 수행한다. 사본이 있다는 사실만으로 실행 경로 전체를 통과시킨 것은 아니다.

[규칙서](35-foundation-rules.md)는 22개 분야의 인자를 정의한다. [공식 사례 조사](34-foundation-reference-study.md)는 8개 디자인 시스템·표준의 15개 공식 사례와 적용 판단을 기록한다.

## 놓친 인자를 찾는 방법

`style-arguments.mjs`는 runtime 코드와 CSS, HTML, SVG, 설정 파일을 조사한다. 객체 속성, JSX 표현, 이름 붙은 기본값, 클래스의 각 유틸리티, 내장 CSS와 DOM 스타일 변경을 기록한다. 발견이 없는 파일도 지문을 남긴다. 재생성한 결과는 `dist/q-design.style-arguments.json`과 제품별 `dist/style-arguments/*.ndjson`에 있다.

동적 식과 Tailwind 유틸리티도 검토 후보이므로 `review-required`를 곧바로 하드코딩 결함으로 해석하면 안 된다. 반대로 토큰 참조도 실제 CSS 우선순위가 올바르다는 증명은 아니다. 자동 면제로 후보 수를 줄이지 않았다. `--check`는 근거의 최신 상태를 검사하고, `--strict`는 미검토 후보가 남으면 실패한다.

등록부는 명시한 공개 렌더 API 195개를 모두 역할에 연결한다. 이 범위와 화면 내부 선언, 업무 조합, 정적 인자 후보 수는 별개의 지표다.

| 제품 | runtime 조사 파일 | 기록된 표현 후보 | `review-required` 후보 | 중앙 사본 |
| --- | ---: | ---: | ---: | ---: |
| Q-Atelier | 1,586 | 49,348 | 9,016 | 13 |
| Q-Maison | 1,566 | 42,185 | 38,753 | 15 |
| Q-Carnet | 236 | 15,435 | 11,215 | 15 |

이 목록은 모든 후보의 시각 검토가 끝났다는 표시가 아니다. 특히 중앙 Tailwind 테마로 생성되는 일반 클래스도 정적 분석에서는 후보로 남는다. 추가 업무 화면 검토에서 정확한 위치를 다시 찾을 수 있도록 근거를 보존했다.

## 실제 화면 검증

[비교 화면](../preview/components.html)은 세 제품의 실제 React 컴포넌트를 사용한다. 공통 인자 편집에서 배경·서체·반경·조작 높이·로그인 인자를 바꿔 세 제품을 나란히 볼 수 있다. 화면의 조정은 미리보기이며 원본 저장은 하지 않는다.

- 컴포넌트: 세 제품 × 두 테마 × 375·412·1440px, 18개 조건.
- 로그인·배경: 같은 18개 조건. 가로 넘침, 입력 영역, 동작 감소 설정 확인.
- 중앙 변경: 반경 10→14px, 조작 글자 13→15px, 조작 높이 44→48px, 진행선 6→9px, 기본 아이콘 20→24px 및 팔레트 변경.
- 인증 변경: 제목·폼 여백·배경·카드 면·글자·반경·리본 투명도 변경 전파.
- 상호작용: Tab·Shift+Tab, Escape, 초점 복원, 체크·스위치 키보드 조작, 중첩 모달, 긴 서랍의 마지막 행동 도달.
- 미리보기: 초기 설정과 재설정이 중앙 기본값을 덮지 않는지 검사.

전체 회귀 보고서의 지문과 판정은 [검증 기록](../reviews/2026-10-10-foundation-verification.json)에 보관했다. 결과 파일은 [컴포넌트 검사](../preview/screens/components/results.json), [기반 검사](../preview/screens/foundation/results.json)다. 화면 스크린샷도 같은 폴더에 있다. 모든 업무 데이터·권한·저장·결재·인쇄 조합을 종단 검증했다는 뜻은 아니다.

색상 감사는 커밋된 로컬 CSS import를 따라가도록 보완했다. 중앙 원본에서 직접 내보내는 파일도 배포 목록의 정확한 경로로 확인한다. 세 제품 지정 범위에서 아뜰리에 8개 원본 축, 기존 HEX 감사의 아뜰리에 62색과 카르넷 68색이 모두 일치한다. 메종 HSL·테마 검증은 별도 팔레트·컴포넌트 검사에서 수행한다.

아이콘 검토에서는 기본 크기 규칙의 선택자 우선순위를 낮춰 메종의 `w-4`·`h-4`·`size-4`가 계속 적용되게 했다. 카르넷은 CSS 값을 단순 숫자로 읽던 경로를 실제 계산된 CSS 값으로 바꿔 단위가 달라도 중앙 변경이 전달되게 했다.

## 확인된 제약

메종의 기존 테마 단추 시험에 두 단추가 실제로 존재한다는 검증을 추가해 undefined 타입 오류를 해소했다. 해당 시험 17개와 전체 타입 검사가 통과했다. Windows 샌드박스의 pnpm 심볼릭 링크 실경로 검사 오류가 대량 진단을 만들었으므로 정상 권한에서 다시 확인했다.

전체 자산 릴리스 검사는 설치된 Edge의 앱 아이콘 재렌더 결과가 저장된 v4 그림 지문과 다른 기존 문제를 포함한다. 아이콘 그림과 판 번호는 바꾸지 않았다. 세 제품 지정 범위의 마지막 전체 릴리스 검사는 이 아이콘 지문 차이 때문에 실패했다. 컴포넌트 통일 검사와 전체 릴리스 통과 여부를 구분한다. 지정 범위 없이 기존 전 제품 감사를 실행하면 이번 대상 밖인 Q-Sonar의 기존 색상 누락도 계속 검출한다.

아뜰리에의 잠긴 원본 토큰, 잠금 파일과 엔진 근거는 보존했다. 저장된 manifest의 CRLF 차이는 별도로 기록하고, 5개 엔진 ID의 기존 HEAD·현재 파일·저장 근거 일치를 확인했다.

운영 서버 push나 배포는 하지 않았다. 로컬 코드, 생성 사본, 규칙서와 검증 화면을 검토할 수 있다.
