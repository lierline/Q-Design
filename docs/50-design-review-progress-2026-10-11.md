# 접근 화면과 아이콘 추가 검수 기록

2026-10-11. 49번 기록 이후의 추가 검수다. 세 제품의 전체 디자인 인증은 아직 완료하지 않았다.

## 수정과 실제 화면 확인

전문가 가입 화면에서 한글 라벨과 선택 안내의 자간이 과도한 것을 확인했다. 중앙 `patterns/foundation/atelier.css`에서 라벨과 보조 안내가 `--qd-tracking-normal`을 사용하도록 정돈했다. 브랜드 제목의 영문 자간은 별도 역할로 유지했다.

긴 가입 양식에서는 좌측 브랜드 영역이 양식 높이까지 늘어나 첫 화면에서 로고와 문구 일부가 밀렸다. 같은 접근 화면 껍데기를 사용하는 로그인과 가입 화면의 브랜드 영역을 데스크톱 창 높이에 맞추고, 양식을 내릴 때도 보이도록 연결했다. 높이가 짧은 창에서 내용이 잘리지 않도록 최소 내용 높이를 보존했다. 모바일의 세로 배치는 유지했다.

비밀번호 확인란은 입력과 안내문을 React.Fragment로 묶고 있었는데, 공통 Field가 Fragment 자체에 `id`를 주입하고 있었다. 개발 오류와 라벨 연결 누락을 실제로 확인했다. 이제 Fragment 안의 첫 입력에만 식별자를 연결하며 이미 있는 식별자는 보존한다. 성함, 이메일, 비밀번호, 확인, 전문 분야, 자격, 소속, 경력, 소개의 라벨 9개가 실제 입력·선택·텍스트 영역과 대응함을 확인했다.

가입 양식은 1280×720과 390×844에서 겹치는 구간을 포함해 위에서 아래 끝까지 확인했다. 로그인 화면도 1280×720과 1024×480에서 하단까지 확인했다. 로고와 문구, 조작부, 안내문의 겹침·가로 넘침·잘림은 이 범위에서 보이지 않았다. 가입 제출, 비밀번호 입력과 로그인은 실행하지 않았다.

## 아이콘 인자 검토

로그인 지문 아이콘, 결재 경로 확인, 검색, 모바일 더보기, 알림, 새로고침, 사용량 표시의 직접 호출 7곳을 TypeScript 심볼로 추적했다. 모두 중앙 Phosphor 아이콘 생성 코드를 사용하며, 옛 `strokeWidth` 값은 실제로 버려지는 호환 인자다. 이 숫자를 시각적 선 굵기 차이나 새 중앙 디자인 값으로 오인하지 않도록 구분했다.

검사는 아이콘의 실제 선언, 중앙 생성물과 제품 사본, 선 굵기를 버리는 생성 코드가 일치할 때만 해당 인자를 판정한다. 실제 SVG 선, 동적으로 선택하는 아이콘, 펼친 속성과 임의 표현식은 승인하지 않는다. 이 후보의 8개 인자는 계속 별도 검토 대상으로 남는다. 크기, 색상과 다른 스타일도 일괄 승인하지 않는다.

이전에 소스가 달라져 효력이 없어진 같은 인자 검토 3개는 새 사용처 추적으로 다시 증명했다. 옛 근거는 이력으로 보존했다. 다른 오래된 검토나 소스 지문을 일괄 갱신하지 않았다.

아뜰리에 미분류 인자는 907개에서 900개로 줄었다. 이번 7개는 호환 인자 판정이며 새 시각 수정 7건을 뜻하지 않는다. 메종과 카르넷의 해당 집계는 계속 0개다.

## 검증과 운영

Field 회귀 시험 3개, 정확한 소스 역변환과 기존 공통 기본값 검사 18개가 통과했다. 아이콘 기본값과 호환 인자 검사 12개, 기존 표시 규칙을 함께 확인한 검사 7개도 통과했다. 별도 소스 역변환은 실제 수정만 허용하고 기존 스타일 기본값, 입력 검증과 제출 로직의 변경을 거부한다.

아뜰리에 커밋 `88618bea79c1a67dd7073503dcef91383220efd4`를 정상 검사 후 운영에 반영했다. 테스트 4,667개 통과, 예상 실패 1개, 제외 3개, 린트 오류 0개와 타입 검사 통과를 확인했다. 기존 린트 경고 1,573개는 남아 있다.

운영 배포 `dpl_6qC7hsR4kmZJrDjCAjoyUo7VX5iw`의 READY 상태, 일치하는 커밋과 운영 주소 연결을 확인했다. 운영 전문가 로그인 화면에서 수정된 브랜드 높이와 스크롤 규칙도 실측했다. 운영 업무 화면 전부를 최신 커밋으로 다시 확인한 것은 아니다.

가입·로그인 수정과 추가한 7개 호환 인자 증명을 포함한 전체 릴리스 검사가 종료 코드 0으로 통과했다. 아이콘 정본 32개도 승인된 렌더러와 일치했다. 공개용 검수 집계에서는 로그인과 로컬 초대 URL의 비밀 인자를 제거하며, 원본 검수 기록과 이미지 지문은 보존한다.

등록된 역할별 주소 540개에는 계속 검토 증거가 있다. 실제 화면 523개와 정상 권한 제한·주소 이동 17개를 구분한다. 이미지 2,328개의 판정을 기록했다. 이 수에는 결함, 불완전한 초기 표시와 대체된 캡처도 포함하며 모든 이미지가 정상이라는 뜻이 아니다.

## 새 발견과 남은 범위

운영 재검수에서 브라우저가 저장된 로그인 정보를 자동으로 채우면 입력 배경이 큐 팔레트 밖의 파란색으로 표시되는 차이를 발견했다. 이 캡처는 결함으로 기록했고 정상 화면 승인에 넣지 않았다. 저장된 정보를 읽거나 제출하지 않았다. 자동 채움 상태도 중앙 입력 규칙으로 연결하는 추가 작업이 필요하다.

남은 900개 인자의 사용처와 표현 규칙, 추가 모바일·테마·입력 상태, 다른 네이티브 시각 인자, 앱 서명과 설치 기기 확인, iOS 빌드는 계속 남아 있다. Android와 iOS의 직전 앱 소스·산출물 검증 범위는 49번 기록과 같다.

Q-Design 수정은 생성, 제품 동기화, 빌드와 배포를 거쳐 반영된다. 설치 앱에 포함된 리소스는 앱 재빌드, 서명과 배포도 필요하다. 모든 화면과 모든 인자가 중앙 제어된 상태라고 인증하지 않는다.

로컬 계정, 초대 주소와 원본 화면은 비공개 검수 증거로 보관한다.
