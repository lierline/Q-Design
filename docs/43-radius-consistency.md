# 모바일 모서리 통일 검토

2026-10-11 사용자가 제공한 아뜰리에 설정 화면을 기준으로 상단 사용량·알림 버튼과 세 제품의 사각 컴포넌트 규칙을 검토했다.

사각 버튼, 입력칸, 카드, 패널과 사각 배지는 `--qd-radius` 하나를 따른다. 현재 값은 10px이다. 작은 크기를 뜻하는 `sm`, `md`, `lg`와 큰 크기를 뜻하는 `xl`, `2xl`, `3xl`도 같은 모서리 값으로 연결했다. 원형 프로필과 상태 표시점, 체크 표시용 작은 표지, 인쇄상 각진 영역은 기존 의미를 유지한다.

아뜰리에 상단 버튼은 공통 `IconBtn`을 사용하지만 호출부 스타일을 받을 수 있었다. 공통 아이콘 버튼, 메뉴와 닫기 버튼의 CSS 모서리 선언을 우선 적용하도록 바꿨다. 호출부가 4px나 16px를 지정해도 공통 값을 따른다. 메종의 `rounded-sm` 6px 규칙과 카르넷의 4px·6px·8px 등 크기별 모서리 별칭도 공통 값에 연결했다.

정본은 `patterns/components.css`, `patterns/foundation.css`, `patterns/foundation/maison-tailwind.ts`다. 정본 수정 후 생성, 동기화, 제품 빌드와 배포가 필요하다. 중앙 저장소 파일을 수정하는 것만으로 이미 실행 중인 운영 앱이 즉시 갱신되지는 않는다.

검수에서 세 제품 각각 375px·412px·1440px 폭, 밝은·어두운 테마를 확인했다. 18개 조건에서 공통 모서리가 10px였고, 정본 변수를 14px로 바꾸면 같은 요소가 14px를 따랐다. 실제 아뜰리에 `IconBtn`과 사용량·알림 아이콘으로 별도 검수 예시를 만들었다. 모바일 버튼은 44px 정사각형, 모서리는 10px이며 가로 넘침이 없다.

검수 이미지: `reviews/radius-mobile-atelier-375-2026-10-11.png`. 이 이미지는 실제 제품 컴포넌트와 CSS를 쓰는 로컬 검수 화면이다. 인증된 운영 설정 화면을 촬영한 자료는 아니다. 사용자의 사진에서 서로 달라 보였던 원인이 캐시인지 과거 코드인지는 확정하지 않았다.

제품 커밋은 아뜰리에 `9044a536`, 메종 `c4c5b751`, 카르넷 `c012651`이다. 아뜰리에의 별도 `tsconfig.build.json` 변경과 카르넷의 기존 미추적 보고서는 이 커밋에서 제외했다. 큐 디자인 저장소의 기존 대규모 감사 작업과 이번 정본 변경은 현재 작업 폴더에 있으며 아직 중앙 저장소 커밋으로 묶지 않았다.

이번 모서리 검수는 전체 업무 화면 감사 완료 판정을 대신하지 않는다. 배포 완료 여부와 최종 릴리스 검사 결과는 `reviews/radius-release-result-2026-10-11.json`에 기록한다.

최종 확인: 세 제품의 해당 커밋이 모두 운영 배포 `READY`이며 각 운영 도메인에 연결됐다. 운영 아뜰리에 로그인 화면의 입력칸과 모서리 별칭은 10px이며, 배포 CSS의 아이콘 모서리 규칙도 우선 적용 선언을 포함한다. 메종 심사 양식과 카르넷 로그인 화면도 운영 CSS에서 10px 별칭을 확인했다. 로컬 18개 브라우저 조건, 제품 테스트, 전체 계약과 릴리스 검사, 아이콘 32개 지문 대조가 통과했다.
