# 106. 문구 대장 분리 검증 (2026-10-13)

현재 문구 연결은 dist/q-design.copy-bindings.current.json에서 관리한다. 기존 dist/q-design.copy-bindings.json은 이전 검수의 재현용 스냅샷으로 보존한다. 문구 생성 파이프라인과 카르넷 존칭 검수는 현재 대장을 사용한다.

현재 대장 변경과 이전 스냅샷 오염을 거부하는 검사를 릴리스 검사에 연결했다. 실제 생성기의 멱등성, 중앙 문구 변경 전파, 카르넷 존칭, 메종 기존 문구 검사를 포함한 회귀 검사 16개가 모두 통과했다. 전체 릴리스 결과는 별도 확인 중이다.

이 수정은 검수 도구와 문구 연결 대장 변경이다. 제품 화면 코드는 변경하지 않았다. 미분류는 아뜰리에 573건, 메종 534건, 카르넷 0건으로 총 1,107건이다. 미분류는 모두 실제 디자인 오류를 뜻하지 않는다.
