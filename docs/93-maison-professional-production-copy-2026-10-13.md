# 메종 생산·안전관리 문구 정리

상태 표시의 `작업중`, `조치중`을 `작업 중`, `조치 중`으로 통일하고 생산·안전관리 요약, 입력 안내, 도움말과 인쇄 안내를 전문적인 표현으로 다듬었다. 7개 파일의 실제 문구 15개를 변경했다.

`작업을 멈춘 건`은 `작업이 중지된 기록`, `원인·재발 방지까지 끝난 건`은 `원인·재발 방지 조치가 완료된 기록`으로 바꿨다. 인쇄 안내의 `찍습니다`, `빈칸으로 나가 손으로 채웁니다`는 `인쇄합니다`, `공란으로 출력하여 수기로 작성합니다`로 정리했다. 입력 안내의 `「확인」 을` 띄어쓰기도 고쳤다.

원본 규칙은 `patterns/professional-maison-production-copy.json`이다. 기존 문구의 원문과 정확한 소스 위치를 문구 바인딩에 저장했다. 중앙 상태 문구를 바꾸면 기존 표시 문자열에 전파되는 것을 검증했다. 상태 코드, 저장 데이터, 공식 서식 제목, 조회 조건, 권한과 업무 콜백은 유지했다. 전체 스타일 인자 스트림은 변경 전후 동일하며 포맷에 따른 줄 위치만 달라질 수 있다.
