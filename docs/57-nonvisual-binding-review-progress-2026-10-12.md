# 미분류 데이터 변수 추가 검토

아뜰리에에서 높이 후보로 잡힌 지역 변수 `h` 여섯 개를 실제 선언과 소비 함수까지 확인했다. 품목 미리보기의 캐시 키 누적값, 내려받기 파일명 헤더, 패스키 기준 도메인 검사, 엔진 내용 지문 누적값, IPv6 주소 파싱과 호스트 이름 정규화다. 화면 높이와 색상 규칙으로 관리할 대상이 아니므로 해당 표현만 업무 데이터로 분류했다.

각 항목은 전체 소비 파일 지문, 정확한 줄과 인자 지문에 연결했다. 다른 `h`, 같은 파일의 다른 표현, 숫자가 같다는 이유로 통과시키지 않는다. 소비 파일 변경, 다른 위치와 인자에는 기존 판정이 적용되지 않는 회귀 검사를 추가했다. 엔진·인증·네트워크 코드는 변경하거나 실행하지 않았다.

이전 커밋 `5ff6ffc`의 전체 판정 보고서와 비교했다. 해당 데이터 판정 여섯 개만 변경됐고 나머지 항목, 인자·소스 지문, 규칙과 목록 메타데이터는 모두 동일했다. 역사적 대조 기록은 `reviews/atelier-nonvisual-binding-decision-migration.json`이다. 추가 회귀 검사 두 개와 최종 `extract-all --check --only=Q-Atelier,Q-Works,Q-Forge`가 종료 코드 0으로 통과했다. 아이콘 32개 지문, 금지 문자 1,688개 파일 검사와 변경 공백 검사도 통과했다.

아뜰리에 미분류는 897개에서 891개로 줄었다. 메종·카르넷은 0개다. 업무 데이터 분류를 디자인 중앙화나 화면 시각 인증으로 세지 않는다. 주변 실제 스타일은 원래 판정을 그대로 유지한다. 정본 구현 28개 파일과 부속 렌더러 5개, 등록 주소 540개와 업무 화면 이미지 2,330개 집계도 그대로다. 제품 실행 소스 변경이 없어 기존 운영 배포와 앱 산출물을 유지한다. 남은 스타일 미분류, 추가 화면 상태와 iOS·설치 기기 검토는 계속 남아 있다.
