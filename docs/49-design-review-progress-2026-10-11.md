# 세 제품 디자인 추가 검수 기록

2026-10-11. 48번 진행 기록 이후 추가로 확인한 내용이다. 전체 디자인 인증은 아직 완료하지 않았다.

## 화면 검수

등록된 역할별 주소 540개에 검토 증거가 있다. 아뜰리에 201개, 메종 277개, 카르넷 62개다. 실제 화면 523개와 권한 제한 또는 정상 주소 이동 17개를 구분했다. 이 수는 기본 데스크톱 범위이며 모든 테마, 모바일 폭, 입력 상태와 설치 앱까지 확인했다는 뜻이 아니다.

이미지 2,312개의 판정을 기록했다. 불완전하게 그려진 초기 모바일 가입 캡처 두 개는 정상 화면 증거에서 제외했다. 폰트 준비 후 다시 촬영한 세 개를 실제로 확인해 대체했다. 전문가 설정과 가입 양식은 390px 폭에서도 아래 끝까지 확인했으며, 입력·선택·버튼의 겹침과 잘림은 보이지 않았다. 비밀번호 조건은 두 줄로 표시된다. 가입과 비밀번호 입력, 계정 생성, 조직 생성은 실행하지 않았다.

허용된 전용 로컬 미배정 계정의 승인 범위에서 초기 설정의 조직 목록과 생성 양식을 검수했다. 운영 계정과 직무 권한은 변경하지 않았다.

## 중앙 규칙과 문구

전문가 가입과 설정에 전문 분야 선택 안내 `고르십시오`와 경력 표기 `경력 (년)`을 공통 문구 규칙으로 적용했다. 실제 수정은 두 양식의 문구 두 곳이다. 기존 수정 증거는 정확한 문구 역변환으로 검증하며, 기존 소스 지문을 새 값으로 덮어 실패를 숨기지 않는다.

배지 372곳과 스위치 3곳의 실제 호출을 추적했다. 크기 선택은 정해진 문자열이나 기본값만 사용한다. 크기 인자, CSS 변수, 숫자 폴백과 스위치 손잡이 위치를 중앙 정본까지 연결해 11개 직접 인자를 검증했다. 상위 스타일 조합도 각 값을 따로 확인한 뒤 판정한다. 검토하지 않은 크기 표현식, 펼친 속성 객체와 간접 호출이 추가되면 검사가 실패한다. 이 판정은 색상, 라벨과 다른 스타일을 일괄 승인하지 않는다.

아뜰리에 미분류 인자는 963개에서 907개로 줄었다. 감소분은 권한 검사 결과의 업무 데이터 29개, 이미 중앙 규칙을 사용하는 인자 14개와 배지·스위치 관련 13개다. 메종과 카르넷의 해당 집계는 0개다. 미분류 수는 시각 결함 수와 같지 않으며, 907개는 계속 검토해야 한다.

모서리 규칙 문서의 오래된 ‘아이콘 버튼 6px’ 설명도 수정했다. 일반 사각 조작부는 중앙 10px 규칙을 따르며, 호환용 토큰 표와 현재 운영 규칙을 구분한다.

## 앱 파일

Android 시작 안내문의 줄바꿈 전략을 중앙 `patterns/native-text-rules.json`에서 정하고 생성 리소스로 전달한다. 세 앱의 실제 소비 코드도 검사한다.

추가로 시작 화면의 밝은·어두운 배경색이 앱별 파일에 직접 적혀 있는 연결 누락을 발견했다. 검증된 웹 팔레트에서 Android 색상 리소스와 iOS `QDesignPalette.swift`를 생성하도록 연결했다. Android 기본 창 배경과 시작 배경은 생성 색상을 참조한다. 기본 색상은 기존과 같다. 중앙 팔레트 값을 바꾸는 검사에서는 Android와 iOS 산출물에 변경이 전달되는 것을 확인했다.

세 Android 앱의 릴리스 APK와 AAB를 다시 빌드했다. 여섯 산출물의 오프라인 자산이 정본과 일치한다. APK에서는 줄바꿈 값과 밝은·어두운 색상, 기본 배경과 시작 배경의 참조가 실제 컴파일된 것도 확인했다. 각 앱의 린트 오류는 0개이며 기존 경고 9개는 남아 있다.

Android 소스의 로컬 커밋은 아뜰리에 `d672530`, 메종 `e125859`, 카르넷 `b1fa778`이다. iOS 소스의 로컬 커밋은 `1fedf97`이다. 기존 서명 배포 파일은 갱신하지 않았으며 새 산출물은 서명되지 않았다. 실제 기기 검수와 iOS 빌드는 남아 있다. 시작 로고의 모션, 제품 금속색 등 다른 네이티브 인자까지 전부 중앙 제어된다고 인증하지 않는다.

## 운영과 남은 작업

아뜰리에 웹 수정 커밋은 `0aa6acb`이며 운영 배포가 READY 상태임을 확인했다. 제품 검사에서는 테스트 4,664개 통과, 예상 실패 1개, 제외 3개, 린트 오류 0개와 타입 검사 통과를 확인했다. 메종과 카르넷 웹 운영 기준은 `6a427ac`, `63e7307`이다. 최신 문구 변경 후 운영 업무 화면 전부를 다시 실측했다는 뜻은 아니다.

공통 인자 전파 408개와 팔레트 36개의 기존 브라우저 검사는 실패 0건이다. 이번 변경 후 전체 생성·동기화·소비 규칙 검사도 종료 코드 0으로 통과했다. 아이콘 32개가 승인된 Chromium 151.0.7922.34, Playwright 1.62.1, sharp 0.34.5, libvips 8.17.3 정본과 일치한다. 배지·스위치와 별칭 증명 43개, 중앙 팔레트와 앱 화면 규칙 18개의 추가 검사도 통과했다.

Q-Design 수정은 생성, 제품 동기화, 제품 빌드와 배포를 거쳐 반영된다. 앱에 묶인 화면과 네이티브 리소스는 앱 재빌드, 서명, 배포도 필요하다. 웹 화면이 편집 즉시 바뀌거나 이미 설치된 앱의 리소스가 자동 교체되는 구조는 아니다.

남은 907개 인자의 사용처와 실제 표시 검토, 추가 모바일·테마·입력 상태 검수, 네이티브의 다른 시각 인자, 앱 서명과 설치 기기 검증, iOS 빌드를 마쳐야 전체 완료를 판정할 수 있다. 계정 사용량은 이번 추가 확인 때 7%로 표시됐으며 사용자가 정한 21% 중단 기준에는 도달하지 않았다.

원본 화면, 로컬 검수 계정과 로그인 주소는 비공개 로컬 증거로 보관하며 이 문서에 포함하지 않는다.
