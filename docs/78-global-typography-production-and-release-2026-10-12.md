# 세 제품 공통 글꼴 연결과 운영 배포

업무 영역의 글꼴 별칭 2곳과 아뜰리에의 레거시 선택자 6곳을 큐 디자인의 UI·모노 글꼴 변수에 연결했다. 기존 업무 영역 규칙은 글꼴 이름을 직접 고정해 중앙 글꼴 변경을 덮어쓰고 있었다. 새 patterns/typography-links.css를 세 제품 기반 CSS의 마지막에 조합하며, 크기·굵기·배치·문구는 변경하지 않았다. 기존 기반 레시피의 전체 바이트와 인자 위치는 유지했다.

실제 인증된 메종 운영 /store 화면을 375px 폭에서 확인했다. 제목·버튼·선택 컨트롤의 중앙 UI 글꼴, 사각 컨트롤의 10px 모서리, 가로 넘침 없음과 새 배포의 스타일시트 적용을 확인했다. 사용자가 작성 중인 /store/new 탭은 유지하고 별도의 읽기 전용 검수 탭을 사용했다. 사용자가 다시 로그인한 아뜰리에 소유자 /dashboard도 1280px과 375px에서 중앙 업무 영역 UI·모노 변수 연결, 사각 차림표 버튼 10px과 가로 넘침 부재를 확인했다. 원래 탭은 이전 배포의 CSS를 유지하고 있었으므로 새 배포로 별도 검수 탭을 열어 확인했다. 카르넷은 사용자가 다시 로그인한 운영 홈에서 390px 폭, UI·모노 글꼴, 사각 차림표 버튼·배지 10px과 가로 넘침 부재, 실제 전달 CSS의 새 중앙 글꼴 층을 확인했다. 세 제품의 대표 업무 화면 확인이며 모든 경로나 별도 전문가 권한 패널의 운영 육안 검수를 완료했다는 의미는 아니다.

실제 생성 CSS와 제품 사본을 사용한 별도 브라우저 조합 검사 24개가 통과했다. 세 제품, 밝음·어두움 테마, 320·390·768·1280px 폭에서 중앙 UI·모노 변수를 바꾸면 해당 역할로 전파되는지, 기존 덮어쓰기의 재현과 수정 후 해소, 가로 넘침 부재를 확인했다. 이 검사는 합성 화면이며 운영 권한·실제 업무 데이터 검사를 대체하지 않는다.

53,997개 인자 중 미분류는 582건이다. 추가된 6개 기반 CSS 인자는 전체 정본 사본으로 검증했다. 이전 53,991개 인자의 전체 내용·순서·판정은 유지하고 변경된 기반 CSS 사본의 지문만 갱신했다. 기존 렌더러 보고서 3개와 근거 444곳을 현재 소스에서 재검증하고 이전 커밋의 보고서를 정확히 복원했다. 예전 배너·터치·토스트 검수의 역검증도 새 글꼴 층만 정확히 제거하도록 보완했다. 무관한 수정이나 빌린 지문은 허용하지 않는다.

최종 전체 릴리스 명령 node tools/extract-all.mjs --check --only=Q-Atelier,Q-Works,Q-Forge는 종료 코드 0이다. 80개 테스트 실행 그룹의 총 586개 테스트가 통과했고 실패는 0이다. 정본·사본, 팔레트, 컴포넌트 계약, 문구, 앱 독립 화면·공통 자원, 문서, 커버리지, 제품 동기화와 아이콘 32/32 대조도 통과했다. 브라우저 조합 검사 24개는 위 전체 정적 검사와 별도로 실행했다. 앞선 실행에서 새 층을 모르는 배너 역검증이 실패한 뒤 해당 검증을 수정하고 전체 명령을 다시 실행한 결과다.

중앙 수정은 생성·동기화·제품 배포를 거쳐 운영에 반영된다. 큐 디자인 파일을 저장하는 것만으로 세 제품 운영 배포가 자동으로 이루어진다는 뜻은 아니다. Android 실제 설치 검사는 미완료이며, iOS 최종 빌드·설치 검사는 사용자 지시에 따라 제외했다.
