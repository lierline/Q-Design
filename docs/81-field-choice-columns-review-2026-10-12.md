# 현장 선택 버튼 열 수의 검수 연결

아뜰리에 ChoiceGroup의 columns를 검토했다. 기본값은 QDPresentation.commonDefaults.fieldChoiceColumns이고 호출 화면 6곳은 QDPresentation.fieldChoiceColumns의 1·2·3열 규칙을 사용한다. 제품 코드는 이미 중앙 규칙에 연결되어 있었으며 이번에는 누락된 렌더러 검수 경로를 추가했다.

정확한 선언·숫자 타입·지역 식별자 한 곳과 모든 호출 인자 및 참조를 검증한다. 전체 소스 경로와 지문이 달라지거나, 호출 인자가 미분류이거나, 펼침 인자·추적되지 않은 참조가 있으면 승인하지 않는다. 작성된 기본값도 별도의 중앙 표현 근거가 있어야 한다. 다른 색상·기본값·부모 표현을 자동 승인하지 않는다.

gridTemplateColumns 표현과 이를 포함한 style 전체 인자 2건만 미분류에서 검증된 전달 인자로 바뀌었다. 이전 53,997개 인자의 모든 내용·순서·소스 지문을 유지하며, 이 두 판정만 정확히 되돌려 이전 전체 보고서를 복원한다. 미분류는 582건에서 580건으로 줄었다. 제품의 화면 스타일·업무 동작·문구를 변경한 작업은 아니다.

새 검수와 이전 전체 대장의 역검증 테스트 4개가 통과했다. 미검토 호출, 호출 누락, 기본값 변경, 식별자 변경, 빌린 근거와 무관한 인자의 판정 변경을 거부하는 것을 확인했다. 이전 글꼴 인자 6건의 역검증도 통과했다.

전체 릴리스 통과를 갱신하지 않았다. 사용자가 병행 수정 중이라고 확인한 메종의 바인딩·소스 변경은 계속 보존한다. 마지막 완료된 전체 릴리스는 78차의 586개 통과, 실패 0개, 아이콘 32/32다. 카르넷 전문 용어 수정은 80차 운영 배포로 반영됐다. 남은 아뜰리에 580건, 추가 tone 발견 후보와 다른 두 제품의 남은 문구는 계속 검토한다.
