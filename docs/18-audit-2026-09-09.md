### 5.1 먼저 할 것 (작게 고치는데 크게 나아진다)

**① Q-Atelier 인쇄가 첫 장에서 잘린다.** 감사증적을 뽑으면 9장 중 1장이다.
인쇄 규칙이 `main.qa-main-content` 는 이미 풀어 주는데 **그 부모인 셸 뿌리를 안 푼다.**
뿌리는 `height:100dvh; overflow:hidden` 을 **인라인**으로 들고 있어 `@media print`
규칙으로는 안 덮인다. 자식을 풀어도 부모가 1000px 에서 자른다.

    @media print {
      body > div {
        height: auto !important;
        max-height: none !important;
        overflow: visible !important;
        display: block !important;
      }
    }

시험했다. `/audit` 가 1장 → **9장**. `html, body` 만 푸는 안은 듣지 않는다(1장 그대로).
`body > div` 는 넓으니 셸 뿌리에 클래스를 붙여 그 이름으로 거는 편이 오래간다.

**② Q-Forge 현장 화면이 좁은 폭에서 넘친다.** `/work` 가 390px 에서 문서 폭 743px,
768px 에서 847px. 머리줄 한 줄이 줄바꿈 없이 아홉 덩이를 담는다. 로그아웃이 화면 밖으로
나간다. 장갑 낀 손으로 쓰라고 만든 화면이다. → `flex-wrap` + 좁은 폭에서 조직명·날짜·역할 감춤.

**③ `nav` 28개에 이름표가 하나도 없다.** 정본(`.qd-rail-nav`)에서 한 번 정하면 두 제품이
같이 받는다. 잰 화면 19곳 중 13곳이 제목이 `h1` 하나뿐인 것도 같은 자리의 문제다.

**④ Q-Sonar 대비 미달 넷이 클래스 하나다.** `text-red-400/80` → `text-red-400`.
재 보면 4.22 → **6.23**.

**⑤ 확인 대화상자가 「취소」에 초점이 있어도 Enter 를 확인으로 받는다.**
`Confirm.tsx:103` 이 취소에 초점을 주고 `:122` 가 초점을 안 보고 `onAnswer(true)` 를 부른다.
영구 삭제도 같은 길을 쓴다. 이 동작을 설명하는 주석도 테스트도 없다.

**한글 어절 공백 399곳.** 규칙이 자간에서 멈춰 있다. 고치면 세 제품 겉모습 399곳이
바뀐다. 안이 둘이다.

    가) [data-hangul] 에 font-family: var(--qd-font-sans) 를 더한다
        곧지만 「생산 로트 LOT-2026-004」 같은 섞인 이름표에서 코드가 모노를 잃는다
    나) word-spacing: -0.35em 을 더한다
        모노 공백 0.6em, 본문 공백 약 0.25em 이라 이 값이 둘을 맞춘다
        크기를 안 타고 코드는 모노로 남는다. 다만 JetBrains Mono 의 폭에 기댄다

권한다: **나) 를 정본에 넣고, 코드가 안 섞이는 자리만 가) 로 올린다.**

**본문 척도 세 벌.** 가장 흔한 글자가 10 / 13 / 12px 이다. 한 크기로 맞추자는 뜻이
아니다. 규제 문서를 훑는 화면과 로트를 장갑 낀 손으로 찍는 화면이 같은 밀도일 이유가
없다. 다만 지금은 그 차이가 **정해진 것이 아니라 각자 자란 것**이다. 정본에 밀도 층

### 5.3 결정이 하나 더 있다 · 정본을 레이어 안에 넣을 것인가

정본 CSS 는 레이어 **밖**에 있다. 일부러 그랬다. 제품이 `@layer components` 안에 같은
값을 다시 적어도 정본이 이기게 하려는 것이었다. 그런데 **Tailwind v4 의 유틸리티도
`@layer utilities` 안에 있어서 같이 진다.** Q-Sonar 의 표 칸에 적힌 유틸리티가 적혀
있는데 안 먹는다(직접 세니 78개 · 51칸 · 10파일).

    가) tools/sync.mjs:103 에서 정본을 @layer components 로 감싼다
        한 줄이다. 실제 파이프라인으로 빌드해 확인했다. 유틸리티 97개가 살아나고
        지금 회색으로 나오는 경고 판 테두리 2곳과 /diagnostics 판정 색도 돌아온다.
        겹치는 자리는 실측으로 Q-Sonar 0곳 · Q-Forge 1곳(이미 죽은 규칙)이다
    나) 정본은 그대로 두고 정본의 장치를 쓴다
        .qd-quiet(흐린 칸) · .qd-num(오른쪽 정렬 + 자릿수 고정)이 이미 있고
        특정도 (0,2,0) 이라 정본 안에서 이긴다. Q-Sonar 는 둘 다 안 쓴다

**나) 를 먼저, 가) 는 결정 사항으로 남긴다.** 가) 는 한 줄이고 효과가 크지만 정본이
내놓는 것이 있다. 레이어 밖에 둔 이유가 바로 「제품이 다시 적어도 정본이 이긴다」 였고,
같은 레이어로 들어가면 뒤에 오는 제품 규칙이 동점에서 이긴다. 지금 겹침이 0곳이라
당장은 안전하지만 **그 보장이 사라지는 것 자체가 값이다.**

정본이 «장치를 안 줘서» 유틸리티를 쓸 수밖에 없던 자리(경고 판 테두리 · 판정 색 칸)는
**정본에 그 장치를 더하는 것**이 이 집안의 방식이다. 그것까지 갖춘 뒤에도 남는 것이
많으면 그때 가) 를 정하면 된다.

🔑 같은 정본을 쓰는 Q-Forge 는 죽는 유틸리티가 **2개**뿐이다. 그쪽 globals.css 는 이
위험을 세 곳에 주석으로 적어 두었고 표를 부품 하나로 그린다. 같은 정본인데 한쪽만
규칙을 흡수했다.

### 6.1 정본에 들어간 것

**한글 어절 공백을 되돌린다.** 규칙이 자간에서 멈춰 있던 것을 끝까지 밀었다.

    --qd-hangul-word-space: var(--qd-hangul-word-space-src, -0.35em);

한글 갈래 12곳에 `word-spacing` 을 걸고, 되돌리는 갈래(`.qd-table--hangul th[data-latin]`)
에는 `word-spacing: normal` 을 함께 넣었다. 빼먹으면 통째로 뒤집은 표에서 라틴 머리글만
조여진다. **글꼴은 안 바꾼다** - 바꾸면 「생산 로트 LOT-2026-004」 같은 섞인 이름표에서
코드가 모노를 잃는다.

**강조 칸 장치를 더했다.** `.qd-table .qd-accent { color: var(--qd-accent) }`.
§5.3 에서 적은 이유 그대로다. **정본이 잡는 속성은 정본이 장치를 함께 줘야 한다.**
장치가 없으면 제품이 유틸리티를 적고, 그것이 안 먹으면서 「고쳤는데 화면이 그대로」 가
된다. Q-Sonar 에서 그런 자리가 78개였다.

§5.3 의 **가) 는 안 했다.** 정본은 레이어 밖에 그대로 둔다. 나) 로 78개가 전부
해결됐으므로 정본의 보장을 내놓을 이유가 없어졌다.

### 6.2 검사기가 또 거짓말을 했다

정본이 `word-spacing` 으로 공백을 되돌렸는데 `check-hangul-live` 는 여전히 「모노 공백」
으로 셌다. **canvas 의 `measureText` 는 `word-spacing` 을 안 본다.** 고쳐 놓고도 검사가
못 보는 형태다. 계산된 `word-spacing` 을 더해서 재게 고쳤다.
이것이 이 감사에서 일곱 번째 «도구가 먼저 거짓말한» 자리다(§3).
