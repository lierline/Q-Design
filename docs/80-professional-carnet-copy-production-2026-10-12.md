# 카르넷 업무 용어 정비와 공통 문구 연결

사용자가 지적한 ‘끝나지 않은 공정’을 ‘미종료 공정’으로 수정했다. 이어 카르넷 13개 업무·공통 파일의 문구 58곳을 정비했다. 메뉴, 홈 현황, 재고·기한, 시연 데이터, 화면 잠금, 감사 추적, 제품표준서 수정과 기록서 발행 안내를 검토했다. 모든 제품의 문구 검수를 완료했다는 뜻은 아니다.

| 기존 표현 | 변경 표현 |
| --- | --- |
| 끝나지 않은 공정 | 미종료 공정 |
| 최소 재고선 아래 | 최소 재고 미달 |
| 기한 임박 · 지남 | 기한 임박 · 경과 |
| 지어낸 배치 기록 | 시연용 배치 기록 |
| 시연 자료 비우기 | 시연 데이터 초기화 |
| 바뀐 칸 | 변경 항목 |
| 차림표 | 메뉴 |
| 자료 받아 오기 | 자료 수신 이력 |

patterns/copy-rules.json과 patterns/professional-carnet-copy.json에서 정확한 제품·파일 범위를 지정한다. AST 문자열과 JSX 문구만 수정하며, 주석·업무 코드·사용자 입력·규제 원문을 일괄 치환하지 않는다. dist/q-design.copy-bindings.json은 원래 문구와 적용 문구를 함께 보존한다. 동일한 중앙 규칙을 바꾸면 이미 수정한 화면도 갱신된다. 소스가 별도로 달라지면 검사는 실패한다.

최근 활동에 노출된 link_connection과 link_inbox는 patterns/carnet-record-labels.json의 ‘연동 연결’, ‘연동 수신 기록’으로 표시한다. 생성된 TS 사본을 tableLabel이 실제로 사용한다. 데이터베이스 식별자는 변경하지 않았다.

시연 데이터 초기화의 확인 문구는 화면과 서버에서 모두 ‘초기화’를 사용한다. 권한, 확인값, 실제 데이터베이스 함수의 보호 조건은 유지했다. 무권한·빈값·이전 문구·잘못된 문구가 데이터베이스 호출 전에 차단되는 것을 대체 경계로 검사했다. 실제 초기화를 실행하지 않았다.

전체 소스 역검증에서 문구 변경과 표시 명칭 import·조회 한 곳만 달라졌음을 확인했다. DMR 스타일 인자 전체가 같다는 것을 확인해 무효화된 기존 근거 5건을 재검증했다. 제품 코드의 주석·줄 배치와 업무 동작을 임의로 재작성하지 않았다.

중앙 문구 검사 11개와 카르넷 기존 검사 21개가 모두 통과했고 타입 검사도 통과했다. 테마, 공통 탐색 사본, 앱 바로가기와 SQL 인자 검사도 통과했다. 카르넷 현재 인자 15,775개, 미분류 0개다. 아뜰리에 검사에서는 582건이 그대로 남는다. 메종은 병행 변경 중이므로 이전 수치를 현재 결과로 간주하지 않는다. 추가 tone 인자는 별도 발견 후보이며 이 수치에 포함됐다고 주장하지 않는다.
