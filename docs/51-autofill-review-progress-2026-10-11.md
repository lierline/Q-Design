## 수정 범위

운영 전문가 로그인에서 브라우저가 저장된 정보를 자동으로 채우면 입력 배경이 큐 팔레트 밖의 파란색으로 표시되는 차이를 발견했다. `patterns/components.css`의 공통 입력 상태 규칙으로 배경, 글자색, 커서와 키보드 초점을 중앙 팔레트에 연결했다. 비활성 입력과 시스템 강제 색상 모드도 별도로 정의했다. 자동 채움 기능과 입력값, 인증 및 제출 로직은 변경하지 않았다.

세 웹 제품에 동일한 생성 CSS를 반영했다. 아뜰리에 독립 시뮬레이터, 웹 오프라인 화면과 캐시 변경 지문, 세 Android 앱 및 아뜰리에 iOS의 생성 오프라인 자산도 갱신했다. 컴포넌트 문서에 중앙 입력 상태 규칙과 적용 절차를 기록했다.

기존 컴포넌트 규칙은 그대로 두고 파일 끝에 자동 채움 상태 규칙만 추가했다. 기존 인자 17개의 근거는 실제 줄과 명명된 클래스 규칙이 변경되지 않았음을 확인한 범위에서만 유지했다. 다른 소스 변경이나 누락을 이 근거로 승인하지 않는다.

## 검증

공통 부품 전체 검사와 최신 커밋을 기준으로 한 전체 릴리스 검사가 종료 코드 0으로 통과했다. 앱 아이콘 정본 32개도 승인된 렌더러와 일치했다. 브라우저 비교, 모바일·테마·줄바꿈·파일 입력·인쇄 문구·반응형 차트 검사도 통과했다. 중앙 인자 변경 전파 검사는 408건과 팔레트 36건, 총 444건에서 실패가 없었다. 이 검사는 전체 업무 화면의 모든 상태를 인증하지 않는다.

초기 검사에서 시뮬레이터 사본과 마지막 생성 이후의 인자 목록이 오래된 상태를 발견했다. 생성기와 인자 추출을 다시 실행한 뒤 전체 공통 검사가 통과했다. 기존 지문에 맞춰 검사 기준을 바꾸지 않았다.

로컬 전문가 로그인에서 배경과 글자색의 중앙 토큰 연결, 10px 모서리와 정상 키보드 초점 표시를 실측했다. 운영에서는 두 입력이 실제 자동 채움 상태인 것을 확인했다. 배경은 `#141414`, 글자색은 `#f0ebe0`, 모서리는 10px였다. 키보드 초점도 중앙 강조색의 2px 테두리와 4px 간격을 유지했다. 파란 브라우저 배경은 사라졌다. 저장된 정보를 읽거나 입력·제출하지 않았다. 화면 상단과 하단 캡처 2개를 직접 확인하고 판정했다.
