# 메종 기능 이식 후 아이콘 연결과 릴리스 후속 검수

Claude 기능 이식 완료 인계를 확인하고 메종 디자인 검수를 재개했다. 업무 코드 27개 파일의 Lucide 가져오기 69개를 공통 Phosphor Regular 모듈에 연결했다. 구매 분석, 일정, 입고 검사, 부적합품, 사고 결재, 첨부 파일과 당겨서 새로고침을 포함한다. 실제 JSX 이름, 별칭, 접근성 속성, 크기 속성과 업무 콜백은 유지한다. 기본 TimePicker 정본도 함께 갱신했다.

새 아이콘은 Q-Design에 고정된 공식 Phosphor 커밋 2b75f3ad12b420c9504ef05df8d2564a28f8500e에서 가져왔다. CalendarCheck는 기존 calendar-check 자원을 사용하고, CalendarMinus·Coins·Repeat·BadgePercent의 공식 Regular 자원 4개를 추가했다. 회사 CI는 변경하지 않았다.

메종 커밋 f121284520f8a3b033c63e8e11f0b493fb3fede1은 운영 배포 dpl_GqJhR8X9AUDJixR4kKAup6ZPUbiV에서 READY이며 maison.medqraft.app 별칭을 확인했다. 실제 구매 실적·납기 분석 화면에서 표시 아이콘의 256×256 원본 좌표와 공통 Regular 형태, Pretendard 글꼴, 버튼 모서리 10px을 확인했다. 1280px 문서 폭의 가로 넘침은 없었다. 업무 데이터를 등록하거나 변경하지 않았다. 운영 캡처는 D:/Claude/tmp/qd-phase85-maison-purchasing-icons-production.png와 qd-phase85-maison-delivery-production.png다.

공통 아이콘 검사와 내보내기를 전체 생성 흐름에 추가했다. 세 제품의 실제 소비 모듈 733개를 검사했고, 사용 아이콘은 아뜰리에 142개, 메종 157개, 카르넷 18개다. 모듈·공통 구현·라이선스 323개 사본을 대조한다. 명시적 가져오기뿐 아니라 재내보내기·정적 동적 가져오기·require의 기존 라이브러리 참조도 검출한다. 전체 계획을 먼저 검증하여 알 수 없는 아이콘 때문에 일부 제품만 바뀌는 일을 막는다. 공통 원본 변경 후 build-react-icons와 sync-react-icons를 통해 실제 사용 모듈에 전달한다.

실제 메종 아이콘 8개를 세 제품 CSS와 두 테마에서 렌더링한 6개 390px 검사 사례를 통과했다. 기본 크기 20px과 작은 크기 16px을 중앙 변수로 각각 28px·18px으로 바꿨을 때 전달됐고, 명시적 16px 크기는 유지됐다. 장식 아이콘과 이름이 있는 아이콘의 접근성도 확인했다. 아이콘 가져오기·크기·별칭 단위 검사 13개와 표시 문구 위치 이동 부정 검사 1개를 통과했다. 메종 전체 TypeScript 검사와 정상 커밋 훅도 통과했다.

아이콘 가져오기 줄 증가로 달라진 문구 연결은 표시 텍스트를 변경하지 않고 재검증했다. 모든 비가져오기 리터럴과 실제 JSX 텍스트를 대조하며 다른 제품 연결은 보존한다. 세 제품 문구 규칙 검사 132개 파일을 통과했다. 구매 지표의 색상 선택자도 실제 소비 부품으로 다시 검증했다. 메종 미분류는 976건이며, 아뜰리에의 마지막 검증 수 580건과 카르넷 0건을 합하면 1,556건이다. 전체 화면 검수 완료 수가 아니다.

전체 릴리스 검사에서 아뜰리에 웹 오프라인 화면과 접근 시뮬레이터의 이전 CSS를 발견했다. 기본값을 유지하며 공통 표시 크기 변수 6개를 전달하도록 재생성하고 캐시 버전을 갱신했다. 웹 오프라인 커밋 d25894e0과 시뮬레이터 커밋 043da298은 origin/main에 푸시했다. 제품의 정상 사전 푸시 검사를 통과했다. 앱 및 iOS 파일은 이번 후속 수정에 포함하지 않았다.

이전 자동완성·루트 글꼴·탐색 이력 검증이 최신 공통 표시 크기 변경에 충돌한 부분을 수정했다. 이미 검증된 정확한 전체 지문만 복원하며 임의 변경은 거부한다. 관련 부정 검사도 유지한다. 기능 이식으로 사라진 예전 메종 치수 10곳은 이전 커밋의 토큰 적용과 현재 전체 파일 또는 삭제를 정확히 대조해 역사 기록으로 구분했다. 새 부품의 디자인을 승인하는 예외는 아니다. 새 UI는 별도의 현재 원본 검사 대상이다.

전체 릴리스는 아직 통과하지 않았다. 진단 실행은 실패 지점 뒤를 이어 확인했으며 전체 통과 기록으로 사용하지 않는다. 현재 발견된 후속 작업은 구매 실적 지표의 열 수 중앙 연결, 새 검사 기록지 로고 높이 중앙 연결, 새 첨부 파일 소비자를 포함한 인쇄 부품의 독립 검사다. 제조·검사 인쇄 양식의 미분류 후보 221건도 남았다. 계정 사용량은 확인 시점 33%이며 50% 상한을 유지한다.

운영 배포, 현재 정적 원본, 독립 모바일 부품 검사와 전체 릴리스 판정은 각각의 근거로 구분한다. 비공개 계정 검수 파일은 열거나 커밋하지 않는다. 병행 작업의 버전 파일과 빌드 설정 변경은 보존한다.
