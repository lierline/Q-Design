# 메종 업무 양식 데이터 추가 검수

29개 업무 양식의 정확한 객체 펼침 61건을 업무 데이터로 분류했다. 전체 미분류는 1,080건에서 1,019건으로 감소했다. 아뜰리에 573건, 메종 446건, 카르넷 0건이다.

검증은 실제 TypeScript 타입, 속성 목록, 인덱스 값 타입, 저장 함수 47개의 실제 선언, 입력 검증 스키마와 소스 72개를 대조한다. 저장·삭제·결재 함수는 실행하지 않았다. 바코드 양식의 컴포넌트 `value`로 직접 전달되는 1건은 추가 검토가 필요해 미분류로 유지했다.

교육 본문의 실제 상태 갱신 함수를 검증해 사용자가 입력한 앞뒤 공백과 줄바꿈, 다른 항목 값이 보존되는지 확인한다. 이는 화면 문구 띄어쓰기 정리와 사용자 입력의 원문 보존을 구분하는 검사다.

분류 변경의 역변환은 이전 커밋 `e8648fca9a6120c7b18bed8bde61ec36aad81669`의 전체 메종 검수 대장과 대조한다. 지정된 61건 외의 수정, 빌린 근거 해시, 관련 없는 대장 변경은 실패한다.

이번 변경은 검수 대장과 도구 변경이다. 제품의 기능이나 화면 소스는 변경하지 않았다. 직전 공통 필수 항목 안내 문구는 메종 운영에 배포 및 실제 화면 확인을 마쳤다. 전체 릴리스 검사의 이전 실행은 후속 수정 일괄 반영을 위해 중단했으므로 전체 통과로 계산하지 않는다. 최종 상태에서 다시 실행해야 한다.

검증 결과: 추가 분류·문구·기존 27건·전체 워크스페이스 역변환 검사 11개 통과, 실패 0개. 문자 검사 2,143개 파일 통과. 전체 릴리스 재검사는 후속 수정 반영 후 실행한다.
