# Claude에게 전달: 문서 검토 시안의 다음 개선 의견

사용자가 '디자인은 더 뭐 개선할거 없나'라고 물었고, Codex가 현재 화면과 코드를 다시 검토해 아래 의견을 제안했습니다. 사용자는 이어서 '관련해서 정리해서 클로드에게 의견 전해줘봐'라고 전달을 지시했습니다. 이번 요청은 의견 전달입니다. 파일 수정이나 운영 반영 지시가 아닙니다.

기준은 이미 사용자가 선택한 장부형 외관, 중립색 주 버튼, 맥락 유지형 검토, 폭이 이어지는 집중 보기입니다. 이 선택을 유지하면서 정보 위계와 작업 상태 표현을 개선하는 제안입니다.

## 우선 적용 제안 1: 본문이 더 일찍 보이게 정돈

현재는 앱 머리, 페이지 제목과 설명, 비교 조작부, 문서 머리말이 누적됩니다. 확인한 모바일 캡처에서는 문서 패널이 화면 위에서 약 364px 아래에 시작합니다. 이 값은 특정 캡처의 관찰이지 모든 기기의 측정값은 아닙니다.

제안: 실제 제품 보기에서는 비교 방식과 느린 재생을 '시안 설정'에 접어 두고, 제목·담당·개정 정보를 간결하게 정리합니다. 비교 기능은 없애지 않고 필요할 때 펼칩니다. 집중 보기에서는 페이지 소개를 축약하되 현재 문서 식별, 복귀, 검토 행동은 유지합니다.

확인 기준: 같은 화면 크기에서 본문과 확인 항목이 더 많이 보이고, 필터와 문서 위치를 잃지 않아야 합니다. 검증하지 않은 면적 개선율은 주장하지 않습니다.

## 우선 적용 제안 2: 진행 상태에 맞는 하단 행동

현재는 확인 항목이 0/3이어도 '검토 완료'가 가장 강하게 보이고, 누르면 오류를 통해 미완료를 알립니다.

제안: 하단에 '1/3 확인 · 변경사항 저장됨'처럼 짧은 상태를 일관된 자리에 표시합니다. 주 행동은 '남은 2개 확인'으로 첫 미확인 항목에 이동하고, 모두 확인하면 같은 위치에 '검토 완료'를 표시합니다. 마지막 체크만으로 검토를 자동 완료하지 않습니다. 완료는 별도 클릭으로 확정합니다.

확인 기준: 남은 항목으로 이동은 값을 바꾸지 않아야 합니다. 마지막 체크 시 버튼 이름 변경을 알리되 초점을 강제로 이동하지 않습니다. 저장 중·미저장·실패·완료를 구별하고, 저장 실패 시 초안과 체크를 유지합니다. 메모 저장과 검토 완료는 다른 행동으로 남깁니다.

## 다음 적용 제안 3: 목록의 우선순위와 안정된 정보 위치

현재 기본값은 모든 상태와 기한순 정렬이며, 완료된 예시 문서가 앞에 올 수 있습니다. 선택된 행에서는 기한 자리에 '열람 중'을 표시해 날짜가 사라집니다.

제안: 검토할 문서를 먼저 보이게 하거나 대기와 완료를 구분합니다. 보완 요청·기한 임박·새 변경처럼 먼저 볼 이유는 실제 데이터가 있을 때만 한 가지로 간결하게 표시합니다. 날짜 위치는 선택 전후에 유지하고, 선택은 면과 제목 굵기로 표시합니다. 왼쪽 강조선은 추가하지 않습니다.

확인 기준: 선택 전후에 기한이 사라지지 않아야 하며, 작업 중 완료 처리로 목록이 재정렬될 때 읽던 위치와 다음 문서가 갑자기 바뀌지 않아야 합니다. 행 밀도는 데스크톱에서 다듬되 터치 영역은 유지합니다.

## 다음 적용 제안 4: 글자와 여백의 강약

제안: 제목·검토 요약·확인 항목·메모를 읽기 중심으로 정리하고, 번호·개정·시간은 보조 정보로 묶습니다. 본문과 중요한 설명은 편하게 읽히도록 크기를 검토합니다. 서로 다른 구역 사이 간격은 넉넉하게, 같은 구역 내부는 가깝게 둡니다. 장식선이나 상자를 추가해 구분하지 않습니다.

확인 기준: 밝은 화면과 어두운 화면의 실제 긴 한글 제목·설명에서 확인합니다. 기존 타이포그래피 정본과 다른 수치는 시안 후보로 다루고 공통값을 임의로 확정하지 않습니다.

## 이후 제안 5: 관련 기록을 잠깐 대조하는 보기

현재 관련 기록을 누르면 검토 중인 문서가 교체됩니다.

제안: 관련 기록 요약을 본문 안에서 잠깐 펼쳐 확인하고, 필요할 때 '전체 문서 열기'로 이동합니다. 이미 목록과 상세가 있는 화면에 상시 세 번째 열을 강제하지 않습니다. 좁은 화면에서도 펼침 영역을 닫으면 기존 위치로 돌아옵니다.

확인 기준: 원래 문서의 초안·체크·읽기 위치를 유지해야 합니다. 미리보기와 현재 편집 대상을 혼동하지 않도록 참조 문서 번호와 개정을 표시합니다. 관련 기록 확인이 원래 문서의 검토 완료 상태를 바꾸지 않아야 합니다.
