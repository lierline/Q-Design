계약 신규 작성과 수정 화면이 공유하는 양식의 안내 2건을 큐 디자인 규칙 `patterns/professional-maison-contract-copy.json`에 연결했다.

| 대상 | 이전 | 수정 |
| --- | --- | --- |
| 계약 구분 | 서식에 찍히는 구분입니다. 「검토 대상」은 «언제 검토하는가»라 다른 축입니다. | 서식에 표시되는 계약 유형입니다. 검토 대상은 계약 검토 사유입니다. |
| 후속 조치 내용 | 필요일 때만 적습니다 | 필요한 경우 입력하세요. |

실제 제품 컴파일 결과는 두 안내 문자열만 바뀌었다. 모든 디자인 인자와 줄 위치가 그대로이며, 입력·선택·검증·저장 동작은 변경하지 않았다. 변경된 파일을 근거로 사용하는 207개 기록은 완전한 소스 비교로 다시 검증했다. 미분류는 아뜰리에 573건, 메종 417건, 카르넷 0건으로 전체 990건이다.

실제 Field 렌더링의 안내, 접근성 연결, 입력 원문 보존, 이미 연결한 문구의 다음 중앙 규칙 수정, 전체 대장 복원과 기존 저장 함수 검증을 포함한 검사 15개 통과, 실패 0개. 처음 작성한 렌더링 검사는 문자열 리터럴의 따옴표까지 표시 문구로 비교해 실패했으며, 실제 속성 값으로 해석해 다시 검증했다. 메종 타입 검사와 정상 커밋 훅의 ESLint·Prettier도 통과했다.

현재 문구 바인딩은 144개 파일이다. 전체 연결 검사는 현재 바인딩 검사에서 수행하고, 각 안내 검사는 담당 파일의 출력과 원문을 확인한다. 과거 계약 데이터 검사의 도구 해시는 고정된 커밋의 정본을 사용한다. 현재의 두 역사 비교 어댑터는 정본 대비 허용한 소스 복원 호출과 이력 해시 참조만 달라졌는지 확인한다. 새로운 현재 근거에는 실제 어댑터 해시를 기록했다. 과거 기록을 몰래 최신 해시로 바꾸거나 업무 데이터 검사를 생략하지 않았다.
