# 메종 문서 내용 잔여 인자 검수

문서 출력의 보류 인자 6건을 실제 설치된 TypeScript 의존성 경로에서 재검증했다. Windows 검사 환경에서 일부 패키지 연결을 읽지 못했던 문제와 실제 소스 문제를 구분했다. 정상 경로에서 도면 축척과 검토자 직위는 문자열로 확인됐으며, 교육 계획·보고서의 기록 변수와 객체 펼침 4건은 명시적인 `TrainingRow`와 타입 지정 조회 결과로 확인됐다.

출력 경로는 `ModuleFormResult.values` 또는 검토 의견 표의 문자열 행과 `trainingValues`를 거쳐 DOCX의 `doc.render`로 연결된다. 입력 값이나 문서를 변경하지 않고 소스만 검사했다. 화면 크기, CSS 위치, 시각적 배율은 승인하지 않았다.

미분류는 전체 996건에서 990건으로 감소했다. 아뜰리에 573건, 메종 417건, 카르넷 0건이다. 이번 변경은 문서 내용 2건과 업무 데이터 4건이다. 정확한 6건을 되돌리면 이전 커밋 `a9817f6`의 메종 대장 전체와 일치한다.

검증 13개 통과, 실패 0개. 이전 문서 내용 13건, 업무 결과 23건, 양식 데이터 61건과 워크스페이스 검사도 포함한다. 숫자를 줄이기 위한 포괄적인 파일 예외나 속성 이름 예외는 추가하지 않았다. 제품 소스 변경은 없으며 전체 릴리스 최종 재검사는 별도다.
