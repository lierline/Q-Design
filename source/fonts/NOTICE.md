# 글꼴 출처

## Pretendard Variable

- 파일: `PretendardVariable.woff2` (약 2.0MB, weight 45~920 가변)
- 저작자: 길형진 (orioncactus)
- 라이선스: **SIL Open Font License 1.1**
- 원본: https://github.com/orioncactus/pretendard

OFL 1.1 은 임베딩과 재배포를 허용합니다. 다만 **글꼴 자체를 판매할 수 없고**,
파생 글꼴을 만들면 같은 라이선스를 따라야 합니다.
이 파일은 Q-Atelier 의 `public/fonts/` 에서 그대로 복사한 것으로, 수정하지 않았습니다.

## JetBrains Mono

- 이 저장소에 파일을 담지 않았습니다. Google Fonts 에서 받아 씁니다.
- 라이선스: SIL Open Font License 1.1
- 원본: https://github.com/JetBrains/JetBrainsMono

```css
@import url('https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;500;600;700&display=swap');
```

## Cormorant Garamond

- 이 저장소에 파일을 담지 않았습니다. Google Fonts 에서 받아 씁니다.
- 라이선스: SIL Open Font License 1.1
- 원본: https://github.com/CatharsisFonts/Cormorant
- **italic 은 로드하지 않습니다** (브랜드 규칙). [타이포그래피 문서](../../docs/03-typography.md) 참조
