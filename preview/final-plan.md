# Q-Design 개선 최종안 (장부형) 2026-10-10

시안: preview/pages-proposal-v3-*.png, phones-proposal-v3-*.png. 코덱스와 세 차례 의논한 결과입니다. 정본(source, dist, patterns)은 아직 바꾸지 않았습니다.

## 합의한 방향
- 상자 · 그림자 · 카드 속 카드를 걷고 괘선과 면 차이로 구분(장부형). 모서리 10px 유지.
- 글래스는 쓰지 않음. 메뉴와 팝업은 불투명 면 + 괘선.
- 연속 검토는 목록 + 상세 나란히 + 집중 보기(코덱스 시안 구조). 선택 문서는 면 색과 굵은 제목으로만 구분. 단건 상세와 폼은 두 칸으로 나누지 않음.
- 폰: 상태 줄 아래 머리줄에 메뉴 부착(떠 있는 단추 없음), 번호와 제목을 고정 머리에, 탭 대신 쌓기(동시 참조가 필요하면), 하단 고정 동작 바.
- 핵심 동작은 항상 보이고 보조 동작만 호버. 상태는 점 + 글자.

| 초점 | 2px 윤곽, 간격 2px |

## 반영 단계 (코덱스 의견 반영)
1. 원본 경로 확정. source/ 는 Q-Atelier 원본에서 갱신하는 사본이므로 source 를 직접 고치지 않는다. 원본 수정 후 extract-all.mjs --sync 로 재생성하고 차이 검증.
2. 기초 층 반영. 양 테마의 계산 스타일이 명세와 일치하는지 실측. 위험: 전역 변경으로 밀도와 줄바꿈이 바뀜.
3. 패턴 층: 연속 검토. 코덱스 시안의 코드를 복사하지 않고 동작 계약(문서별 초안, 위치 복원, 독립 저장, 실패 후 재시도, 저장 중 이동)을 가져와 실제 저장과 권한에 연결.
4. 패턴 층: 단건 상세, 폼, 폰. 상태와 행동의 일치(현재 단계와 다음 행동이 겹치지 않게), 키보드, 가상 키보드 확인.
5. 가드 시험 추가: 조작 윤곽 3:1, 글자 단계, 모서리 10px(적용 부품에 한정), 저장 실패와 상태 전이.
6. 시험대는 Q-Atelier. 로컬에서만 확인하고 배포 판정과 분리. 공통 변경은 Q-Maison, Q-Carnet 회귀도 확인.
